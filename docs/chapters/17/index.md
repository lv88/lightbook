# 十七、至尊大正理杜鹃师的历史

“师之长子大理鹃。”

值得宗喀巴大师这般称赞的大正理杜鹃师，从童贞身入佛门出家，成年受比丘戒。在止迦摩啰室啰寺中，精研三藏教典，成为彻底善巧者。他依止阿阇黎月称座前，听受了从圣龙树传来的显密全圆教授。内心专一住于正定精修，以此对于大乘道次第，获得彻底的修悟通达。他对于正见的一些甚深最细难通的要扼，为了引渡难关起见，长久向上师与本尊无二无别前猛利祈祷求加持。并努力勤修积资忏罪，以此获得具德怙主圣龙树亲自现身，对他详细开示正见细微诸难处。他获得完全拔除了相执的缠缚。在阿里法王菩提光派遣拏错译师去迎请阿底峡尊者时，拏错译师去到止迦摩啰室啰寺中，访问阿底峡尊者住在哪里时，他看见止迦摩啰室啰寺大殿的僧会中，在众班智达的列座中央，坐著一位年老具足威仪的大德，他问这位怙主是阿底峡尊者吗？僧人对他说道：“西藏的长老，你说的是什么话，这位大德是在具德阿阇黎月称座前，亲自听受过正法的正理杜鹃大师，他是阿底峡尊者的太老师。”大德正理杜鹃他是怙主圣龙树的再传弟子。在《克主杰的密传》中也说：“往昔他愿生为正理杜鹃时，圣龙树前来开示他正见最细要义，令他所有执实颠倒，都得从根拔除。圣龙树对他说：‘我是印度诸大成就师中，依止至尊文殊者。这种原因，也是由于发现经教最细难要时，向文殊菩萨祈祷求加持，而细察甚深教义的。你也应当依止至尊文殊菩萨吧！’又说：‘我也愿于未来世，作饶益边地众生事业，你也将在那时做我最初侍众中的上首弟子。’曾经作了这样的未来记别。如像这样阿阇黎月称也对大正理杜鹃记别说：‘在未来世，至尊文殊将如愿生在边地示现为比丘相。你也当生在那里，依教奉行，大弘佛教吧！’”以上情节，是依一切智克主杰密传中所说而录出的。
