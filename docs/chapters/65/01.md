# 附一、持律师洛卓伯巴略传

这位大师，是在庚辰年(公元一五八○年，明万历八年)，降生在后藏上部曲阁区的约仲城中，师在孩童时期，对有情生起悲心的时候，就自然地流泪不止，这是由本性中现起的悲相。继后师到纳塘在大堪布。住巴协饶(成智)座前出家，命名叫桑珠扎巴伯敦(义为意成名称德)，依大译师桑迦西(义为僧吉祥)听受许多《声明》论著。继后，由于他看见哲日山等处的许多修行胜地，发生现在我愿作一个大修行人的念头。那时，师的法友有一康区僧人劝他说：“暂时求学经论吧！然后才去修行那就很好，否则现在就修的话，那是鲁莽愚修。”以此继续学习还未学完的经教。这位大师说：“我那时如果住哲日山修行，或许将成为一个大修士，但是能否值遇这一甚深中观见，那是不能知道的。”继此，师与一些法友结伴同赴前藏的时候，在能见桑耶山的一条道上，他突然失去知觉而昏倒，同伴对他很好救护苏醒转来，他说：“我所见的是同一位大德结伴而行，到了说是桑耶佛殿的跟前，与那位大德一同进门去的时候，有一白色人说：‘你这人往哪里去，将我挡住不让进去。’就在这时，我在梦中，听到他人叫我的声音，以此恢复知觉苏醒过来。那白色人是那位大德的本尊，以此是他解除了我的灾难。”此后勤学《般若》，一直研习了三年的时间，对于教法，也就成为通达无碍。

继后想学《中论》，及《释量论》的时候，又是法友康区僧人劝他说：“你如果想学《中论》及《释量论》的话，当以‘甘丹寺’为最好。”以此因缘，他前往甘丹寺，到了贾曹杰甘丹教主的座前，在那时也就与协饶生根及根敦主两位大师相见。他想《般若》自己已经是这样了知，念当对于《中论》，及《释量论》学成善巧，也就在贾曹杰大师座前听讲，也在法王协饶生根及根敦主两师座前听讲；以此一变过去所学《般若》诸宗，而对宗喀巴师徒的不共宗见，获得生起定信。特别是他虽是没有见著宗喀巴大师，然对宗喀巴大师确生起视如真佛的思想，他说：“这好像有一种业力因缘，法友康区僧人对我是有大恩的。”

继后，这位佛子持律大师到了二十六岁时，在乙巳年，贾曹杰大师为作亲教师，持律大师扎巴绛称为作轨范师，仁嘉瓦为作教授师，在僧伽大众当中，受具足戒，成为真正比丘。师从此哪怕是细微过犯，也不染犯，护戒如护眼珠，以此都称他叫持律师。他继想如果不听讲《毘奈耶》，那就行将成为如一些十论师，也不懂《毘奈耶》条规实施是怎样的。他想应当对于律经四部中所说的开、遮、应行三者的所有学处，毫不紊乱地获得了知，于是在持律大师扎巴绛称座前，听讲戒学处及其规约等。他说《菩提道次第》最初也是在持律大师座前听得的。此外还听受了很多教法。

他继在法王协饶生根座前，听讲《密集本续》及其释论，圆座明灯论等宗喀巴大师著述，以及圣传法类完全听受，并听受关于《胜乐本续释》及其释论《如意乳牛》、鲁枳两师所传的圆满次第的胜乐法类等许多法门。主要所有金刚乘法恩，是从大德协饶生根座前，圆满听受，以此对协饶生根大师作为恩德最大的上师。关于以四部难论为主的许多性相法类经论，他是在一切智根敦主大师座前听受的；以此关于三藏经论方面，则以根敦主大师为唯一受恩深重的上师。这位大师求广大多闻的情况，如他自己所说：“我在教师一切智座前，听讲《毘奈耶》共复座六次，又在法王须鲁嘉却(义为童胜)座前听讲一次，共七次。又我在‘坝索寺’讲说一次宗见导释的时候，对离一异品的义理，作了一次最广的解说；这是由于我在教师一切智座前听受的没有忘掉，又加上我在教师座前，得过一次大乘修心的修验直观教法。”

这位持律大师洛卓伯巴，他是一切智根敦主的所有寺外他方僧伽召集的掌管师，他所教育下的门人，也是很不少的。他在中间有段时期，去到伦波哲从拔峨。云登嘉措大师座前(能海)听受了许多密法教授及其实施法。根敦主大师及持律师洛卓伯巴两位大德对圣教，作出了极大的事业；特别是在后藏，为了弘昌宗喀巴大师教法起见，建立扎什伦布寺等，经历千辛万苦，完成宏大的僧院。所有赡洲诸方人士齐来根敦主大师座前求法受教的，是难数计，以此成其广大而且周遍的事业。

持律师洛卓伯巴他真如谚语所说：“高高仰托风，低低如水流。”那样，他生起舍此世心，如鸟脱网，从贡塘直到大雪山王——岗底斯山，以及喀什米尔的边区——玛区的边境，所有静修地方中，他勤修禅定，以此修力获得能忆知往昔生处等神通。特别是生起了殊胜中观见，能亲见过去印藏许多班智达和大成就师。特别是由于他前生在喀什米尔地方，和宗喀巴大师有师徒因缘，以此对于宗喀巴大师身语净相，何时想见，就能显见。关于持律师前生如何闻法的情况，见于他此生后期所著悟道歌中的一些如下：

“阐明佛教如日光，出生无数大成地，佛所赞地喀什米，其地庄严有善巧。

成就显密教法主，名号玛底坝扎师，彼之无垢莲座前，洛卓伯巴我曾礼。

从师佛语莲舌说，四部戒经之心要，我善闻受依教修，成我现今戒律藏。

复从莲舌说经要，菩萨愿心及大行，由常听受修习力，今得菩萨戒缘份。

集聚诸经秘密旨，成熟密集四灌顶，从师语得种子力，今得密法戒缘份。

族高释迦佛子我，得从庄严玛底师，播来无边见种子，大哉今获解脱道。

思此忆念玛底师，恩德无比今亦念，念师刻中从不弃，生死险处师救我。

但念此义恶众生，大半堕入邪见边，以此乃至如藏隐，此生如日没西山。”

正如师所说的那样，那时，师已明示他将生为“西山王”的儿子。

此师住在玛区的时候，在法王协饶桑波(义为智贤)座前，听受了许多法要；那里的僧众也在持律师前饱餐法味，那里的师徒们请师就在那里长住下去。师说：“我怎能将如母亲一样那边的寺院扔下，而抓著现在这里的寺庙呢？”又师住玛区的时候，还作有悟道歌：

“圣法教王净饭子，第二佛陀慧贤称，师恩念已从生死，再再祈祷拯救我，

佛子大德金刚持，智狮师及根敦主，远在边区忆师座，念师悲钩立导我。”还有：

“智狮弟子根敦主，从师恩德忆念中。”等不少的歌词。

当法王协饶生根示寂时，师说他住在阿里地区，得见非常清楚的梦境，清楚地见到自己和他人的过去和将来的情景等神通妙用。他在阿里住了约六、七年，由于想谒见上师，复返回卫藏地区。他在北部安乐寺住时，著有《中观空量》，后来又著《迦利迦大疏》、《菩提道次第杂作多种》、《玛季所传觉法门》、《大小催动法》，抒情的悟道歌及赞颂也作了很多，齐集起来他的著述有两大卷束。他来到后藏与一切智师徒等相会见，相商很多关于教法的事。后来又在“桑登甘丹”等茅蓬专修约有十年之久。师说：“我修暇满难得这一缘念法门，也修了十八个月的功夫，依照这样，对于菩提道次第所有缘念法门，由久修，而才得定解通达。”

他到六十多岁以后，也就遍游绛称却隆(菩提法寺)、若巴羌、播冻区的隆纳、协迦、播脱、伦波哲、绛清、达纳日喀(黑马山寺)、卓玛顶(度母高地)、药日迦瓦泽(鱼山乐苑寺)、普谟却仲(法城寺)、嘉清哲(帝释峰)、伦坝索、勒宁、扪隆、充达贡色(新寺)、仲哲、扎什伦布等处，广讲《广略菩提道次第》、《大小学处》、《戒品》、《根本罪释》、《事师五十颂释》、《密集生圆二次》、《胜乐生圆二次》、以及“觉”法指教及修观指导等很多教法，对僧俗大众，作了极大饶益。特别是他讲说《菩提道次第》及修观指导次数之多，为他人所难比拟。一切智大师根敦主曾经这样说：“我们整个一生中讲说《毘奈耶》，比不上持律师讲一次学处为有力。”持律大师他亲口说：“有一晚上，梦见正在作‘二五’(即圆根灯会)供养宗喀巴大师供事，在那边见著法王(宗喀巴大师)骑著□牛来到，我作了祈祷。法王说：‘我对阿底峡尊者师徒，是十分敬信的。你也应对阿底峡尊者师徒生深信仰。’从第二天起，我的胸膛原有一种疼痛疾病，也就没有复发。”又说：“在一晚上的梦中，梦见‘种敦巴尊者’对我从头至尾传授了一遍《噶当法函》，这一法函我是可以口诵的。”又说：“现在我是暂减脉息修功而说法，我过去住阿里地区的时候，五、六天的当中，可以不用饮食，是由于有很好的三摩地修力。”又有一天持律师在僧院中说：“我虽曾经到过尼泊尔、喀什米尔、那烂陀等处，那些种种过去时候的故事，行见已经忘掉。”持律师在绛称却隆寺住的时候，曾经说：“由于我明年不在，渴想听法的人，你们今年听法为妙。”他这一段话，有些人传到法王一切智根敦主的耳里。一切智大师说：“他的这类话，是没定准的，他过去也说过七天就要死；以此走了，可是仍然无恙地回来了。这以后他或许可能死，但一直是从平安到平安。”

在卯年的冬季，由于来了一切智大师的指示，持律师也就住在扎什伦布寺中，讲说很多要法。由根敦主及持律师师徒俩所传比丘戒约四十多次。在那时，法王根敦主也作指示，且阿阇黎朗巴也启请法王夏秋两季都来住扎什伦布寺，并禀法王说：“要建筑一间驻锡的静室的。”法王应允说：“很好！”一切智法王根敦主也就一直住到示寂为止。一切智大师在他病体沉重的时候，吩咐说：“去迎请阿阇黎朗巴到这里来。”在以持律师为首率同闻说教法大众，齐绕法王座前时，法王说：“我本想再住一些时间，但现在看来，是要走了。不过没有懊悔的，这是寿命的时间所主。我希求你阿阇黎朗巴依扎什伦布寺，不断地做出利益佛教的事业，我想这样做将能圆满愿心与我的遗志。不须建造身、语、意所依，我的骨骸焚化后造一千不动如来像吧！也叫卓玛到这里来，这小僧三十多岁起就为我作仆役，朗巴你也分给他不亏的一份。”说后也就将钥锁扔给朗巴。阿阇黎朗巴请示说：“对这里寺院，当如何做请赐指示。”一切智大师说：“持律师同你阿阇黎朗巴共同研究如何才好，然后做下去。”临到示寂时，持律师启问一切智大师是否须得提醒一下修要的念头，大师说：“不须。”根敦主大师圆寂后，持律师洛卓伯巴为了完成根敦主的遗志，与及使寺院不衰起见，他对于寺院委派任务等所有事务，都极为关怀。就这样，可以说这位持律大师他对根敦主大师所兴立的寺院，最初苦于立根，中间培育使其不衰，后来大宏事业，以及完成师命乃至委派寺务等，所有恩惠是与一切智大师没有差别的。所有门人施主人众也都对持律师和根敦主两师，是一般无二的尊敬。

在冬季两次法会中，持律师他为有胜慧的六十多位善知识，讲说《五次第直观教导》，讲毕后，他去到乌精城住了一月多的时间中，讲说了不少的教法。继应伦波哲寺的迎请，师去到那里为千百大众，广讲所有显密甚深教法，令听众皆得饱餐法味。在这里持律师略示身体不适的现象，他带病返回扎什伦布寺的夏季法会中，刚到寺他也就住在“黄宫”闭关修法。在那里也请来一位医生诊病，他对医生说：“你对我的病根，如果有办法的话，你就往好的方面作吧！但我没有打算再住的愿望，由于这衰坏的身躯，它没有自性不变坏的理义存在。我从这里将往兜率天宫去，那里兜率宫中宗喀巴大师的座前，有一切智克主杰，及法王协饶生根两师都在那里，我将受生为一天子而闻法，作饶益众生事业。此后复在东印受生，在那里仍由一宗喀巴大师化身的上师来摄受，看来是将由往生道法门，而进入地道诸果。”医生对僧众们说：“大师的病根，虽是能解除的，但是从师的语气看来，简直没有再住下去的愿望，以此难有愈病的妙法，修法禳解或许能有好转。”到了二十三的那一天，由侍膳长卓玛作供僧众茶饮的施主，请僧众齐集佛殿依药师仪轨修法。这件事被持律师知道后，对医生斥责说：“是你对我作损害，本来我对今明两天的选择中，我是选择今天的。”二十五的那天，大师将自己所用资具中，有加持的两疋毛布，及经书四十卷束，供献给大殿僧众。二十六的那天桑脱岭僧院，在一晚间茶饮的当中，来师前叙谈请问修法禳解事宜。师说：“对我本来不必修法禳解，现在这样办吧！念诵‘具德三时颂’，向宗大师祈祷吧！”也就在二十八的那天，天将黎明时，往生兜率弥勒内院绛伯岭波(妙吉祥藏)的座前。那时，发现虹霓等许多稀有瑞相。

意乐修菩提道次第的人们，应当谨向一切智根敦主，及持律师两师徒，虔诚祈祷求加持，并当效法两位大师清净行传，由持戒和宗见清净纯洁之门，见一切经教皆教授，取而励行勤修。
