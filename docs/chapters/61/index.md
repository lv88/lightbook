# 六十一、喀垛堪布索巴嘉措的历史

珠康大师。格勒嘉措的得意弟子喀垛堪布。索巴嘉措(义为喀垛寺方丈名忍海)，在壬子年(公元一七三二年，清雍正十年)生于拉萨地方，父亲是一持密咒人，名昂旺楚称(义为语自在戒)，母名阿杰吉吉(义为乐姑)，父母给他取名叫协饶嘉措(义为智海)。这位大德由于夙世熏修的习气，以及父母都随顺佛法的原因，他刚一会说话，就能诵六字大明咒，并会念诵各种诸行及文字读本；发现他不作十恶业，作礼佛绕塔等净行，身、语、意都合乎善行。他到六、七岁的时候，心中有所感觉，生起俗家如牢狱的想法，刹那也不想住下去，常时总想或在色拉、或在哲蚌寺中去住，很好地修学正法。他在父母前，请求满他这种愿望的时候，由于父母都是随顺正法行者，所以不作阻难，应允满其所愿，并助以入佛门的顺缘。他也就在年满十三岁的那年，去到色拉寺大乘洲，加入色拉上院克芒扎仓(义为多善巧僧院)中，在上院阿阇黎绛称敦珠(义为法幢义成)座前，受得沙弥戒，取名叫索巴嘉措。当年他就将各种法行熟记心中。十四岁时求学于学法院，最初加入初学加行班次，学辨色启智之学。他不须他人来鼓励，自己能孜孜勤学，不久也就将加行诸学学好，进而学习波罗蜜多教典(指现观庄严论)。他将班禅却季绛称所著有关波罗蜜多书籍，都熟记心中，昼夜不断地精进钻研，经三年时间，他已成为善巧波罗蜜多教典者；并对于业果，趣入地道诸果情况等《现观庄严论》中要义的修法，获得决定胜解，生起了极猛烈的一心静修的愿望。他在老师及诸学友前，讨论他的心得和一些余义时，谁也不勉励他去修行，都一致同声地对他说暂时不能去专修的道理。这位大德，他是如良马加鞭，一意驰向修的方面，而不再用鞭策。

他认为依照他们所说的那样，那么，只此一次获得暇满人身的这段时期中，如果不毅然决然地去修行，也就死去，岂不空过如此暇满人身。同时他生起了这样的强烈思想和愿望——他想自己也没有肯定的把握说今天不死的话，以此应当立即修行。原来他常想加入学僧院中，渐次学完《现观庄严论》后，继即学习《中观》诸经论，到了能了解中观见的时候，才很好地去修行。这下他念想到“死来无定期”，以及贪恋此世的人们所有言行，都成了助缘，他也就无暇去学习中论诸经论。当他听得色拉哲，宗喀巴大师曾在那儿修行的“珠康”茅蓬，驻有一贤善的喇嘛的消息，油然感动得来身毛竖立，生起难以言喻的极大敬信！心想我当去到那位喇嘛的座前，毕生专修。并猛勇地发誓求空行护法作证，我决如此作。于是他去到色拉上院中上师座前，悲泪地详细说明原因，再三请假。

也就在年满十七岁的时候，去到色拉哲拜谒珠康大师。他如像密勒日巴启请玛尔巴译师那样，对珠康大师，他身、语、意虔诚供养，而祈求摄受他毕生勤修宗喀巴大师之教要——菩提道次第。珠康大师也十分欢喜地允如所请。对他详细地传授了三世诸佛所趣唯一大道，摄八万四千法门教义，而为一补特伽罗修行之次第——《菩提道次第导修讲授》。他复很好地听受了作为修行经验教授，关于上士道法门，修学大乘发心教授，为阿底峡尊者之耳传法流，佛子妙善吉祥作出如摄颂那样的讲授——《修心七义论讲授》；及为菩提道次第除障增益法门——《“觉”法讲授》；及观世音菩萨摄显密二道之要，传授与大成就者弥扎大师，亦即《圣教三要教授》等教授。他年满二十岁时，仍在过去受沙弥戒的戒师色拉上院上师绛称敦珠前，请求传授了比丘戒。他遵照珠康大师之命，在色拉哲新建一所能容自修的小屋。计从十九岁起，至二十三岁之间，一共五年的当中，他摒绝内外纷扰，过著苦行生活，一心勤修菩提道次第法门，以及除障增益《觉法观修法门》，修心证验法门等。以此获得从依止善知识法门起，直至止观之间，整个圆满道体的有功用的很好修悟。此后，他为了使修行更能增益起见，凡宗喀巴大师及八大弟子在何处见法证真，获得殊胜成就的地方，如阿喀等处，他都去到那里住下静修。最初去到闻地的静修窟中，住修一年，对于所修善法，得到很大的进益，并在那儿亲见六臂明王得到教诲。

从当时起，这位大德的功德，就受到许多人士的敬仰，不少具足净信的弟子，随在何处，净信弟子们启请传法，他随各自根机向他们传授合机的正法。这位大德常时是如瑜伽自在师密勒日巴那样独自住在寂静的地方，有时采用石子辟谷法，有时采用花英辟谷法，有时采用泉水辟谷法；平常食用只少许糌粑，仅不断榖食而已，或一些粥汤即能自足，不复贪多。他谨持圣者四智、沙门四法，在阿喀却隆等宗喀巴大师修行胜地，发愤勤修。继后，又在却柯嘉诸胜地，及扎日(大雪山)诸胜地，精勤静修，以此他所修善法，获得很大进益，并且发现许多清净的证境。继在返寺的当中，又在耶巴区拉日岭波及彭裕地区噶当派古德修行诸胜地，特别是在热振寺都作过长久时间的精修。他在各地方，复亲近许多善知识，听受了不少的灌顶、经教诵授、教授秘诀等法要。后来，回到喀垛，运用“镇伏三观法门”，使当地山神地祇都前来许誓发愿为护法，并预示将来当地渐次形成精修院的缘起。此后，他善行益增，为了教诲一些具缘善信众生起见，他去到江区，在温萨巴大师师徒获得修证的处所——温贡寺，及香多区的葛昌等处住下来学修温萨巴师徒史事德行；并在仲巴大师师徒中得意传徒喇嘛准珠嘉措(义为精进海)前听受《上师供养讲授》等许多温萨耳传教授。他复到扎什伦布寺拜谒班禅洛桑耶喜，继到纳塘、扛金、措普及佛子妥默让波伯(义为无著贤祥)静修胜地欧曲却仲等处朝礼，并暂结住缘。继到达纳地区，朝礼廓译师修行胜地，及大成就者却季多杰(法金刚大师)降生地，与达赖根敦嘉措(僧海)降生地，暨仲巴。达普巴大师驻锡地达普多杰古康(金刚帐室)等处，并在这些处所静修，以此所修善法，获得很大的进益。特别是在达普地方，他对那里的许多具信坐山修行者，传授了菩提道次第及修心法门等许多法要。并应达普坐山静修人们的请求，为仲巴。达普巴大师撰有一略传。

此后，他回到前藏，来到色拉哲在珠康大师前，恭养承事，使师大生欢喜，在师前听受许多显密法要。他间或为一些从色拉寺前来请他传法的具信人们，传授一些灌顶、经教诵授、讲授等法要。此后，喀垛精修院已经建成，他也就迁往喀垛去驻锡。他的德行声誉，已传遍于各方。他对十方前来求法的善信大众，广传灌顶，经教诵授、教授秘诀等法。他为了圣教的事业，在喀垛精修院中，新建许多关房及不少的佛殿；并刻菩提道次第导修指授一切智所趣之坦途资粮田，依教授口诀画出的图板；又刻以宗喀巴大师为道之主尊，符合导修讲授的资粮田诸尊肖像图板；复新刻甘丹四尊等许多本尊佛像图板；及许多曼陀罗与经论印板。他对具信的在俗人们也作了不少的饶益事业。他为了使圣教常住起见，著作有他的《自传》、《取舍除暗篇》、《上师瑜伽讲授》、《上师瑜伽讲授补充》、《颇章喀目录》、《菩提道次第坦途口授补遗》、《金刚萨埵法门讲授》、《依法王宗喀巴大师而修之上师瑜伽》、《喀垛寺禅定洲目录》、《花英辟谷教授》、《常用“觉”法心要》、《十处仪轨》、《常用荟供心要》、《能怖金刚修行篇》、《金刚萨埵净瓶修法》、《歌颂汇编》、《菩提道次第加行思义显明经教日》、《菩提道次第坦途胜观补遗》、《格勒嘉措大师传》、《贡德格西传》，及一些零散著作《请住世祈祷文》等。

这位大德就这样作了广大的弘法利生事业，完成了他此生应化众生大事，也就示现圆寂，往生兜率内院。
