# 结尾发愿回向颂文及著本论缘由

完结颂说：

“诸佛菩萨一致说，虚空十方世界中，一切有情利乐源，皆依圣教而生起。

利乐生源佛教法，全圆无倒菩提道，一切佛法道次摄，二大车轨所说故。

以此何时能入住，菩提道次说修时，应说尔时佛法住，如是衰失无佛法。

犹如无执舵桨者，舟不趣向到彼岸，若无宣道善知识，则失妙道宏教机。

若无日出无白昼，无有大地无禾稼，无有海藏无珍宝，无示道师则无道。

如诸林木与花草，得住地上从地生，增上解脱诸功德，皆依示道师生起。

宣说正道善知识，增上解脱妙道眼，一切胜共悉地基，诸佛菩萨所赞叹。

由见此理故我作，宣示无倒善妙道，所有本传诸上师，师师相承斯传记。

自从轮回无始来，由惑业力取此身，所作任何世间业，皆归废业无义事。

现为增益圣教故，不惮疲劳我撰作，如是师师相承传，使此人身义不空。

无始以来轮回中，所有此心及心所，莫不奔驰于邪途，常时自我作毁灭。

现以鹅王分别智，观阅诸佛及佛子，贤善事业诸功德，智亦灿烂具大义。

无始以来由惑业，于秽精血和合中，幻轮所造此肉骨，所作皆归毁自他。

今以精血中净质，取色眼根常阅读，师师相承净行传，成嘉言故眼具义。

无始以来纵千舌，说亦皆归三毒中，由不善言度昼夜，常作自他皆毁灭。

现宣众生之明灯，佛及佛子渐次出，所有事业妙行传，以此舌亦具大义。

三派承传诸上师，贤善事业净行传，虽由我编广作赞，少分功德亦难宣。

犹如以管窥天界，以蠡测量大海水，我赞佛及菩萨等，此亦如是念善作。

三派诸师之功德，如空及海深莫测，由我智弱不明故，有过我向师前忏。

如童乱呼父母名，虽呼亦作为稀有，如我昏庸赞佛德，及佛子德亦稀有。

净智善巧及证达，修要诸师若毁污，虽生犹死遗臭故，不作正士所斥业。

恶慧嫉魔所乱众，虽斥如是所作业，彼之自性无实故，对彼有谁作计较。

此如壁上画佛像，虽由童戏所绘作，由见佛像亦具义，能增福故佛所赞。

佛及菩萨诸事业，我以信心略作赞，亦思具义增福德，故我不惮劳著述。

勤此事业所获善，愿回妙道唯一目，菩提道次斯教授，长明不灭普弘昌。

直至陆海未解体，世灯未断双存间，愿此嘉言师行赞，成众视察妙道灯。

愿我从今一切生，得胜乘师作摄受，能入全圆无颠倒，菩提道次修心要。

愿由三派师加持，获得三藏义定解，三学修行达究竟，速证圆满三身位。

愿慧贤佛金刚持，此法求者尽施与，三士道中诸护法，常助修此法要者。

愿梵释及四天王，所有护善诸护法，对此胜法常护助，善乐普遍诸世间。”

这一《菩提道次第师师相承传——圣教殊胜庄严宝鬘》，过去曾由很多善知识策动我撰作，又经修此胜法的比丘昂旺敦真(义为语自在持教)，再再殷勤劝我作详广的“坦途”与“语教”两系承传诸师的行传。又我的近侍比丘耶喜桑敦(义为智禅)，也劝我作一《宗喀巴大师详传》。以及阐明圣教的善知识妥默(义为无著)的史事，复再三劝请我作《怙主慈氏上师的广传》。特别是最近，雪域众生怙主一切智达赖至尊洛桑敦比旺秋绛伯嘉措(义为善慧教王妙吉祥海，即第八世达赖喇嘛。著者耶喜绛称即这一达赖喇嘛的上师)大师，对我发来上谕说：“为了使圣教心要增长起见，无论如何须得著作一部从导师释迦能仁王佛起，直至现在住世的根本上师之间，所有菩提道次第师师相承全圆无缺的广传。”恭敬受命之余，从亲教师班禅一切智至尊洛桑耶喜(因事称师名)恩德中，身入佛门而出家，获得研习大车轨诸经论的善缘者，复从依温萨耳传获得最高成就果位离世修行自在大师至尊上师洛桑朗嘉，及住持全圆圣教之主至尊昂旺绛巴两位大师的恩德中，获得《菩提道次第教授》的比丘耶喜绛称(义为智幢)于第十三甲子——丁未年(公元一七八七年，清乾隆二十五年)，在布达拉宫中编著。

愿由此善使圣教一切法门，于诸方隅弘扬光大，长久住世。

唯愿利乐！

“贤劫虽出有多佛，浊世无怙诸众生，较他佛陀悲心胜，释迦王佛我敬礼。

无等导师能仁王，观察众生之身心，及习随眠与根器，而示八万四千法。

一切佛经心要义，为一善缘修次中，一切善集全圆法，即此菩提道次第。

广大刹中一切佛，绍继胜乘善知识，宣说菩提道次第，印藏诸师前敬礼。

如满众愿如意宝，三士妙道作阐扬，一切上师稀有业，得显空前此善著。

雪域众生之怙主，至尊慧贤曼殊海，由悯中边诸众生，增益法施此法流。

愿由励此诸时中，所获净善皆回向，全圆无倒菩提道，遍于诸方得弘昌。”

圆满吉祥！
