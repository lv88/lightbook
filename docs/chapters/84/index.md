# 八十四、善知识朴穷瓦。迅路绛称的历史

这位善知识是在辛未年(公元一○九一年，宋元祐六年)诞生在彭裕地方中嘉区的吉热正喀村中。由于他多生薰修佛道的习染，以此他从儿童时代，就自然生起无常觉悟，而对世间一切荣华受用全不贪恋，意乐身入佛门，纯洁地修学正法。于是逃出家中前往嘉区的寺中，在香大师，及伦楚绛两师前，出家为僧，取名叫迅路绛称(义为童幢)。此后，他严守戒律，如护眼珠，并想效法过去先德的清净行传，精勤闻、思、修三业。于是在大善巧库敦师前，听受《般若》约十五次，多闻很多经教。他听受《毘奈耶》后，也做了彻底的研习。在业塘地区，他和阿底峡尊者见面，在尊者前，也听受了一些教法。阿底峡尊者示寂后，他也就前往热振为种尊者作服役侍者，听受了完整的教授，发心修行。他承种尊者的面命，也培育徒众。在种尊者座前，新来求学的诸比丘，种尊者每命他教授他们《毘奈耶》学处，因此他也就讲授《毘奈耶》的诸种实践方法。他依止种尊者十一年之久，心中完全获得尊者的一切功德。种尊者示寂后，他全无此生的牵挂纠缠，心中生起住寂静地彻底精修显密全圆道体的意乐。他这样说：“我朴穷瓦愿生也生在寂静山林中，死也死在寂静山林中，独尝整个腔肉那般专事修行。”于是前往彭裕地区的朴朴穷寂静处，修筑了一间修屋，一心精修。那时，修屋的西面岩石上，还有运用神变，以手指插穿的穴中，涌出的泉水。

这位大师对前来求学的徒众，主要是讲授《十二因缘法》；传《道次第》也配合在《十二因缘法》中而教授。这位大师他如伤兽般，极怕喧嚣惊扰，以此除三昆仲相聚会时前来会中外，经常不在会中，独自住在异常寂静的处所中，但是他的芬芳德行，仍然遍布于一切方隅。其余两昆仲的弟子，大都没有不在他座前听受教法的。慬哦大师圆寂后，嘉裕瓦前来朴穷瓦那里听受《十二因缘法》时，芒热大师说：“现在朴穷瓦那里，以声闻的神变力，正在成熟一位菩提萨埵(指嘉裕瓦)。”后由嘉裕瓦承传的《朴穷瓦十二因缘法讲授修法》，得到极大的弘扬。善知识朴穷瓦是以常供三宝作为主要修行的，以此他的修屋外面，供香的香气，经常芳香不散。他说：“我最初只能供辛辣刺鼻的粗劣草香，继能供四种香料合制的香气扑鼻的线香，而今我能供用极贵的沉香及安息香等香料合制的香气馥浓的极品上香。”据说有一次他配制香料的价值，就值二十二两黄金。又朴穷瓦说：“我现在对‘皈依’修力串熟的时候，在病中疼痛时，不禁呼出三宝来替代呻吟，不料佛尊等也就随呼声而来临。”又有一次据说他用皮条覆在头上，也就见著嘉寺区无数的亡魂。又有一次朴穷瓦同康垄巴相晤面时，康垄巴说：“听说善知识唯说业果为极要。我想现在不计说、闻、思、修三业，唯修这一业果法门为最难。”以此朴穷瓦答道：“正如你说的那样。”又朴穷瓦说：“我在这年老时，结合口头说法，也不离《贤愚因缘经》。”他又说：“我们应当诵出的是善句，驱出的是不善事。”

又有一次朴穷瓦大师在半夜时，发出悲叹声。问他有什么不幸呢？他说：“我今天阅读经著中，见有末劫时，声闻如砂袋倒栽在地上而行走的说法，我想也有我在其中，不作高不可攀的法，将是如贪馋香谷粒那样(言合多数口味，易起修欲)。”他又说：“对于行法，应知，应解，应用，复应生起极大毅力而作。虽是应当改变地方习俗而作，但也应当自他相换，或不同流合污世间法而作。应当接受毁谤恶语，应当将心比己作为心印。”又有一次朴穷瓦呼出善知识侠峨岗巴的名讳而说：“阿底峡徒！不晓‘死’——它将人尸如粪肥那样送走的这点，任用所有一切世间法来观诸法的真实，此心是难以置信的。对于这一说法，忽视的人是有很多的啊！”又说：“侠峨岗巴，我今天在你面前要听你说一法门。你说特谟塘那里所烧诸尸吧！”侠峨岗巴说：“那边正如所说，在作焚烧等事。”朴穷瓦说：“既是那边正如所说，在做焚烧等事。以此应知这是给杂合烦恼活动的人，能活动的皮囊人，整块肉蹄者们，留下的法门。”侠峨岗巴说：“比起这一知晓者来说，尽管智中还有上智，比起智者来说，尽管多中还有更多的。”有一次他说：“多修死无常和业果吧！哪怕犯了四他胜罪，也能净治的。这是我的遗嘱。”又说：“自对何人不喜悦，等于对他者完全压迫。”这一说是菩萨学处的内涵。

三昆仲齐集在种敦巴尊者座前，直至种敦巴尊者示寂之间，虽是未曾分离，但完全拥有阿底峡师徒秘法者，虽非朴穷瓦一人，但种敦巴尊者对他也这样赞说：“戒炽大宝光明耀，以宝光耀庄严戒，持我传行勿陨灭。童幢与我无二别，大悲隐护常爱子，诸世间中此幢遍，诸莲丛中此童严。”又说：“座前为僧无有谁，不来作徒亦无谁，住持一切无住刹，众中人王咸敬供，愿我童幢常尊胜。”
