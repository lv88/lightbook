# 叙噶当师徒获得《幻化卷帙》史事  叙《十六心滴教授》、《噶当幻化卷帙》传授简史

阿底峡尊者师徒二人住在耶巴神山间时，相谈一切显密经论的要义——《菩提道次第》中的诸要扼时，所有三系承传诸师都齐来到，而现身相会。怙主观世音及救度母等本尊，也都真实现身。那时，由金洲大师说出：“对于《菩提道次第》的心要，及命脉和道之根本——‘菩提心’，未生者令生，生已令其辗转增上，与修行到究竟，都必须依止大悲本尊——怙主观世音，而虔诚祈祷。”并且也就说出如怙主观世音身像庄严，不可思议十六心滴教授中，所说的一切情况。至尊救度母也详细说出了忆念一切经论等皈依处上师；忆念自身即本尊；忆念诵言；忆念众生为父母；忆念真实空性等五种忆念摄要修法。这些也就是《十六心滴教授》的修法。继即由阿底峡尊者说出种敦巴尊者往生事纪，并略说其不可思议的诸种化现庄严。同时对种敦巴尊者说，你是西藏怙主大悲观世音，以此不必过分隐秘，为利后世应化众生起见，当略为示说。这样劝动的时候，种尊者也就消去他所示现的凡俗身相，立即现起大悲观世音诸佛海会，能依所依等曼陀罗，而演说《十六心滴甚深教授》等法。这也不仅是为阿底峡师徒所说，也是显密经中所说的教授，这与《宝箧庄严经》中所示十六滴曼陀罗相似。经中示说大悲观世音身相一一毛孔中，都有无量佛刹等说法。如像这样的还有密集大咒等，及耶喜师传的密集根本教授——《妙音语教》，及这一教授的修法普贤，与及《解脱心滴本释》等中，所示说的十六心滴诸修要等。关于这些详细的情况，我(著者耶喜绛称)另有论著写出。这样的心滴曼陀罗甚深教授，深信根源严净，加持极大。

这一法门由阿底峡尊者师徒二人传授给善知识桑朴瓦，这位善知识桑朴瓦名叫峨·勒比协饶(义为善智)。他从无量劫，积广大福德资粮，特别是发宏愿住持阿底峡师徒的秘密法藏，并为至尊文殊亲作加持，以此他无碍通达一切所知境。这样的大德他在桑普为五百僧众，广讲一切经论的时候，由至尊文殊的策动，他舍弃此生的一切喧杂扰乱。带著一个随从来到耶巴神山间阿底峡师徒座前，供上有一箭直径大的银曼遮，上面以螺布设堆聚等无量珍物，供而再再地请求开示种尊者往生事纪，及《十六心滴教授》。他对于所开示的一切教授，完全记持胸中，同时至尊圣文殊教授，完全化现为字迹的《噶当幻化卷帙》，他也获得到手。此后峨·勒比协饶大师也就回到桑朴，在《噶当幻化卷帙》前，作无量供养，常勤祈祷。

以此有一时中，由至尊文殊的劝动，名叫阿里瓦。协饶绛称(义为智幢)的一位大菩萨在桑朴山林中静修的时候，桑朴瓦。勒比协饶亲自前往他的静修处，对他略说一些关于《十六心滴教授》的史事。这位菩萨协饶绛称，当即请求无论如何传授这样的甚深教授时，桑朴大师也当即允传，并指示在观世音曼陀罗前，必须准备充分的供事因缘。大菩萨协饶绛称当即将自己所有资具全作供事因缘。在这之上，又由桑朴大师复赐他很多资具，这样布置起了十六心滴曼陀罗，连同修伴比丘四人，经三十天之久，才将《十六心滴教授》全部传授完毕。最后复将《噶当幻化卷帙》也赐授给他，嘱严持法传。此后，大菩萨协饶绛称在罕无人迹的寂静处，数数勤修此法，获证殊胜通达后，他去到善知识朴穷瓦那里的时候，朴穷瓦由神通得知他拥有《十六心滴教授》，也就请求他传授。大菩萨协饶绛称当即允传，并说这一深法必须在观世音曼陀罗中，供养供物的时候，朴穷瓦祷毘沙门天王做这一事业助成者，立即无碍地成办了所有一切供物来陈设曼陀罗。由于他们两位都是舍离一切而专修者，以此找不出其他助修的人来时，朴穷瓦祈祷圣十六尊者，而获得十六尊者来作助修者。于是大菩萨协饶绛称住十六心滴曼陀罗中而为灌顶，及传所有教授。经四十八日之久，才全部传完。最后，也将《噶当幻化卷帙》授与善知识朴穷瓦后，大菩萨协饶绛称也就立即收摄身相，化为虹身而逝。

朴穷瓦得法后，也就在寂静处，数数精修，证得双运身位后，他去到大菩萨仁清绛称(义为宝幢)的那里。这位菩萨也就请求朴穷瓦传授他《十六心滴教授》时，朴穷瓦说：“这一教授在大悲曼陀罗中，须得一些供物，你自己可以去乞化一些来，我也帮助你去寻找一些。”朴穷瓦于是去到热振等处，寻找到各种食物及各种药物；菩萨仁清绛称乞化到所有资具。一切全备时，朴穷瓦每日传一心滴灌顶，经十六日将十六心滴灌顶圆满传完；所有教授则历时六个月之久，才宣说完毕，以成熟受法者的身心，而令获得解脱。那时，朴穷瓦大师为了使噶当这一法要，在雪域西藏，不致湮没而得到弘扬起见，也就将这一噶当具七尊法的心滴教授是如何而来，如启开秘藏那样笔录出来。就这样朴穷瓦大师将《噶当心滴教授》完全传与菩萨仁清绛称后，也将《幻化卷帙》交付给他，朴穷瓦大师也就化为虹身而逝。

此后菩萨仁清绛称，也就前往卫、藏、阿里、尼泊尔等地的很多寂静处，一心专修，证得殊胜通达后，他前往热振，他预知那里有一少年僧人名叫香敦。达玛绛称(义为盛幢)，将来将成为这一教授的法主，以此摄受了这一少年僧。由格西多迦瓦为他成办了各种资具及供物后，也就在热振迦里玛殿中，绘画十六心滴广大曼陀罗，得到阿底峡师徒现身来临，为作助修。经一个月零两天的时间，传完十六心滴详广灌顶。继此达玛绛称在师前，依止服侍十二年之久，在很多寂静处，才将十六心滴教授完全传授毕，最后也将《噶当幻化卷帙》赐他，加持香敦。达玛绛称为这一法门之主。此后，香敦。达玛绛称在很多寂静处所，一心精修，证得殊胜通达后，他也就摄受多迦瓦。绛秋桑波(义为菩提贤)。绛秋桑波在香敦。达玛绛称前，请求传授《十六心滴教授》。达玛绛称允传后，也就筹备各种供物及资具，筹备齐全时，他们前往种尊者诞生地普仁。经十六天之久，才将《十六心滴灌顶》传完，继前往热振，经一个月时间，将心滴近修法作毕。此后，依止达玛绛称九年之久，才将所有教授完全听受完毕。继此，阿阇黎绛秋桑波也就精修《十六心滴教授》，证得殊胜通达后，他复摄受多迦瓦。朗喀仁清(义为虚空宝)。朗喀仁清在阿阇黎绛秋桑波座前，请求传授这一噶当要法心滴教授时，得到允传，并说须备供物。答师随即寻求，直到将一切供物都找齐全时，经十六天传完《十六心滴教授灌顶》，继前往很多寂静处所，才将所有教授完全传授竣事。与师从不离开依止了二十四年之久，听受了噶当派所有全部教授。

在这以前，这一法传，都是单传(一师传一徒)。到此阶段，阿阇黎绛秋桑波命多迦瓦。朗喀仁清，以后对这一教授略为广传。于是由阿阇黎朗喀仁清广弘出如大宝珠鬘般的菩萨大众。并对很多勤求法义诸人，也宣说《噶当幻化卷帙》。将《十六心滴教授》授与种。姑玛罗玛底，齐备一切供物资具后，经十二日，传完十六心滴灌顶，也将《噶当幻化卷帙》完全向他宣说，命他牢记心中。种。姑玛罗玛底将全部《噶当幻化卷帙》一句不遗，牢记心中，作为常持念诵。据说阿阇黎朗喀仁清也就将《噶当幻化卷帙》装入“多迦塔”中。此后，种。姑玛罗玛底前往纳塘广弘《噶当幻化卷帙》。纳塘大堪布利玛绛称(义为日幢)，将姑玛罗玛底大师口中所说出的一点不差地录之于笔，刊行出《噶当卷帙》本问世。这一刊行本遍布于各方，以此到现在能得到阅读《噶当卷帙》的机会，这是由种。姑玛罗玛底将全部《噶当卷帙》牢记心中的恩惠而来的。此后，渐次传到一切智根敦主，及达赖根敦嘉措两位大师手中，由这两师大弘这一法门。渐传至班禅洛桑却季绛称，及达赖昂旺洛桑嘉措两位大师，复得到弘扬。据我(著者自称)的上师说：“达赖昂旺洛桑嘉措，亲得种尊者为他现身，传授他《十六心滴灌顶及教授》。”后期中，我(著者自称)的具恩根本上师至尊昂旺绛巴大师，住持这一心滴教授灌顶及教授，使不致湮没，除为一些求法义者传授外，未见广作传授。在这位恩师座前，由我(著者自称)求得这一《十六心滴灌顶及教授》。由于我(著者自称)想到阿底峡师徒秘法——噶当具七尊法心中心要的《十六心滴教授》这一法门不致湮没，长久住世起见。以此我(著者自称)著有《十六心滴教授师师相承传》，及关于这一法门的曼陀罗仪轨摄受弟子法等详细的论述，命名为《噶当显扬论》。另外著有下智诸人念诵这一法门仪轨等法，及这一教授如何修法的讲释，与对噶当具七尊法的史事发愿颂文及这一教授具体支分等详述。

意乐修行菩提道次第的人们，应当谨向广行承传诸师，及深观承传诸师，与修行加持承传诸师祈祷求加持，并不应偏向道之一分，而应对显密完整道体，作为修要。最低限度也应当对全圆道体，作为发愿修行的对境，而努力薰习。
