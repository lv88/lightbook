# 四十九、坝索·却季绛称大师的历史

“辨别广大正法义，智者众中如幢严，龙树第二说法王，贤名师前我启请。”

值得这样赞颂的住持耳传教授藏的坝索·却季绛称(义为法幢)大师，在壬午年(公元一四○二年，明建文四年)降生于藏北垛雄地方，父名扎喜伯让(义为吉祥贤)，为藏北的贵族，母名布正嘉谟。幼年时代即厌离俗家烦扰，而进入佛门，出家后即在宗喀巴及克主杰两师徒座前，亲近承事，听受很多正法教义。特别是他依止兄长克主杰为师，学习总摄三藏四续部的经论，成为一位究竟善巧者。继此他想到应当就多闻的教义，了知它都是修行的教授，进而对于整个显密圆满要道，修行心要。于是他在一切智克主杰座前，听受了菩提道次第修学讲义及密集、胜乐、能怖三法等无上瑜伽灌顶及生圆二次讲义等法。从此他内心深得宗喀巴及克主杰两师徒的慈恩与加持力。他依至尊文殊菩萨的记别，在大成就上师绛伯嘉措座前，听受了菩提道次第耳传教授心得等，以及密集、胜乐、能怖三法的修学教授心得等，还有甚深道“觉”(施身断执法)修法教授心得；特别是文殊菩萨亲传宗喀巴大师的耳传教授，圆满深道，从上师即佛瑜伽之门起修，就浊世一生即能成就双运身佛果的密中极密，无上方便，他完全获得听授。复得到大成就上师绛伯嘉措依至尊文殊菩萨记别，将整个噶当耳传教授，最后传赐的《幻现宝笈》也都赐给了他，暂时单传后，也就密封起来。继后，却季绛称大师在桑朴寺为听众讲了一些法要。此后，他想著未来的一切意义，于是去到后藏，住持坝索。吞朱德清寺，一心以修行为主，有时也为其他具缘有情传赐正法甘露，以此都称他为坝索法王的美名，于是大著。继后他复在其他很多寂静地方驻锡，仍以专修为主，有时为不少具缘听众，讲授正法，并在接近肖堆生格哲地方，建立一座寺院名日窝德清(大乐山寺)，他也就驻锡这一寺中，以修为主，并为那里的很多听众随其根器赐正法甘露。

此后，大德却季绛称为猛利出离心激动，想到现在我既已获得贤善人身，在这值遇著仅一次获得的真佛住世也是除此外没有他说，觅之任何佛土也难获得的至尊上师宗喀巴的耳传显密甚深教授的这一时期，我当远离无义利的此生事务，而去到谁也显见不到的地方，如喀什米尔分区舍谟垛或南方吉祥山等特殊寂静地，修行到究竟地步，如大德霞惹瓦那样的人物。他内心生起了这样强有力的思想，刚开始依著思想去作的时候，在梦中见宗喀巴大师来到他的前面鼓励他说：“你当继承甘丹大寺祖座。”又金刚瑜伽也为他授记说：“你住持甘丹祖座的期间，将会造就出能住持宗喀巴大师耳传教授的人士。”当时，为法王洛卓却炯(义为智法护)住持甘丹祖座，他渴欲离开诸务，须得寻求堪能承继祖座的人物，那时后藏扎什伦布寺一切智根敦主巴(义为僧成)的弘法利生事业，如夏季海水那样的盛溢，以此甘丹墀巴法王洛卓却炯为首率同甘丹大多数的大喇嘛前来请求根敦主大师登甘丹祖座，补处第二佛陀宗喀巴的宝座。大德根敦主对他们说：“我须得在杂瑜地方，建筑杂喀堡屋，也就在那一期中，住持至尊宗喀巴大师教法。现在克主杰的兄弟坝索·却季绛称的教证功德，任何一方面都胜超他者，以此迎请他去承继甘丹祖座，将是最好的。”根敦主对他们作这样的记别后，他们也就依照根敦主的记别，法王洛卓却炯等人都去到肖堆迎请坝索法王却季绛称。当坝索法王应请来到扎什伦布与一切智根敦主会面的时候，根敦主对坝索法王说：“现在你已是接受至尊宗喀巴祖座的大德，我向你顶礼，请你不必还礼。”于是一切智根敦主同他的徒众等都向坝索法王却季绛称恭敬礼拜。渐次在第七甲子癸未年，来到了甘丹尊胜洲寺，接受了第二佛陀(宗喀巴)补处之位。随即住持了文殊宗喀巴上师的法统。而为无数具缘众生传授出家戒、比丘戒，以及灌顶、传经、教授等。特别大转三世诸佛所趣唯一大道，二大车轨，即文殊宗喀巴上师心髓教授——“菩提道次第”法轮。由此法传，培养出了许多著名的大班智达、法王遍于大地之上。

坝索法王，他是一位获得教证不可思议功德，特别获得比他人大的至尊宗喀巴耳传教授加持的大德。勒宁夏仲。恭嘎邓勒(义为庆喜福善)曾经说：“我确有不以为自己生在勒宁种姓而骄傲，而是以自己为坝索法王的弟子而骄傲的心。”细味这种说法，不难知道坝索法王，确是一位具有一切使人见闻、忆念都能获得他的摄受加持的大宝藏大德。他的事业功绩中，在紧靠甘丹大寺的香洁殿中建造了用诸宝铸造出甚为稀有的狮子吼佛像，以及甘丹寺前代诸座主的身像，并由财法二施之门，使甘丹尊胜洲寺弘扬光大起来。特别是他遵依至尊文殊菩萨所记别，对于如大宝根器的人，秘密传授了耳传教授法要，以此培养出获得双运身成就的三昆仲弟子，即大成就师却季多杰(义为法金刚)、堆隆巴。伯敦多杰(义为吉祥金刚)、康巴。多杰伯瓦(义为金刚吉祥)等三人。他们三人，是著名的依文殊宗喀巴大师的教法，一生即身修成虹霓身的金刚弟子三昆仲。对于意乐随学文殊宗喀巴大师的一切人们来说，应当知道关系于受化人自己做到实修的话，宗喀巴教法中，确有这种能够获得殊胜成就的方便，他们三人成为生起决定信念的实证。成就双运身位的金刚三昆仲中，康巴。多杰伯瓦(金刚吉祥)，不管是当他最初在班钦。却季嘉补(义为法王)座前，听受耳传教授的时候，以及他驻锡格迫的时候，和后来他会合金刚三昆仲的时候，似乎住在普通凡夫不易看见之一修行胜地，而有勇士空行围绕的当中，有时或去到其他清净刹土。不管是怎样，总之，这位大成就者对于此间西藏，没有获得他显著的教法恩赐。至于堆隆巴。伯敦多杰(义为吉祥金刚)，他仅是对于一二具缘有情，传授了教授甘露。达赖根敦嘉措(僧海)也曾在这位获得双运身成就的勇士座前，获得他的法传恩赐。此外其他一些人士也会见过这位大德和听受过他法语教诲。三昆仲中的大成就师却季多杰(义为法金刚)，他遵依至尊妙吉祥与金刚瑜伽母的记别，他成为住持整个耳传圆满教授的《幻现宝笈》之主。这位大德的净行史事，在下文即将述说。

大德却季绛称在他圆满度化事业的时候，他观见自己的死征，他也就请法王洛卓敦巴(义为智坚)住持甘丹祖座，而自己摆脱一切事务，一心专修中，于癸巳年(公元一四七三年，明成化九年)底，享寿七十二岁时，示现圆寂，往生兜率法院弥勒妙吉祥藏座前。至尊坝索法王为饶益后世众生，他著作有《时轮生圆二次第讲义》、《中观见广义指授》、《能怖金刚生圆二次第讲义指授》、《三种心要讲授》等论著。

由于大德却季绛称作出了广大的弘法事业，以此培养出无数住持正法的弟子。此中最主要的传徒，即成就双运身果位的勇士，大成就者却季多杰(法金刚)。

意乐修行菩提道次第的人们，应当谨向住持耳传教授的坝索·却季绛称大师祈祷求加，并应如大师那样的净行——见行清净，一心专修诸佛所喜的妙道心要，即远离一切损失、紊乱、杂合、虚伪等过染，从佛起未曾中断的这一殊胜卓越的耳传教授获得后能修学成功。
