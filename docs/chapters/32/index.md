# 三十二、大善知识拉·隆根旺秋的历史

根据宗喀巴大师所著赞词中赞道：“最精无垢教，获得自在师。”

受这样赞叹的大善知识隆根旺秋，他降生在颐章康玛(义为红色宫殿)地方，系戊寅年神变月(四月)十五日，太阳刚出时生，他的父亲名爵富伦厥(义为拉主瑜伽)，母亲名纳朗。沙衣伯正(义为吉祥引)。他在幼年时代，身口意三门的一切行动是很调柔和雅的，不待他人的启发和劝动，就可自发地生起寻求正法的思想。他到八岁的时候在故日哇大师座前，求得近住斋戒，及领受了许多正法行教典的诵授，他如法行动而度著时日。在那时他心中生起了这样的一种决定——他想到我虽生为上种(王族)，并具足富有，但是顷刻间这些都决定是要失掉的，以此我对于无常、不固、不可靠、欺诳的这些有法，哪能去贪著它呢！现在佛教的究竟心要，吉祥王底邦迦利的法传还未失去，仍然存在的这个时间里，我无论如何应当入于佛教中，修学我佛极喜的一种清净正法。他不仅生起了这样的猛利意乐，并且常时滋生羡慕过去古德们的高风史事。在那时他一听著内邬苏巴大师的名字，也就顿生敬信。

继后他毅然决断地，想到现在我决定应当抛弃这污秽泥泽般的家庭而出家。他是十四岁的时候在故日哇前受优婆塞戒；也就在十五岁的时候，迎请了阿阇黎鲁迦(鲁是族姓，义为白鲁)，及善知识章巴。穹波二师，他请求鲁迦为作教范师，穹波为作阿阇黎，而在嘉萨地方出了家，起名绛秋仁清(义为菩提宝)。那时他也就在阿阇黎及教范两师前，很好地听受毘奈耶学处，自己的行动都按戒律来实行。他听受了《迦列迦五十颂》(想即沙弥五十颂)后完全体会在心里。他听受了详细的沙弥学——三百颂两遍；并对毘奈耶教典也很好地阅读，而有条不紊地知道一切粗细染犯，并且能按照所知道的诸戒如法实行。他在守护毘奈耶学处的基础上，进而研习三藏教典，成为善巧精通的人士。他对一些具足善缘的人士，也宣说法要。

他一瞧见切喀瓦大师的塑造面像，就顿生信仰，而问这位大德名叫什么，答以名切喀瓦已圆寂。现在这位大德的传徒生。吉布瓦还健在，因此，他心生敬仰而来到大菩萨生。吉布瓦的那里，心行两种都很如法地依止。他也就在吉布瓦座前听受了一切经教和经论的心要——菩提道次第导释教授，而意乐地修学，并将一切佛语和经论，特别是噶当六论，糅和在修学菩提道次第教授中。因此，大菩萨吉布瓦对他心中十分欢喜。在那里住的一切僧人，也都对他很欢喜而帮他砌筑一座静修的小屋。他到了二十四岁时，吉布瓦向他说：“这下你可以作比丘吧！”他于是从嘉萨岗迎请阿阇黎伦大师为作阿阇黎，请求香阿阇黎为作羯摩师，请求梁师为作教授师，而受了具足戒。

在那时喀什米尔大班智达释迦西，也到了西藏，他也就在班智达释迦西座前，请求了许多法要，并在其他许多善知识前，获得所有翻译来藏的一切佛经的教传(即是俗称过经，由师诵读，弟子听受)。特别是对噶当六论等大车轨诸论著中，所有在藏的教典承传现在哪里还保存著，他都去寻访而请求传授，都获得这些传承。当他无垢的理智日渐增长，而对于整个的教法要义，无谬地获得生起坚固的定解时，也就决心摒除此生的一切纷扰散乱，在汝巴地方，谨严地闭关专修起来。那时，他首先以修行积福忏罪为主，以此他最初亲自得见薄伽梵“药师佛会”为他现身，并如清净水中显现月影般地亲见著许多佛及菩萨真像。他到拉萨的时候，拉萨小昭寺中由汉迎来的释迦教主像的心间放光，射到他的心间而入于他的心中得著加持。由于他努力勤修慈心、悲心、菩提心的缘故，如愿地亲见怙主观自在菩萨为他现身。以有这些秘密因缘，他在拉。库湜寺的绘画像轴里，中间绘画了这次他亲见的观音像，后依此绘画十一面观音的画像成为画规，也就盛行起来了。因为他对于许多部门经教都领受传承，而获得自在权威，并且心中存在整个的经藏教传妙味甘露的缘故，所以普遍都称他叫拉。隆根旺秋(义为经教自在王)；也有称他为拉钦波(义为大王)的。一切智宗喀巴大师也是想到他的这些德风而赞他道：“最精无垢教，获得自在师。”根据《噶当法史》中说：“这位大善巧经教自在师的语录中说：他著有《切喀瓦宗风选集大疏》，还有一部详细的佳作是《修心教授记录》。”拉。隆根旺秋他从与吉布瓦最初见面起，直到吉布大师示寂之间，他都是很好地如法依止。吉布瓦大师圆寂后，他继即在庚戌年主持吉布寺和切喀寺，而很好地护持噶当教典派的宗规。这样一直到壬辰年，计主持寺务共四十三年，做出了广大的弘法利生事业。他享寿七十五岁，是在壬辰年神变月十五日圆寂的。这位大善巧师抚育出许多弟子，而拥有噶当教典派所有教授，获得如瓶水全倾般的最得意首要弟子，确为拉。卓瓦贡波(义为众生怙主)。

以此意乐菩提道次第修心的人们，应当对于这位经教自在大师祈祷求加持。并应当发愿如这位大师的德风史事一样——由一切经教和经论的教义二者之门而护持教法。与及首要的是对于一切经教及经论的心要——菩提道次第，应竭力地一心勤修。
