# 附一、仲巴·嘉操巴·洛桑准珠绛称略传

洛桑准珠绛称(义为慧贤精进幢)系阿里法王吉德利玛棍后裔桑那嘉补(义为桑那王)的王子。由于过去薰习善法之力，生性具有皈依三宝，唯以正法为念的心。他在父母及褓母等养育之下，到了成年时，虽是发生前往卫藏寻求正法之心，但是由于他是王子，王臣等都说他须护持国政，没有去求法的机会。始终由于他长久修行发心之力所感召，发生了那格王率兵前来将桑那王城掠夺而统属桑那所有土地。以此王子准珠绛称同一些友人改作僧装前往卫藏去的时候，被那格王得知他是桑那王子，将他逮捕起来准备杀害时，其他同伴都惊骇叫苦。王子准珠绛称不仅没有惧怕而且还十分喜悦，他想的是我今被杀，由于存著去卫藏寻求善法的这一善净的愿望而死，来世得生卫藏值遇正法，所以十分欢喜。这种行态，确是难能可贵的史事，是有著至心皈依三宝及真实深信业果的心，以此出走也没有超出为法的范围，并且有著为求正法敢于牺牲生命的精神。正如略本《般若经》中说：“精行为法，命亦能舍瑜伽行。”这是获得不退转的象征，以此这是后世所有人们应当随喜的史事。后来，那格王也被他的行态感动而生敬信，未加杀害，释放了他。

此后，大德准珠绛称到了二十四岁时，前往卫藏，顶礼于班禅洛桑却季绛称大师座前，次第受得沙弥及比丘等戒。他效法宗喀巴大师德行史事首先广大求多闻，住色拉寺上院，依止毗敦。伯觉伦珠(义为满成)师前，学习经论。继到达波扎仓勤学四大难论。复回色拉详阅大车轨诸经论住有数年之久。后到上密宗院住了数年，学习密教经海。那时他见得继任密院喇嘛起很大诤执，心中生起很大厌离，回到班禅洛桑却季绛称座前，请授摄一切佛经要义为诸佛菩萨所趣向之唯一大道——菩提道次第温萨巴耳传教授修验指导，对于耳传教授所有口诀除障增益等法都获得一定的把握。复听受文殊耳传教授噶当大手印甚深讲授及六加行四大讲授等，获得生起决定。继复听受《修心七义论讲授》，及启虚空门灌顶，以及“觉”法(以身供施断执密法)甚深讲授，有关四部密续的无数灌顶、传经、教授等法，特别是生圆二次第诸教授，与及由宗喀巴大师所传那若六法等教授口诀。

继依上师班禅洛桑却季绛称所指示到后藏各寂静山林专修为佳的师教，他先去到色地区住诸山茅蓬专修。继到达纳地区，在王噶及大成就师法金刚诞生地葛窝仓，及廓译师修行处“夏日”等处安住长时精修。当时，他以专修为主完全舍离世务，以此中间有段时间缺乏衣穿，到了严冬时期，他掘地洞坐草堆中修行，等同瑜伽自在大师密勒日巴那样的苦行。这位大德既是班禅慧贤法幢大师如自己眼珠爱护摄受的得意弟子，哪有缺乏生活之理；但是由于上师慧贤法幢观察到为令他成为住持文殊宗喀耳传修派法流人物的缘起，以及护持不失过去大德清净苦行的德风，与及慧贤法幢大师自己也曾经一时住寂静山林专修，处于困难苦行仍进行精修，这样对于圣教有最大利益，所以使这一得意弟子也经过一段苦行。

大德准珠绛称对于文殊宗喀耳传教授，经过长久精修，渐次通达一切共通道及不共道中有功用及无功用的修验，获得不退转的决定，复为其他具缘人士授赐正法甘露。他的弘法利生事业渐次广大起来，德风美誉，遍扬于各方。他对各方希求法义的人士，主要传授《菩提道次第》详广导修讲授。对于宗喀圣教深生信仰，能够研习显密圆满道体的应化众生，则传授以噶当大手印甚深详细讲义。对于没有智力学修大手印，而于宗喀耳传法流有极大信乐的人士，则传授以加行六法，及三士道导修讲授，总三士道应行学处，都学习完善后，到了当学止观的阶段时，则传授以甚深噶当大手印共通讲义。对于一些已成上智的人士，则进而详细传授生圆二次第及那若六法。继后，大德准珠绛称得到上师班禅洛桑却季绛称委以新建香多廓仓地区邦瓦桑敦寺寺主，以此他晚年都住锡在廓仓及拉安扎两处广弘圣教。

最后，他年届八十四岁时，圆满了此生救度众生的事业，也就在拉安扎寺示现圆寂。为表示宗喀修派法流之重要，在地水火风空诸大渐次收摄，将进入于大空光明中时，身直如箭，住于一切皆空光明性中，约一月有余。当时这位大德住于光明空性中，有这样的一种特征表现：大德是在十月三十日示现圆寂的，时值冬月，照例是寒风凛冽的时候，可是在大德住于空性定中直至未从定起之间，天空清明无有纤云，俨然是秋季明朗的晴空，竟无一些寒风，香地区一切山谷都温暖如春，香河结冰，亦顿解冻，如秋气候等相，为众目所共睹。继从光明而起后，诸大弟子为首率同善信人士供无量供。师身荼毗后留下心、舌、眼三根未毁，安置在廓仓茅蓬银塔中，以作人天供养福田。

班禅大师洛桑却季绛称多次传授《菩提道次第导修教授》，以此传出无边法流。特别是从他的首要诸大弟子所传出的法流，又各有多支。此中住持事业为时最久的一支，系由洛桑却季绛称大师传金刚持师根却绛称(义为宝幢)，继由根却绛称传洛桑耶喜(义为慧贤智)。另一支系由大师洛桑却季绛称传仲巴。达普巴，继由达普巴传格勒嘉措(义为善海)。以上两支传流最为广大，为时也最久。著者获得两支承传法流，以此在本书中，将述说这两支承传诸师的史事。

意乐修学菩提道次第的人们，应当谨向班禅大师洛桑却季绛称祈祷求加，并应效法大师的清净史事，求得显密整个圆满道体，进而对于如何修学之法，求得宗喀巴大师耳传教授后，不是虚有外表，而是应当尽其所能勤奋精修为要。
