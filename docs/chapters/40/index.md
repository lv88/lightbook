# 四十、善知识杰贡巴的历史

根据宗喀巴大师所著的师承赞颂文中说：“精修依胜乘，赞我杰贡师。”

值得这样赞说的大德杰贡巴大师，他的族系源于婆罗门“杰拉朗”种姓，系庚午的那一年(宋高宗绍兴二十年，公元一一五○年)，在伦村的上区诞生。父名杰。协饶然(智救)，母名客谟鲁江。他从幼年时代就有了极好佛法醒悟的薰习，即能表现如善法那般的行动。这样经过了一段时期，到了十二岁的时候，他的父亲逝世。因此，他的母亲怀抱著两个大儿子，背揹著小儿子去到业区他的舅父家里。舅父敬。达玛藏那是业区的长官，他的母亲也就将孩子托付给舅家。这位杰贡大师十二岁就在业区出家，命名须鲁扎巴(义为童称)，刚一出家他随即很好地学习所有毘奈耶应守的制戒，如爱护眼珠般守护戒律，并且努力精勤学习噶当教法的学行。继后，他去到朗日塘巴那里充当仆役，也就在朗日塘巴的附座经师，是一位持律师的座前听受毘奈耶；继在嘉裕瓦大师来到业区时，他听受过一次大师为众普讲的教法。嘉裕瓦大师是在为众说法的会期前就来到了业区的，在这一时间中，有一位教导杰贡巴的导师在嘉裕瓦的座前请求对杰贡巴多多关注。他对大师说：“这一青年僧是有很大的希望的。当我给他授戒的那一晚上，梦得极佳的梦兆。”嘉裕瓦大师说：“他是我前生的一位教师。”当即脱下自己的帽给杰贡巴戴在头上，而为之摩顶加持。并且说：“你将来决定当作一位大修行者，将成为一位有大福德的人，比我的福德还大。”到后来杰贡巴大师说：“我比嘉裕瓦上师的寿命长一些，以此长寿福力得以成办我的一切心愿。”有一天在嘉裕瓦上师将要来到那里造访的后方，杰贡巴走过去摘了三朵很鲜活的杜鹃花，供于嘉裕瓦座前，以此因缘嘉裕瓦说：“这一缘起很好，你将作一位三藏法师。”继后杰贡巴他心行两方面都如理地依止上师嘉裕瓦，在师前主要听受所传授的菩提道次第教授，与及嘉裕瓦所有的一切教授法门，并且能依著嘉裕瓦所传授的菩提道次第教授如闻而修。尤其是他听受任何一法，都能发挥很大的智力，一句不遗牢记心中，而无疲厌。杰贡巴自己也这样说：“我从嘉裕瓦大师座前所听受的任何教授，直到现在一点也没有忘失，很清楚地显现在心中。”

继后，格西枳贡来到了内邬苏地方，他对内邬苏巴大师说：“我们那里有一如此这般智慧锐敏的青年僧，如果能来到这里大师的座前，还望大师慈悲关注。”大师听后心中很喜欢地说道：“把他领到这里来吧！”于是格西枳贡把杰贡巴叫做“猴脑子”，说道：“猴脑子，有善知识名内邬苏巴，是一位修不动金刚获得坚实的大德，你到他那里去吧！他说对你能作关照。”于是杰贡巴他作了将到内邬苏去的观察，在他明天将启程的头天晚上，梦中清楚而且一点不差地见著内邬苏巴大师的静修室，与及那里的住屋塔院等。到第二天清晨，虽有一些其他的人来到，但他已决定启行，于是来到那谟铺及噶哇隆，继续前进在晚间才行到容哇村。得到那里的一位静修者的关注和帮助，他才得到住宿地和卧室。第二天他和一批康巴隆巴的僧人结伴来到了康巴隆，也就在那里住了一天。第二天复从康巴隆起身向内邬苏前进。卓瓦钦季与他作伴来到了内邬苏的时候，时间已很晚。忙到内邬苏巴大师的座前去参拜，大师问他道：“你是从何处来的？”回答道：“我是从伦村而来的。”大师说：“啊！那么枳贡所说的就是你吗？”回答说：“是的。”大师复说道：“我好像和你曾相识那样，今晚你仍旧到那边去安睡，明天黎明再来吧！”

第二天黎明出时，大师当即传授以不动怙主的缘念三法的念诵经文，及《喀坝玛》秘藏经文，并吩咐他说：你须熟记其中每一字。他回答上师已如所说的那样一般无二地记起来了。大师对他说：“从我的心中观察，你在这年轻时光中，就将成为一个能一心专注的人。现在你可以就住在这里吗？”他回答说：“我暂时去把食粮的事办好后再来。”大师说：“那么随你的便吧！”说后给了他一包酥油，一大碗好茶叶，及大师自己留下的一份余食。他于是回来办好了食粮的事，再来到师前的时候，大师对他说：“现在你要做我的仆役，还是一心修法呢？”他回答说：“愿一心学法。”大师说：“那么一心修法者须有一间得有自主权的住室。”说后大师从自己腰包里掏出二钱黄金来，说道：“你拿这黄金去买一间小屋吧！”于是大师传授他以修法教授，并且对他说：“这些教授是其他的人们来求我而未获得的，现在是我将你觅著而传给你的。”大师对杰贡巴十分重视，把所有教授都传给了他。

杰贡巴他住在内邬苏的时期中，除听上师说法外，其余时间都在一心精勤闭关专修。据他说除有一次上师为众说法他未能参加外，其余的法座他都很郑重地参加听讲，从未缺过一次。他并且说：“我在内邬苏住了九年的当中，从未作过夏冬两季在那里住下，春秋两季又离开那里的行为。”那时内邬苏所聚会的僧团是很大的，有一人士问：“内邬苏巴大师，你这样大的僧团想来有一些对有情能作饶益的。”大师答说：“洽巴的那位青年僧是有希望的一个。”原来杰贡巴住的那地方，先有一名叫章本洽巴的卜者住过，以此大师把他叫做“洽巴青年僧”。内邬苏巴大师对杰贡巴是另加等级特别看待。在僧伽大众中也公开说：“你们先休和那青年僧作比赛，你们修吧！”杰贡巴他是以修为主，以此都称他为“杰贡钦波”(义为杰氏大修行者。)，这位被称为杰贡钦波的善知识，他是从心行两方都如理依止善知识，长久期中勇猛精进地专修菩提道次第，以此他是一位真实获证道次通达的。他的心中生起了清净的出离心，因此他对于贪欲境，任何时候也不生起放逸散乱的心，并且有坚固的正知正念，使他所守持的戒不染丝毫罪过；最低限度乃至不念诵“桑把惹”(系加持食真言)他是不进餐的。这样种种关于所有戒律中粗重和细微的一切制戒，他都是精严守护而无退失。

他具有很大的精进力，所以念诵了很多亿万数的不动怙主咒。杰贡巴说：“善知识内邬苏巴曾经亲口说他已念诵了不动怙主十字真言十三万万遍，看来我也能念诵那样多的遍数。”他又说：“我的身语意三业从未安住在那凡俗境界中。”他不管是在大众法会中或是特开说法场合中，都是极其严谨地防护此心。最初在佛殿僧众聚会中他是不参加的，因为他说集会后此心随便放松，以此他不到集会中。这样说后他确是在作极大的精进修学。由于他生起了猛利的慈心、悲心、菩提心的原因，以此他对于一个哪怕是弱小卑下的有情，也总想著：若我能饶益他的话，我决定对他作饶益。村中穷苦无力的人们来迎请他，只要对请者能作饶益，他就决定去。以此他说：“旁人来请我去为村中在家人诵修超度亡者仪轨等事，要是对于为利有情能作一些饶益而不作的话，那应叫做是菩萨放逸之点。”所以他直至未示寂之前，仍为村中在家人诵经修法。他享寿八十二岁的当中，哪怕是一个困苦无依的单身妇女，只要来到他的面前，他也慈悲摄受传授她以皈依发心。他曾经这样说：“我从幼年时起，从未生起过大不了的瞋恨心，并且饶益他者的心任运地生起著。”所以一切智宗喀巴大师想到杰贡巴的这种修心精神，而赞颂说：“精修依胜乘，我赞杰贡师。”

杰贡巴大师具有极大的智慧，他对于菩提道次第法门中所有要点，他都运用无边的理智去一一寻思修练。他对于依止善知识法，是已精修获得真实证解的。他曾经这样说：“我对于指示要道的善知识，从未生起过上师非佛想的那种凡俗念头。于经教中所说现在对善知识生起了真实的敬仰，而体悟供养一切佛不及供养上师的加持大。”这一教言对于这位杰贡巴善知识来说，他的心中也是真实生起了的。并且对上师祈祷，就能获得诸佛加持而得见很多本尊，与及天眼神通等前辈诸师的所有功德，他的心中也是生起了的。这位大德他能将前辈诸师所传授一句不遗牢记心中，而复授给他的首要弟子桑杰温敦等无量的具缘人士。由于他在长久时间中，精进励力勤修善法的关系，他的心中生起了如广大车轨经论中所说的圆满诸相的三摩地。他生起了那具足四相的三摩地后，他以所修证的情况，在内邬苏巴大师座前详陈求印证。内邬苏巴大师对他说：“你到了六、七十岁时，将得到俗众礼拜敬供。到那时应修建一塔，如果不修建那将成为一种大憾事。”格西达脱巴说：“有一晚上，内邬苏巴大师座前，有四起以所修之相来求印证的人，其中有一人是心中生起了那具足圆满四相的三摩地，以此我专对其人心生敬仰，后来我一细查才知道那人是善知识仁清岗瓦(杰贡巴的别号)。”

杰贡巴大师具有极清明的三摩地之力，以此得亲见很多佛菩萨。他说幼时依著母亲的膝下东看西看的时候，看见一位尊神，那时不能认识是何尊神，后来阅览密经知道那是阎曼德迦(大威德金刚)。他住在内邬苏的时候，亲见不动怙主。内邬苏巴大师示寂后，他刚年满二十九岁，众施主来迎请他，他也就在塔谟地方住了一夏，讲说了一次菩提道次第法门。继后来到仁清岗，在己亥年为修建旧寺及仁清岗寺作了奠基工程。他说在仁清岗驻锡时，在那里的南方亲见薄伽梵释迦能仁，在那里的西南方得见药师佛，在西方海边得见大悲观音巍巍然如大雪山。又他得见自己身是曼陀罗中所有诸尊，与及诸尊进入自身中无量宫殿，得见五方五佛安住其中。又在住处供佛殿柱基那里得见大悲观音及救度佛母，那时也就在八臂救度母前听受了八臂度母修法教授。到后来他来到了嘉裕地方，将所见诸尊情况，详陈于嘉裕瓦大师座前求印证。嘉裕瓦大师说道：“极为稀有，此中不存在凡俗境相。”又说：“杰贡巴是需要大悲怙主法门的，他虽是来向我请求此法，但我只当是使他重温正念。”说后即将八臂度母修法向杰贡巴讲了一遍。杰贡巴听后说：“和我原先听受度母为我亲说的修法是一般无二。”又善知识嘉裕瓦说：“学开光等法事来说，本来杰贡巴自己也知道，但是由于我寻觅著他，仍然需为他而服务。”说后不待杰贡巴向他求法而将一切法门都传授无遗。又善知识嘉裕瓦说：“你在这里受我一点供养，对我是有著无比的恩德。”有一批施主在建寺完毕后，请求善知识嘉裕瓦接管。大师说：“既是这样，那么我就叫杰贡巴来护持此寺。”杰贡巴说：“我可以依照您的意愿去作，但如果这样以后恐怕连甲鲁寺这三个字都听不到了。”此外杰贡巴系亲见誓句三立本尊。他想金刚座圣地的念头起的同时，得亲见大菩提主从三尊。又他在嘉裕住的时候，得亲见护法母。由于他诵修本尊明咒等是很彻底完善的，常时保持那不过不减的正确数量，以此获得饶益其他有情的功德。他对其他有情修法加持时，从未发生过不起饶益效验的事。

他的身体真是如金刚那样坚固，他又说：“我从未发生过一次病痛。在孩童时代，有一次地方中发生很厉害的传染病，以此死了不少的儿童，所有儿童的尸体都送到城市后边去。我的两个兄弟也被瘟疫传染，我将他们两人一左一右安放在我的身边，我一心念诵顶髻如来咒。有一晚上，梦我去到城市后边，看见那里有很多形形色色的阴暗密集的鸟头黑影。又有一井口，复有很多黑鸟密集在那里，去一看时我的两个兄弟奄奄一息待在那里，我急忙用手抓著他两人提出了井口。到第二天黎明，两兄弟霍然而愈。”杰贡巴大师复具有广大的他心通，他的得意弟子桑杰温敦(系他的侄子)在去年的时候，有一次刚动念想：“叔父的那串念珠给我的话，那有多好……”，他还未开口要的时候，杰贡巴当即向他说道：“念珠如果只是手持著是没有意义。这些不过是突显自己。”又桑杰温敦说：“在还未生起修善的意乐时候，如果去到杰贡巴师座前，就会见著上师面上现出不豫之色而说：那样没用。如果有一天你油然生起了修善的意乐而去到上师座前时，上师就会对你喜欢地问：‘今晨你心中生起了些什么？’回答说：‘生起了如此这般的心。’大师说：‘那是我加持你而生起的。连我现在已老也应当须要那样的法，你也应当是须要那样。’”这些事迹是杰贡巴大师能知他心的神通功德。其次说他证知神通境界的功德。杰准。喇嘛耶喜说，一次他想向杰贡巴大师求法，去到大师所住的静室中，他进的门内，身体堵塞在门口内窄狭的空隙中，用手去摸著门槛坐下的时候，突见杰贡巴大师从没有门道的屋后而来到室中。

具足这般功德的杰贡巴大师驻锡仁清岗寺，直到八十二岁中，他都是以菩提道次第法门来作饶益有情事业。他曾经这样说：“这一菩提道次第根本论乃是阿底峡尊者传授给衮巴瓦的，本论的讲说及诵授等根据博多瓦所讲授而作，我们不以自己的文献为足，而复参阅其他文献来增广讲义，并且无繁言废语夹杂其中；这譬如不管弓箭拉的怎样满怀，而所缘只是一个箭头的尖端，以是我辈大乘人来说其所缘应只是利他的一个心绪。”又说：“如师住世时，应当做这样一种善法，即决择疑虑，增省诸义留于后世，使现在自己纵然去世，亦能作为师者的代表。”他又说：“依止的前辈诸师身躯消逝后，他那并未消逝而且正在弘昌的教授——良师益友，是极为重要的！不应寻求那与自己上师的德行不合的第二位上师，如果去寻求那样的上师，那么，你前一位上师的加持，就会如同螺上的尘土被拭擦去那样干干净净消除而不存在。”又说：“能在上师逝世后，依随顺正法的僧伽为友，而把上师的教授视为助援的人，他自己是不衰退的。”又说：“上师逝世后，能依止一位随顺上师的教授而修的人士做为后来上师的人，他自己是绝不退堕的。”说了很多诸如此类的话。

又杰贡巴对温敦说：“有两个迎接我的使者来到了。”说这话的当天晚上，温敦梦见有一批说是天神之子前来供养的神人，及有一身白极为整洁的人也来到的时候，善知识杰贡巴大师身著比丘的单衣，头戴折叠帽，扶著手杖，同那位洁白的人来到他的床前，把手杖竖立在他的枕边，对他说了一些教诲的话后，洁白的人同杰贡巴大师二人，也就向东南方向的天空飞去而消逝不见。继在几天过后，杰贡巴大师也对温敦说了一些教诲的遗嘱，但由于温敦年轻也不知止住悲泪，如果不是这样，那时或许还能有很多谆谆教诲的话。此外，杰贡巴大师对温敦吩咐说：“还有如此这般具有大加持的佛像经塔在某处，与及经箧、记有要法的小册子在某处，所有这些物件切勿散失入于他人之手，这些都是我经常缘念的物件，是有虹彩光明放射著的。你将来如果能达到如此这般的功能，那时你可以说法，与及开光诵修供养消灾等法。你应当随顺正法而作，这两寺如果能顺正法的话，你就善为护理吧！如果不顺正法，你就放下它吧！”有此吩咐温敦获得了行事的方便。继后杰贡巴大师寿届八十二岁的那一年，岁次辛卯(公元一二三一年，宋理宗绍定四年)正月二十九日，在仁清岗寺示寂，圆寂时结跏趺坐，左手作入定印，右手作压地印，顶门有一股热气如瓶口向上腾出，由于我们见相未净，而只能见著这般的示寂现象，他处所见则是有光明升起。此后大师的骨塔，受到所有众生的广大供养和祝愿。杰贡巴大师约有门人八百徒众中，首要大弟子为卓衮桑杰温敦，此外还出有很多能住持教法的贤士大德。

以此意乐菩提道次第修心的人们，应当对于善知识杰贡巴大师勤行祈祷求加持，并效法杰贡巴大师的德行史事，依三士道次第而勤修速证真实通达之心，最低限度亦当以大师德行成就作为吾人祝愿之境而修此心。
