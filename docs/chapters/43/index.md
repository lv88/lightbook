# 四十三、大堪布生根桑波的历史

根据宗喀巴大师的《师承赞》颂文中说：“离世八法师，我赞师子贤。”

值得这样赞说的大堪布生根桑波(义为师子贤)，生在须普族姓中，系大堪布朗喀嘉补的侄儿。由于他有著往昔贤善习气的力量，年方七岁即能不贪恋一切欲乐，在无人察觉的当中，私自去到一处岩洞中，而不依赖人间饭食，只食石子，一心专修。他亲见很多本尊，获得加持，生起殊胜修证。到廿八岁时，他在大堪布朗喀嘉补前出家，学习毘奈耶诸戒行，复在香。耶喜哲前专研《律经》根本颂。继后在大堪布朗喀嘉补前听受《菩提道次第修学详导》，而依之一心专修获得定解。在大堪布朗喀嘉补示寂后，他来祖寺继掌法座，整顿三事戒规等所有毘奈耶中粗细诸戒行。他创建了纳窝新寺，并迎请持律大师措那巴为僧伽大众转正法轮，大弘佛教事业。由于这位大德他远离贪欲，而常时精勤苦修，获得殊胜修证的原因，一切智宗喀巴大师对他赞美说：“离世八法师，我赞师子贤。”这位大师他作了这般广弘佛教的事业后，收摄色身时，说要往生杨柳刹土(金刚手净土)，言毕即圆寂。那时发现天雨花等瑞相。这位大师对很多具缘人士，广传《菩提道次第修学详导》，以此出有不少的门人，而能住持其法传的主要弟子，则为大堪布嘉色桑波(义为佛子贤)。

因此，意乐菩提道次第修心的人们，应当对大堪布师子贤祈祷求加持，并应效法这位大德，远离贪欲而专住修行功德中，一心勤修菩提道次第。
