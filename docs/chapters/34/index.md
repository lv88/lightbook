# 三十四、善知识桑钦巴的历史

根据宗喀巴大师所著“菩提道次第师师相承启请文”中，有颂句赞道：

“净戒香四溢，大德桑钦巴。”

值得这样赞叹的大德桑钦巴生在梁下区地方，诞生时候发现很灵异的征相。他少年的时候，也就对纷扰的俗家不起贪恋，而常时生起进入佛教之门，修学清净正法的猛利意乐。这样的念头，谁也阻止不了他，于是他从住持桑钦寺(义为大贤)的法座阿阇黎索朗鞠勒(义为福生)大师出了家。最初阶段他受沙弥的戒律仪，起名叫达玛索朗(义为盛福)。他就依止受戒的阿阇黎而很好地学习沙弥学处，心中完全体会了解一切法行，继即钻研一切教典，对三藏教法学习得善巧精通。他的内心受著清净出离心的策动，也就在亲教师达叶哇，与及补充足数的各僧伽众的当中，而受了具足戒。他在拉。卓瓦贡波大师的莲足下顶承教诲，所有毘奈耶四部所说一切句义，如阿阇黎德光决择律经一样，从彼授受，及可取诸水以上的比丘一切粗细分诸学处，他的心中都学习得了解透达，而依戒实行。所有毘奈耶中说的戒律规条，哪怕是细微的过犯，他都不使染污而严守清净戒律。传说他由于持戒的功能而发生出一种奇妙的戒香，不待风吹而清香四溢。宗喀巴大师思想到他这种功德因缘，所以对于这位大善知识赞叹说：“净戒香四溢，大德桑钦巴。”

他在拉。卓瓦贡波大师座前，听受佛经和大车轨的许多经论，而成为彻底精通的人士。由于他的才能和功德的感召，获得了僧伽大众推选他为桑钦寺主持人，登上说法大学院的狮子座，而宣说广弘大车轨诸经论。以此善知识桑钦巴的美名，也就遍传于各方了。继后他迎请拉。卓瓦贡波来到桑钦寺中承事供养，而很好地听受了卓瓦大师讲说糅和一切佛经及经论等的要义，而成为一补特伽罗修行的次第——具吉祥阿底峡尊者的教授菩提道次第的修验导释。并且他不是仅听受后也就搁置起来，而是如法地修行获得很好的修验。他在拉。卓瓦贡波座前，听受了《噶当六论》，也就能将菩提道次第一切所缘，与大车轨诸经论结合起来讲说，获得无畏的辩才。他复迎请喀什米尔班智达释迦吉祥到桑钦寺中，他在班智达座前听受了许多显密教法。

他对于门人如首要弟子措那瓦大师等许多具缘的门徒，广弘宣说菩提道次第的导释和大车轨诸经论的教义。最后他享寿到七十五岁的时候，受了一种肉毒，以致身体得病，一切僧伽大众都为他诵经修法；护法贡波扎迦侠也为他化现成乌鸦，从印度、尼泊尔啣来新鲜橄榄而供于座前，但是无论做怎样的方便和诵经修法，终未获得挽救而西逝。僧伽大众做大供养后，并建立了奉安遗体的大塔，也就将护法啣来的新鲜橄榄供置在塔的前面。由于发现遗体的面容转向西方的缘故，据说这是对于僧院将大兴噶当教法的预兆。这位大善知识教抚出很多弟子中，首要的弟子确是措那巴大师。

以此意乐菩提道次第修心的人们，不仅应当对于这位大善知识祈祷求加持，更应当效法这位大德的史事，高风守护清净戒律为基础，而对于菩提道次第修心当中，能显现了知一切经教皆为修心教授。
