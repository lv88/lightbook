# 《密集》法类师承概况

至于金刚乘道次第的承传诸师次第，由阿底峡尊者亲自命名为“修行加持派”。此中复分“金刚乘总共通承传次第”，及阿底峡师徒秘法“不共噶当十六滴承传次第”两种中，以前一种显密总共通承传次第来说，四部续经中，有无边的灌顶、经教、教授等，在这里哪能尽量写出，以此应从其他论著中去了解。这里是了解到至尊怙主文殊对法王宗喀巴大师指示：在这浊世寿短一生中，意乐速中更速成佛的人们，从依止善知识起直至整个道体学行之间，关于彻底修悟共通道次第后，应当求得胜乐、密集、能怖三法的灌顶，及诸种教授，不间断地努力勤修这三法的原因，多次教诲那样。为了使圣教心要，这些究竟修行要扼，不致湮没起见，以此在此间略述密集、胜乐、能怖三法的灌顶、经教、讲授教授要诀等的承传次第诸师的名称如下：薄伽梵释迦能仁王佛、转金刚乘法轮的情况，详如前文释迦能仁世尊清净行传中，不必重述。这里说从能仁王佛起直至现在。

金刚乘承传诸师次第而来的情况如下：

在释迦能仁王佛住世时，印度西方乌仗那圣地，出有国王名亨遮菩提。他安住美妙王宫屋顶的时候，亲自看见阿罗汉比丘从虚空飞行往东西方向而去。他问：“这些是些什么？”一些熟悉佛出世史事的侍臣答道：“释迦净饭王的太子成佛后，在圣地大转法轮，这是他的声闻徒众前往他方，以此从虚空飞过。国王所见的那些，也就是佛的声闻徒众。”国王听后，心中生起了不退转的敬信，而谨向佛世尊祈祷求加持。佛由神通得知，同徒众以神变力而来到王宫中，向国王说法，以此国王生起了特殊信解，并做如是言向佛启请说：“我愿还未舍弃俗装的时间中，也就能成佛。”由于这位国王是大宝根器，以此薄伽梵能仁王佛于密集曼陀罗中，现起金刚持身，而为国王灌顶，开示教授，说密集本续，复由金刚手善为讲释。由此亨遮菩提王修行究竟共通及不共二次第瑜伽，行戏论行，而在这生证得双运身佛果。

此后，亨遮菩提王也就对当地的应化信众，开示金刚乘法，以此出有难以数计的大成就者。后来亨遮菩提王将密集灌顶，及所有教授完全传授给有承命弘扬这一法类的具缘修者鲁谟伦觉玛(义为龙女瑜伽母)，瑜伽母传毗苏迦巴王。毗苏迦巴王修此法门，也获得大成就，由他传给具德萨惹哈，萨惹哈也修得成就后将密集所有灌顶、教授完全传给怙主圣龙树，圣龙树得法后，在南方吉祥山中精修，他在此生中，获得双运身佛位成就。他将密集所有灌顶、经教、教授等完全传与上首弟子阿雅德瓦(义为圣天)，及鲁衣绛秋(义为龙中菩提)、释迦协业(义为释迦友)、达瓦扎巴(义为月称)等很多得意弟子。以上阿雅德瓦等四位大师，都是修行密集二次第达到究竟，此生获得双运金刚持果位。此外，还出有阿阇黎桑杰交(义为佛护)等很多获得双运果位的龙树弟子。从阿阇黎圣龙树师徒所传出的密集灌顶、经教、教授承传次第诸师，是出有难以数计的大德，哪能逐一写出。为一般普遍传称的灌顶师承次第，则是由圣龙树，次传阿阇黎玛当根巴，次传大成就师帝洛巴，次传班钦。那若巴，次传玛巴诺扎(义为玛尔巴译师)，次传楚敦。旺根多杰(义为灌顶金刚)，次传昆敦。格巴根底，次传嘉贡巴。索朗仁清(义为福宝)，次传土拉瓦。楚称交(义为戒护)，次传汤伯瓦。帕巴交(义为圣护)，次传色顶巴。迅路峨(义为童光)，次传一切智却姑峨热(义为法身光明)，次传一切智帕巴峨(义为圣光)，次传法王布顿仁清珠(义为宝成布顿大师)，次传穹波特巴。迅路索朗(义为童福)，次传法王宗喀巴大师，次传克珠。格勒伯桑(义为福善吉祥贤)，次传班钦。却季绛称(义为法幢)，次传大成就师却季多杰(义为法金刚)，次传考嘉瓦。洛桑邓珠(义为善慧义成，即温萨巴)，次传克珠。桑杰耶喜(义为佛智)，次传至尊洛桑却季绛称(义为善慧法幢)，次传金刚持师根却绛称(义为三宝幢)，次传至尊洛桑耶喜(义为善慧智)，次传金刚持师洛桑仁卓(义为善慧明解)，次传善巧成就金刚持大师耶喜伯觉(义为智富德)。在这位恩德无比的金刚持大师座前，由我(著者耶喜绛称)(义为智幢)获得密集所有四灌顶完全要法。

又由一切智法王宗喀巴大师次第承传诸师：为至尊协饶生根、杜纳巴。伯敦桑波、大密师更敦迫(义为僧增)、大密师扎喜帕(义为吉祥圣)、大密师桑珠嘉措(义为如意成海)、大密师准珠帕(义为精进圣)、大密师多杰桑波(义为金刚贤)、大密师桑杰嘉措(义为佛海)、大密师根却嘉措(义为三宝海)、大密师根却雅迫(义为三宝增盛)、汤萨巴。欧珠嘉措(义为成就海)、成就自在师邓约克珠(义为不空善成)、至尊昂旺绛巴大师(义为语自在慈氏)。在这位至尊恩德无比的大师座前，由我(著者耶喜绛称)获得密集所有灌顶，密续经教，二次第教授完全教法。

又由圣龙树次第承传所出诸师，为阿阇黎阿雅德瓦、妥比多杰(义为学习金刚)、大成就师纳波觉巴、喇嘛真季须金(义为云中力师)、仁波切廓(义为廓大宝师)、芒热瓦。生根绛称(义为师子幢)、垛。耶喜生根(义为慧师子)、垛。阿雅德瓦、伦察。利玛江、达巴。仁清扎(义为宝称)、土拉瓦。楚称交、汤伯瓦。帕巴交、色顶瓦。迅路峨、一切智却姑峨热、一切智帕巴峨、法王布顿仁清珠、至尊上师索朗绛称、译师朗喀桑波(义为虚空贤)、无等至尊仁达瓦大师、法王宗喀巴大师、至尊协饶生根、大密师敬巴伯瓦(义为布施吉祥)。由此师所弘传密集讲轨承传诸次第，如一般传诵的师承那样，直至住持密集教主至尊昂旺绛巴大师，继由大师传一切智班禅洛桑伯敦耶喜。在这位班禅大师座前，由我(著者耶喜绛称)获得密集所有密续讲释四种合注完全教法。
