# 《胜乐》法类师承概况

关于胜乐轮法类：是由导师释迦能仁金刚持，将胜乐轮所有灌顶及续经完全传授与秘密主金刚手菩萨，秘密主传大成就师萨惹哈，次传怙主圣龙树，次传侠瓦里巴，次传大成就师鲁亨巴，次传达里迦巴王，次传阿阇黎多杰枳布巴，次传大成就师汝伯巴，次传大成就师乍伦达热巴，次传大成就师纳波觉巴，次传大成就师桑瓦巴，次传大成就师朗嘉，次传大成就师帝洛巴，次传班钦。那若巴，次传滂亭巴昆仲，次传洛嘉。协饶哲，次传玛译师洛卓扎(义为智称)，次传萨迦大师恭迦领波(义为普喜藏)，次传至尊索朗哲谟(义为福峰)，次传至尊扎巴绛称(义为名称幢)，次传法王萨迦班智达，次传佛子索朗生根(义为福师子)，次传阿阇黎桑杰绷(义为俱胝佛)，次传大德勒比洛卓(义为善智)，次传喇嘛伯敦生根(义为具德师子)，次传布顿仁清珠，次传穹波特巴。迅路索朗，次传法王宗喀巴大师，由宗喀巴大师所传出师承次第与上文密集师承相同。鲁亨巴师传胜乐二次第所有教授由汤萨巴。欧珠嘉措传与成就自在师绛央邓尾多杰(义为文殊乐金刚)，次传至尊恩师昂旺绛巴。

大成就师枳布巴师传胜乐灌顶及二次第教授等，由班钦。洛桑却季绛称传与金刚持师根却绛称，次传吉学夏仲。昂旺敦真称勒(义为语自在持教事业)，次传克珠。洛桑克准(义为善慧智严)，次传至尊恩师昂旺绛巴大师。在这位恩德无比大师座前，由我(著者耶喜绛称)完全获得这一法传。
