# 《能怖》法类师承概况

关于能怖金刚法类：是由印度大成就师喇里达念诵《文殊真实名称经》时，经中有句说：“能怖金刚能作怖”及“六面忿怒王怖畏”及“阎曼德迦障中王”等句。他思念这些句义，而想到定有能怖金刚密续经，及红黑大威德诸密续。他于是前往印度，在一切班智达及成就大师座前，访求这一法类。但当时这一法类没有在印度，以此没有求得。他才明白这一法类存在乌仗那圣地，他向上师与文殊无别的尊前，长久祈祷；完全为利圣教，不顾自己的生命危险，经千辛万苦来到乌仗那。在他勇猛作祈祷的时候，得著智慧空行母的摄受，将能怖金刚灌顶，及红黑大威德两种灌顶完全传授给他，并赐示最后教诫。他复为利有情故，祈祷请赐密续经卷的时候，智慧空行母为他开启秘密法库，并指示《能怖金刚广大根本密续》全部有十万颂三百分别法类，必须在七天之内，阅读此中，能记持的都记持心中，不得超过此限。吩咐后没有允赐携出全部密续。喇里达大师想到七天中不能记持这样大的经卷中，众多法类，还是发愿祈祷为最要。他在七天中，在诸密续经卷前，作供养、礼拜、绕行，并勇猛地祈祷。到了第七天，三百分别法类中名叫《悉地分别法类》，系《能怖金刚大密续第七分别法类》清楚地显现心中。他复想到心中所现的这些，是否有错误和增减，必须查看一下。那时面前的经卷自开，查看时和自心所现的无有丝毫差别。刚看完时，诸密续经卷，顿时收入诸空行母秘密法库中去了。

此后，大成就师喇里达前往印度，广大弘扬大威德红、黑、能怖三法类；特别是能怖金刚大灌顶，及二次第教授，密续经教等，对很多具缘信众，广大传授。由此，出有很多依此法类而得成就的大密师。承命住持法传事业的大师，则是大成就师邓约多杰(义为不空金刚)大小两位密师。由小邓约多杰传给大成就师白玛班遮(义为莲花金刚)，次传大成就者玛默哲松(义为护灯)，由玛默哲松传给成就弘扬这一法类伟大愿力的惹译师多杰扎。惹译师在卫、藏、康一切方隅，对很多具缘信众，广弘这一法类。因此，对这一法类提升了很高的声价，求传一遍《第七分别法类》经教，也必须供养多两黄金，这是完全作为“金法”。那时，由能怖金刚大密瑜伽之门，而获得成就四种事业，及修证二次第者，与彻底修悟第一次第，及证得圆满次第等，出了不少对于此一胜道修证成就的人士。惹译师大弘事业中，承命绍继法传事业的弟子为惹却饶(义惹师法深)，惹却饶传耶喜生根(义为慧师子)，次传惹绷生(义为惹师亿师子)，次传迦译师，次传绒巴。协饶生根(义为慧师子)，次传喇嘛耶喜伯瓦(义为慧吉祥)。以上诸师都是证得二次第成就的大师。

继由喇嘛耶喜伯瓦传给法王顿珠仁钦(义为义成宝)，这位顿珠仁钦大师，为普遍传称他是证得能怖金刚成就大师。这位法王，他在做内、外、密、空性等供养，猛利祈祷本尊时，得能怖金刚对他说：“明年我将来到这一地方的村头上，到那时应善作业。”以此法王顿珠仁钦想到他所住地方的村头，有地区名宗喀(即是宗喀巴大师诞生的地方)，那里将有一能怖金刚转世的化身。仔细寻查的时候，在宗喀地方，果然发现路绷格及辛惹阿却夫妇所生灵童。他明白这是能怖金刚的化身，也就再三叮咛他们两夫妇，对这一灵童应当清洁爱护。并赐灵童服用的甘露丸，及护身金刚结等。他亲自前来观看这一化身灵童，也就给了很多财物与他们两夫妇，对两夫妇说：“我需要这一化身灵童，请给我。”就这样宗喀巴大师刚诞生，就已为顿珠仁钦大师所有。

由此看来，至尊宗喀巴大师，真实是为弘至尊文殊教法，及利一切有情，如愿而来的一位大德。并且为了教导后世应化众生起见，不说自己是至尊文殊，仍持凡俗人的态度，依止法王顿珠仁钦为师，很好地听受能怖金刚大灌顶，及所有教授。他年仅七、八岁的时候，就已彻底修完能怖金刚的接近本尊的修行法。后期中，他到前藏，由喇嘛乌玛巴(义为中观师)介绍的因缘，他在至尊文殊面前，听受了很多文殊法类，及能怖金刚教授。继后，至尊文殊为他亲自现身宣说无量显密教法，特别是传授他能怖金刚大灌顶时，至尊文殊刹那现起能怖金刚身，为他作四种全圆灌顶，并教敕阎摩法王做他的护法等，有这些不可思议的神变事迹。

以此作为不共来说，法王宗喀巴大师本身就是真的至尊文殊，不仅如是，并且获得和威两种本尊文殊，为他示现亲传本尊这一大法灌顶及所有教授。因此，作不共近传师承次第祈祷，应当是这样颂说：

“文殊金刚宗喀巴，克主昆仲法金刚，温萨师徒善慧王，祈请赐我二悉地。

证得胜成三宝幢，曼陀罗主善慧智，至尊善慧贤劫海，祈请赐我二悉地。

诸佛悲体慈氏称，至尊善慧具德智，恩德无等本师前，祈请赐我二悉地。

唯一佛父妙音尊，为调一切难调者，故现能怖和威身，祈请赐我二悉地。

愿由此赞至菩提，胜诸违缘四魔军，息增怀诛八成就，一切悉地常丰获。

愿从今至一切生，大威文殊悦摄受，究竟证达二次道，速证三身佛果位。”

由一切智洛桑耶喜传与至尊洛桑格桑嘉措，次传至尊洛桑伯敦耶喜，在这位大德座前，由我(著者耶喜绛称)获得能怖金刚灌顶。

又由洛桑耶喜大师传金刚持师洛桑仁卓(义为善慧智解)，次传金刚持师耶喜伯觉(义为智富)，在这大师座前，由我(著者耶喜绛称)获得能怖金刚灌顶。

又由洛桑耶喜大师传大堪布昂旺洛桑，次传大主座朗喀桑波(义为虚空贤)，在这位大师座前，由我(著者耶喜绛称)获得能怖金刚灌顶。

又由至尊耶喜生根大师(义为智师子)所传“舍”法传派诸师承，次第承传到至尊昂旺绛巴大师，在这位大师座前，由我(耶喜绛称)获得能怖金刚灌顶，及二次第诸教授。

以上所说密集、胜乐、能怖三法承传次第，是就现在普遍传称者而列出的。如果就这些内部来分析，还有由印度很多大成就师所传出的师承次第，及很多译师所传出的师承，与及此中复分灌顶师承次第，及密续经教承传次第，及二次第教授，导修释义承传次第，及本续释续的讲轨承传次第等很多的分类。这些情况，详如《宗喀巴大师闻法录》及《克主大师闻法录》、《班禅洛桑却季绛称闻法录》、《五世达赖喇嘛闻法录恒河法流》、《至尊洛桑耶喜闻法录》等书中所说。
