# 叙修心教授师承概况

于至尊仁达瓦大师座前，至尊法王宗喀巴大师听受了《修心七义论》后，复为无量具缘信众传授。在至尊宗喀巴大师讲授《菩提道次第》的时候，关于修菩提心法，是由“七因果教授”之门而修之法，及依寂天菩萨所作论著，由“自他相换”之门而修之法。两种修法中，宗喀巴大师对于由“自他相换”之门修心法，则依仁达瓦大师这一修心诸教授而做开示。又由菩萨切喀瓦对于这一修心法门，作出七科，取名也叫《修心七义论》。符合这一论的讲义，是由佛子妥默桑波大师所作的《修心七义论讲释》，并传授了《七义论讲释》。宗喀巴大师前往温。扎喜多喀地方时，为大菩萨霍敦巴等很多佛子，广传了《修心七义论讲释》，继由霍敦巴传授给法王根敦主大师，根敦主传授给持律师洛卓伯瓦，洛卓伯瓦传授给班钦。耶喜哲谟，耶喜哲谟传授给交却伯，交却伯传授给嘉瓦。温萨巴，温萨巴传授给克珠桑杰耶喜，桑杰耶喜传授给洛桑却季绛称，洛桑却季绛称传授给拉巴。敦巴达杰，敦巴达杰传授给大成就师洛桑绛巴，洛桑绛巴传授给住旺。却嘉措，却嘉措传授给至尊上师成就自在大师洛桑朗嘉，恩德无比上师洛桑朗嘉座前，由我(著者耶喜绛称)获得这一法恩传授。又佛子妥默桑波大师将此一法门传给大菩萨嘉玛瓦。云敦峨(义为功德光)，从此次第相传，直传至我(著者自称)的根本恩师至尊昂旺绛巴(义为语自在慈氏)座前，由我(著者耶喜绛称)在师座前，详细听受获得这一法恩传授。修心耳传这一师承次第祈祷略颂如下：

“释迦文殊寂天师，唉那达里勇金刚，宝吉祥及金洲师，祈请加持我身心。

拥如意宝燃灯智，胜者生处种敦巴，阐明圣教博多瓦，祈请加持我身心。

胜德名称霞惹瓦，二菩提熟切喀瓦，见行清净嘉瓦色，祈请加持我身心。

唯作利他节却拉，三学清净拉顶巴，三门利他拉顶温，祈请加持我身心。

住诸佛道功德祥，弘扬佛教乐吉祥，善严无比四论师，祈请加持我身心。

利乐生源仁波切，福智力称三千界，慈悲怙主法中王，祈请加持我身心。

第二无著佛子师，雪域顶严仁达瓦，诸佛真体宗喀巴，祈请加持我身心。

胜乘教藏虚空祥，三界教主根敦主，大菩萨师智隐前，祈请加持我身心。

智称文殊交却伯，现证三身温萨巴，彼之长子佛智师，祈请加持我身心。

至尊善慧法幢师，长子夏仲拉巴师，善慧慈氏成就师，祈请加持我身心，

大菩萨师正法海，善慧尊胜根本师，直及再传诸师前，祈请加持我身心。”

又根本上师昂旺绛巴座前，听受法传祈祷颂，佛子妥默大师将以上师承颂为上文，以下师承祈祷颂如下：

“佛子无著贤大师，德光及智增戒盛，福天及福善胜师，祈请加持我身心。

语自在称班钦师，语自在法名称师，岩寺富成业弘师，祈请加持我身心。

一切经论心要义，总摄阐明作开示，恩德无等上师前，祈请加持我身心。”

以此对于菩提道次第，意乐修心的一切信众，为了心中迅速生起自他相换菩提心，应谨向“修心耳传”诸师前，祈祷求加持。并当思念修心承传诸师的清净行传，将所有一切智慧、能力、作为都拧在一起来，不断努力使菩提心未生者令生，已生者令其辗转增上。关于至尊阿底峡尊者，及法王宗喀巴两位大师的心髓精华教授——《菩提道次第》，分显密二者共通的道次第，及不共金刚乘道次第两者中，对于共通道次第来说，由于阿底峡尊者汇合了三种承传法流，以此关于广行派及深观派，与从广行派分出的伟大行派等三派承传诸师的清净行传，已如上概略说完。
