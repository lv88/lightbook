# 八十、大堪布四论师扎巴须鲁的历史

大堪布四论师扎巴须鲁(义为名称童子)在丁巳年(公元一三一七元仁宗延裕四年)诞生在称作“具辫纹”的杰色城中，父名杰色哥巴。他从幼年就对喧嚣俗家生厌，由于厌离生有的出离心的鞭策，他在堪布扎巴绷(义为名称俱胝)师座前，离俗出家，取名叫扎巴须鲁。继后，他心行两种都如理依止大堪布邓瓦伯座前，听受了很多经教和教授。他年满二十岁时，由雅德法王大堪布邓瓦伯为作亲教师，阿阇黎土杰伯桑(义为悲祥贤)为作教导师，阿阇黎却敦伯桑(义为德祥贤)为作轨范师。在丙子年五月，有净信比丘六十人的当中，受具足戒，他守护戒律，如护眼珠。继后，他复在大堪布邓瓦伯座前，听受了三世诸佛所趣之唯一大道——《菩提道次第导释》，及道次所依据的根本——《现观庄严论》，及《入行论》等经论。特别是听受了诸佛的修行心要——《大乘修心导释》，并作修习。复在大堪布邓瓦伯座前，听受了杰岗巴所传的《大悲观音法》、及《不空羂索法门》、《锐利妙吉祥法》、《白色独勇成就法》、《尊胜佛母》、《摧伏金刚》、《药师如来》等随缘灌顶法及很多法行经教诵授，以及《缘念三法门》等。他又在措普阿阇黎四论师须哲(义为童美)座前，很好地学习了《对法集论》、《量决定论》等。又在善巧师云敦绷(义为功德俱胝)座前，听受了《律经根本》及《俱舍》。又在雅德译师索朗生根(义为福师子)前，听受了《胜乐及红阎摩法》等很多经教。又在绒巴。协饶生根(义为智师子)座前，听受了《时轮及阎曼德迦》等惹译师所传的很多法类。又在敦巴。恭噶嘉波(义为普喜王)座前，听受了《时轮六支法类》，及喇嘛珠却(义为胜成)座前，听受了很多密教的法门，闻法的学业达到彻底精通。他在有一次月蚀的时间中，由修“摩沙加行法”生起花朵。略入睡境的当中，得见文殊菩萨现身，问他道：“请我来意欲何为？”他答说：“请将你那宝剑赐给我。”菩萨说：“对你已给有慧剑，你拿这一金刚杵去罢！”如像真实般给了他一支黄金四股金刚杵，由此他心中生起了对于分析经论教义，彻底无碍的通达。

继后，在甲午年，他年满三十八岁时，当上了僧伽大众的主持导领大堪布的职位，他也就对具缘信众广为讲授《律经根本》、《对法集论》、《释量略论》、《般若》等很多经教，以及《大乘修心教授》等来摄受信众。喇嘛达里钦波等萨迦派的裔传诸师，以及布顿仁波切，菩萨索朗扎巴(义为福称)等很多智巧戒严的大师们，都以他为师。他在不可思议的弘法利生事业当中，在下“娘”区的朗毕隆茅蓬，一心专修，对于其他具缘信众，也传授《菩提道次第》，及《修心教授》等很多教法。他年满五十九岁时圆满了这一生度生事业，时在乙卯年(公元一三八七年，明洪武二十年)九月十五日，恰逢月蚀全解的时候，示现圆寂。那时有虹如柱贯入他的尸体，同时天雨瑞花。继后，由冲堆始谟的施主们，齐来迎请扎巴须鲁大师肉身到冲堆去的时候，由布顿仁波切为首率同穿著法衣的比丘约二百人，手持妙香、伞、幢、音乐等种种供养，以及盛大的会众，前来迎接到冲堆城区附近。肉身荼毗时，大降天花，出现很多舍利。在以后的世代中，他的骨灰所制的泥像，及荼毗肉身的余灰烬中，还生出了不少的舍利，发现了这类不可思议的稀有奇迹。
