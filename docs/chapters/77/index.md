# 七十七、甘丹大座主昂旺却敦大师的历史

大座主昂旺却敦大师，在乙巳年(公元一七二五年，清雍正三年)诞生，生处为安多地区的真措地方所属的迦谟铺村中。父名朗索。恰多札喜(义为金刚手吉祥)，母名播却。这位大师从初生起一贯就脱离凡俗孩童习性和行为，常时正身端坐作静修状，及口诵真言等大德的行态。在他的邻近有人讽诵《三摩地王经》及《大解脱经》时，他一听得，对于经义，就能大半领会。继后，他觉悟到居家是烦恼和过恶的生源，出家为一切功德之所依，于是在父母前，再再请求许可他出家，父母也愿成其志。也就前往甲穹却德寺(大鹏寺)中，在堪布昂旺楚称(义为语自在律仪)座前剃度，取名叫昂旺却敦(义为语自在有胜)，复受沙弥戒，他对于沙弥戒学处，任何时中也不犯染。如理依止堪布昂旺楚称座前，学习行法次第诸书，及修现观庄严论等四大论著等，与辩色等启发理智诸法类，不感困难，就能通晓。

由于他往昔长远的薰习力，对于世间任何美满受用，不生贪著，对轮回油然生起出离心，对一切法自然显见其如幻，相虽现有，其性本空。他年满十五岁时，为了绍继宗喀巴大师清净行传，发起前往卫藏求学的愿望，向堪布上师及父母说明他的志愿，取得他们的同意后，也就来到前藏色拉大寺大乘洲分院内，住上院克芒札仓(多善巧僧院)中。由于他是贵族后裔，人们都劝他应取“却哲”位(行法者)，但是他认为摆起大人物的架子，对修学将有妨害，没有听从众人劝意，仍参加僧院中一般学僧行列，依止上师绛称邓珠(义为幢义成)，先学《释量论》，次依据却季绛称大师所著论述来研习《般若》，并结合印藏所有般若论著来作仔细研究，对于般若四种摘要，也都领会于心中后，才到僧会中作考试答题。他年满十九岁时，已将般若听受和研习的学业完成，年满二十岁时，也就游桑朴辩场，对般若立宗辩难。继后，他续上《中观》学习班中，对于色拉杰隼巴所著中观论述，完全领会心中，并仔细研究了龙树师徒等所著中观诸论，及宗喀巴大师师徒所著中观诸论述，成为彻底的通达者。继后，他从二十二岁到二十四岁的三年中，精研《毘奈耶》及《俱舍》两论，成为彻底的善巧者。他年满二十五岁时，在拉萨宏愿大会中，立四难论宗。

继后，他效法宗喀巴大师行传，想得到一切经论，当作修行教授，于是前往色拉哲，在珠康巴。格勒嘉措大师(义为福善海)的座前，听受三世诸佛所趣唯一大道——《菩提道次第导修广释》。对于所有要义，完全能领会的时候，格勒嘉措大师十分欢喜地对他记别说：“你才这样年轻，如果能彻底精修菩提道次第，那么获得证达后，对佛教法，你将成为一位能作饶益的人。”这位大师对于过去所研习的一切经论，一句也不荒废，都取作调伏自心的殊胜教授。并能如阿底峡尊者对金洲大师，认为恩德无比的根本上师那样，他对珠康巴。格勒嘉措，也认为是无比的根本上师。他称师名时，立即双手合十，两眼盈眶的信泪。他从珠康巴大师前，听受《菩提道次第》后，修习所教诸法门时，对于上师的语教，每句都异常珍重，礼拜及供曼遮都如教修积。他没有其他供器，只好洗净瓦器来不断地供水等诸供，使上师珠康巴的净行宗风，得以不废。继后，他想念如能在无量光佛所化现的班禅。洛桑耶喜座前，受得比丘戒，那是再好没有。于是他不避艰苦，放下大人物的架子，所有生活食物用具等，都自己背著前往扎什伦布寺。他一见班禅。洛桑耶喜的容颜，立即如证初地那般喜悦，生起视班禅如佛的真实净信。获得比丘戒后，他心满意足，如亲教师一切智所指示的一切戒律仪，他都守护不犯，成为佛的代表人物。

继后，他续研密教，住下密院中，心行两种如理依止下密院法王根敦彭措(义为僧满)大师，精研密续之王《密集释注教授等法类》及一切母续之主——《胜乐轮续释教授诸法类》，以及《能怖金刚续教授导释等法类》，成为彻底的善巧者。他年二十七岁时，在修夏期间，他虔诚启请大密师根敦彭措，住奇弥传经室中，依照克主杰目录中所出摄二次第导释所有广略施实法要，作详细的教导。这位大密师根敦彭措，他具有《温萨耳传教授》、及《舍派传来的教授》、和《下密院本系所传教授》等三种教授。并且不仅是诵授经文，而是仔细地依直观教法来指授。以此他对于显密两种道次第，获得无畏的定解。继后，他复在绛央协比多杰(义为文殊笑金刚)师前，听受《菩提道次第导释》、及《生圆二次第导释》，以及多种灌顶和随赐灌顶等法要。此外，还依止很多善知识，听受了所有灌顶、传经、教授等法。继后，由于他的父母再三催促，他也就回乡住了四年。

到三十三岁时，他复到藏，仍在大密师根敦彭措座前，再听受密集、胜乐、能怖三法的生圆二次第导释，及《宗喀巴大师全集》诵授等很多要法。他年满三十四岁时，由藏政府委派他为脱顶寺堪布。他前往脱顶升登金座后，对于昔日大译师仁清桑波(义为宝贤)住持脱顶寺时，所建佛像、经、塔，及说修显密经教法规，所有中期已经颓废的，他都完全培修和重兴起来。犹如译师再世，使阿里三区，广宣显密教法，对教法作出了广大的事业。他在阿里住了七年，辞脱顶寺座，前往卫藏的途中，顺道去朝礼岗德色圣迹。在这一圣迹地方中，有过去“噶举派”的很多前辈喇嘛留下不少的手印和足印。他一见著这些印痕时，为了显示宗喀巴大师教法的伟大起见，他也在石上留下足印。继往芒格地区的吉仲(乐城)地方，在自然现出的瓦底让波像前，作了供养，并发宏愿，复在吉仲的普札喀茅蓬上师洛桑却柯座前，听受了很多要法。继来到伯库朝礼伯玛却顶(莲法寺)，他对播栋季乍(义为无畏师)所著诸书，很生喜悦。渐次来到扎什伦布寺，在班禅大师座前，供养了以良马三十匹为首的隆重供礼，并请传授了《菩提道炬论》等很多要法。

继后，他复前往前藏，在成就自在师绛伯嘉措(义为曼殊海)座前，听受弥哲百法灌顶及随赐灌顶等很多要法。又在大密师根敦彭措座前，听受《胜乐根本续》，及其《隐义普明论》本释合编经教诵授等很多深法。继后，他也就升登下密院座主。先是宗喀巴大师指示协饶生根大师：“为了使父续《密集》，及母续《胜乐》两种密续释，以及生圆二次导释等法类，常不衰颓起见，必须建立密宗学院。”协饶生根大师遵宗喀巴大师的意旨，也就建立了以讲说及听受两种密续之王为主，并对于胜乐、密集、能怖三法的仪轨所有施行作法，都按照密续及宗喀巴大师意旨，极为纯洁的密宗学院。在很长一段时期中，虽是得到弘扬光大。但因时变因缘，中间一段时间胜乐法类，特别是听受胜乐法规，已经废弛。昂旺却敦大师发愿振兴颓风，他常时猛利祈祷宗喀巴大师加持，并劝请守护宗喀巴大师教法的怙主明王及护法，执行护教事业，复派遣了几位明智的三藏法师前往温寺，觅得温萨巴大师师徒是如何建立胜乐仪轨施行法规等，取回重建仪轨法规。在原有闻说《密集四种合释》未废的法规加以增大的基础上，重新建立闻说《胜乐本释及隐义普明论本释》的法规。从此每年不断地讲说密续大疏及《胜乐》、《能怖》两种生起次第，以及《五次第明灯论》、《能怖金刚生圆二次广释》。在修夏期间讲《密集生圆二次修要导释》等，并对一些智明求义的法师，讲授八大导释，以此金刚乘教法，获得大弘，总对佛教法，特别对于金刚乘教法，作出了恩德无比的事业。此外，他复在洛色岭(智明洲)僧院洛桑敬巴(义为慧贤施)，及成就自在师邓约克珠(义为不空善成)等师座前，听受了不少的显密经论导释。就这样从丁亥至丙申十年的当中，他住持下密院座主以来，他由财法二施之门，尽善尽美地培育僧院。特别是对于已经废弛的《胜乐》法类，得到他的重新振兴。他为了使胜乐法类长久住世起见，竭力请求藏政府得到新置供修《胜乐》法类的供养基金。

继后，由于一切智达赖洛桑格桑嘉措(义为慧贤贤劫海)，需要听受密教，迎请昂旺却敦大师作他的密经师。昂旺却敦大师也就辞了下密院座主位，接受了作达赖的师傅职，前往噶塔(即康区泰宁)。他在噶塔住的时间中，对达赖格桑嘉措，依下密院的作风，先习供养金刚阿阇黎仪轨，每天传授密续四注合释一遍，及受持密续大疏，这样从初不断传习的当中，复传授灌顶、随赐灌顶、经文诵授等法类。仍依下密院的作风，冬季大都完全闭关静修，从转春起复广传密续经释闻说事业，不仅是诵授经文便以为足。而是对于密续根本与诸家释疏对照合讲，并对其中经义，结合圣龙树师徒所著诸论，及宗喀巴师徒所著诸论，详讲六边及四理的要义。达赖喇嘛也发心总为受持佛的一切正法，特别愿对于无上金刚乘教法，所有已经废颓的，加以重兴，法流还略存在的法类，更加以广弘的增上意乐，特具毅力。以此如大海不厌水足那样，他对上师金刚持广讲多传，仍没有饱满，总是向上增益。师徒在噶塔住期中，所有闻、思、修事业，如夏季海水及上弦月光那样，成为辗转向上增长。这样在噶塔住约两年多的时间中，殷勤地讲授四注合释，达赖心中获得领会。

继后，在返藏起身时，章嘉大师也从内地来到。于是达赖也就在这两位大师座前，听受所有一切显密经教，特别是在昂旺却敦前，复听受《密续四注合释》、及《五次第明灯论》、《八大导释》等所有显密甚深教法，昂旺却敦大师也如瓶注水般尽量传授。继后，来到布达拉宫时，他仍对达赖传授所有一切显密教法。继由达赖任命大师为甘丹大寺座主，登位后护持宗喀巴大师风范，令不衰颓。计在位七年，最后辞座主位，住布达拉宫达赖近前，仍对达赖传授教法，并对很多求学人士，广施法雨。继后，他年满七十高龄的时候，他觅积了超过百两的黄金，对西藏所有一切有加持的佛菩萨像等供上涂金。

总说起来，这位大师如理依止善知识，精研显密一切教法，对成佛正道，以理智引生而获得定解，彻底通达诸宗大海，由于他生起了真实出离心，以此他厌离一切有漏乐，推己及人的爱他菩提心已达精熟，以此他的身语意三门所作事业，无有不是为利他而作。他观内外一切缘起犹如水月，以此已达智慧与方便的彼岸。更由于他已获证显密两种菩提道次第瑜伽，及空乐三摩地，以此摄伏一切空行，诸护法都愿执仆役。由于他住持佛教愿力的成熟，所以能在这末法的时间中，总对佛教法，特别是对宗喀巴大师一切教法要义，都能得到如白昼般那样的光显。再拿他的精修事业来说，他曾经前往岗德色、岗波勒朗、达索乍迦、夏乍岗日、日峨噶登、颇章喀等很多修行圣地，长期闭关专修。大师除最忙时间外，他自从到阿里起，在他一心缘念利他的当中，每年最低限度也要闭关专修三、四个月。他平常精修的次第，是依耳传上师瑜伽，取受四种灌顶，及依《菩提道次第坦途》修菩提道次第缘念诸法类；并修密集不动金刚，枳布师传胜乐身曼陀罗、能怖十三尊等三种广修瑜伽，及其每一种的生圆二次第等法类。并不断地修供，以六臂怙主明王为首的诸尊护法，供垛玛、作广大的回向。供水食百粒等法行次第，及方便法类诸种修法。在下座后未修时间，则作礼拜及供曼遮等加行，以修菩提心为修之主要。平常修各本尊根本咒，特别是能怖金刚根本咒每天诵五百遍，从未间断过。金刚诵法，及瓶息合风修法，也屡修不断。以善说教法来教化众生的程序来说，他自从到阿里以来，一心缘念利他当中，有一、二年除外，其余时间，大半讲说《菩提道次第导释》，广略任说一种，是没有间断过的，只是传授《菩提道次第广论》，就超过十次。讲四注合释的密集续释，共约二十余次；讲《五次第明灯论》，及《胜乐隐义普明论》等大论，有很多次；传授灌顶、经释、传经，随赐灌顶等更难以计数。由他这些事业之门，教法得到大弘。特别是他作达赖的师长，有二十四年之久，将一切教法，如瓶注水般完全传授给达赖。达赖也在一切师长中，是以他为恩德无比的师长。

继后，他年满七十五岁时，在达赖前，陈明由于年迈请假退居僻静处，达赖以伯柯却德(德轮寺)供师，师请求赐热振寺驻锡。达赖对师十分怀念，亲往大师所住静室中，省视师长身体及语言情况，再再恳求师长住世，勿往他方刹土，并在诸大圣地佛、塔等前，大兴供养，以三大寺为主的各寺中，放施僧众茶饮，命修法事，诸静修寺院中，命为师修长寿法事。再再嘱医细心治疗，尽量供诸妙药。虽是这样，大师仍请求达赖说：“现在请决定准老僧前往热振寺，作最后圆寂地。”达赖亲到大师静室中，请求说：“请师不必这样说，伯柯却德寺已供师，热振寺也如师愿供养，仍请师长住此布达拉宫中。”并以隆重供品作代曼遮供养。达赖虽是悲泪满眶，殷勤恳求，但大师说：“深谢慈恩！老僧从幼学法，承事宗喀巴大师圣教，彻底求学，对思修两种，也励力而作，清净的修悟证相，也常显现。特别是对达赖佛座完成传授显密经教任务，以此我心很安。”达赖除再请师一切生中，都赐摄受外，不忍再听下去。

在大师将前往热振寺的晨间，天刚亮，达赖喇嘛就亲来大师静室中，师徒二人说不尽的话，彼此不忍分离，掉下不少的悲泪，彼此互求加持。大师以他如受比丘戒时所佩佛像那样珍重的主要佛像——极有加持的“至尊空行佛母像”一尊，供赐给达赖，启请说：“愿佛座长久住世，事业宏昌，于一切生中对我永作摄受。这也就是老僧的祈愿，请慈悲摄受！”达赖喇嘛也很好地表示如愿应允。大师突然站起来一直走到室外路口地方。在作送行的时候，达赖喇嘛的头紧贴大师胸间，作了很久的发愿祷祝，同时落下悲泪。请大师坐轿直到布达拉宫大门附近，大师对达赖喇嘛的侍膳长札巴塔野等内侍“仔仲”(官名)等人，说了很多教导他们的话。于是渐次来到热振寺后，享寿七十五岁，在未年(己未公元一七九九年，清嘉庆四年)八月初七日，命设高座，大师登座安住，达赖喇嘛特送来修法加持的净瓶中水，及舍利等物。到了初八日上午，大师双手合十向布达拉宫作礼，中午时天空细雨蒙蒙下降，大师结跏趺坐，手作定印，身躯端直，渐次经三空相合过程，进入现证一切空光明法身，脱粗分色身躯壳，而现起智慧身具七合德相。无边净土中难以数计的勇士空行齐来供养迎接，往生兜率至尊弥勒座前。

意乐修行菩提道次第的人们，应谨向大座主昂旺却敦大师祈祷求加持，并应效法他的清净行传，对于显密两种道要，每日如恒励力薰习，必须获得清净定解。
