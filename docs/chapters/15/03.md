# 附三、阿阇黎那迦菩提略传

梵语名为那迦菩提，在藏语为鲁衣绛秋(义为龙菩提)的这位大德，他依阿阇黎龙树的教授精修，证得虹身金刚身，在吉祥山等静修圣地安住，摄受无数勇士空行，及具缘信众。在噶当派前辈时代中，曾见这位阿阇黎为噶当诸大善知识现身，而开示教授，并作出了许多随缘赐教的事迹。他常和大成就师法金刚相聚会，谈论金刚乘要法。在班禅洛桑却季绛称(义为善慧法幢)修建静和宝塔，开光时，这位阿阇黎龙菩提和法金刚两位大德亲自现身而来，同坐塔顶而作开光法事。并对班禅洛桑却季绛称开示教授及随许法。这位阿阇黎著作有《密集曼陀罗仪轨》，及《示三身道用殊胜建立次第》，此外还著有不少的其他论著。
