# 附六、阿阇黎清辨略传

他是为了阐明甚深中观妙道乘愿而来，做圣龙树的首要弟子的一位大德，共同传称他是圣须菩提的化身。这位阿阇黎为了阐扬龙树妙道，著作了《中观根本般若灯释》；此外，他还著有其他不少的论著。这一《般若灯释》成为“中观自续派”所依的论著的原因，是由于圣龙树所解释佛密意的中观究竟见，很难通达，为了引导应化众生渐次能通达起见，运用善巧方便而著作的一种论著。

圣龙树在赡部洲中住世六百年来，大弘佛教，以此他一生初中后三段中，次第出有很多弟子。在他此生后段期中所出的首要弟子，成为一切持教大师的顶宝般的大德，则是阿阇黎月称。如过去一些佛教史中所说，圣龙树在他临往极乐刹时说：“最后弟子为月称，末为宣说无生法。”这位月称大师对佛教作出怎样的事业情况，当随即在下面详述。

圣龙树住世六百年中，大弘佛教后往生极乐刹中。据说在赡部洲中，往昔他身躯和头首渐次合拢来复作弘法利生的事业。最后，他于信光世界中，现证圆满正觉，名智慧生源如来。

以此意乐修行菩提道次的人们，应当谨向具德怙主圣龙树虔诚祈祷求加持，并应遵从这位伟大的阿阇黎所说的那样，从依止善知识起，直至双运位之间，对于整个显密全圆道体，由教及理二门获得定解，而努力勤修。
