# 附五、阿阇黎佛护略传

他降生在印南，当缚那的分区名鹅游的地方中。身入佛门出家受比丘戒，精研三藏及四部密续教义，由此通达如海般的自他各宗教理。他依止圣龙树座前，听受了所有显密诸教授而努力精修，以此获得成就，亲见至尊文殊本尊，并由道次第迈进，而获得很高果位。他为了利益圣教，阐明圣龙树甚深究竟密意——甚深缘起千百理智，而著作出《中观根本释》，这一论著通称为《“菩达缚里达”中观根本释》(阿阇黎月称及至尊宗喀巴大师广赞此论著，在一切中观根本释中，如法幢的顶髻般是最为殊胜的)。此外，他还著有不少的其他论著。
