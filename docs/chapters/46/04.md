# 附四、宗喀巴大师专修时本尊所记别的八位弟子简介

宗喀巴大师离世事专修时，至尊妙吉祥所记别的八位清净弟子计有喇嘛绛噶瓦。伯敦桑波(义为吉祥贤)、上座桑炯瓦(义为贤护)、上座仁清绛称(义为宝幢)、上座绛生瓦(义为菩提狮)、喇嘛绛伯嘉措(义为妙吉祥海)、善知识协饶札(义为智称)、善知识绛伯扎喜(义为妙德吉祥)、善知识伯觉(义为吉祥护)等人。这些大德，都是往昔长远生中，得宗喀巴大师摄受，共同发宏愿。都见一切世间如火如荼，厌离轮回中所有欲乐，不为自利的解脱涅槃，而完全为利他有情发慈心悲心，修行于佛子行海中，全无惧怯。并能观三有如干闼婆城，运用智慧之火，烧毁我见薪柴。一切生中都得到至尊妙吉祥的摄受，具足内外一切因缘，以此刹那刹那都趣向地道果位。对宗喀巴教法美严光大。成为诸佛菩萨所赞美的福田。这些大德一一生处，以及每位大德一生事业，如果详细写出，将发生累赘篇幅之嫌。其中喇嘛绛伯嘉措(上师妙吉祥海)的史事，由于此师列入菩提道师师相承传中，以此他的史事，将在下面详说。
