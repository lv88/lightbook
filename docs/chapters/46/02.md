# 附二、首要弟子持律师扎巴绛称略传

首要弟子持律师扎巴绛称(义为名称幢)，此师从无量劫以来发菩提心，从学习佛子行海中，为在西藏弘扬宗喀教义，乘愿而来的一位大德。此师于甲寅年(公元一三七四年明洪武七年)降生在乌堆区(前藏上区)丈村中，从幼年即依止止贡法王而出家。在很多善知识座前听受显密无量经教。特别是长期依止在一切智宗喀巴座前，听受总摄三藏及四密续经论要义的菩提道次第教授，精勤修学，生起彻底通达，并对摄四密续诸本尊瑜伽粗细诸法要，努力勤修，显现真实曼陀罗，修证通达生圆二次第诸教授。对三种戒律，哪怕是细分极轻罪过，也守护不犯，以修菩提心为主要修行，以此成就具足教证功德藏，成为法王宗喀巴大师的首要弟子。所有宗喀巴门徒对此师如对宗喀巴一般恭敬，都领受其教法之恩。这位大菩萨观察到一切福德之本，都是由如理依止善知识而来，以此他在宗喀巴座前，是常时以三种欢喜来使宗喀巴大师极生欢喜。特别是任于何时能依师教而行。当修建甘丹寺时，他依宗喀巴所嘱而作，对于修建殿堂，及诸修定者所居茅蓬等工作，不避艰苦，勤作不懈。并且最初观察地基，其次启白僧众，僧众许已选派授事人，从建房轨则，乃至佛殿、经、像等，都依律所说而作。承担责任，直到完全修建成功，迎请宗喀巴大师来寺，大师一见心生欢喜。总之，在能作、所作、作业三事中，无不使上师心生欢喜。

后来，宗喀巴大师示寂时，此师不作继承祖寺师座，而由贾曹杰来继承寺座。此师造檀棺装置宗喀巴大师肉身，复用十八个白银大元宝来铸造套装檀棺的外棺。并奉安大师灵骨在佛殿墙外突出的塔殿中，广大供养。修诸佛事等任务后，为完成宗喀巴大师意愿，他特建祖谟察寺，自己主持教育僧众八百余人。此师间或驻锡邦萨等寺院及其他山中茅蓬，作弘法利生及静修事业。有一时期，去到察贡塘寺讲授戒学及菩提道次第。以此察贡塘一切僧伽都持戒清净，并学修上士道法。这是从持律师扎巴绛称的恩德中而养成察贡塘寺最好宗风的。这位菩提萨埵大师，显见是宗喀巴大师受命的一位密教及戒律法流传承大德。他为使宗喀妙善讲说轨范不衰起见，著有《戒律学处广论》、《沙弥学处》、《三事仪轨作法》、《毘奈耶说集》等论著。《宗喀密教修法曼陀罗等补遗及作法》、《开光仪轨》、《胜乐轮外供》、《密集不动金刚略供中前生供养法》、《枳布师传五尊修法》、《大轮本尊曼陀罗修法》、《鲁亨巴师传曼陀罗仪轨》、《红黑本尊修法》、《金刚界曼陀罗仪轨》、《毘卢遮那仪轨》、《密教净治三恶趣诸说》、《事续部三种仪轨作法》等很多论著。

这位大德的不共(秘密)史事及本生事记，在大堪布勒季多杰(义为业金刚)启问秘密主，及喇嘛乌玛巴(中观师)启问至尊妙吉祥，又喇嘛绛伯嘉措(义为妙吉祥海)启问至尊弥勒等记别，大致相同。大体是这样说：阿阇黎扎巴绛称多生以前，生为“切乌哥滂”(义为职位童子)时，对消除邪信如来所化身的一位辟支佛，供养上妙食一钵，祝愿从此一切生中住持诸佛正法，为边地众生宣说正法，安置此诸众生于三乘道中。以此愿力，六生中都生为边区国王，为无数众生宣说三乘法轨，安置众生于正道中。继此生为出家僧及善巧三乘的比丘，以及智明善巧的班智达等多生中，都为无量众生宣说正法，作广大利益有情的事业。继此生为三十三天天子名细瓦朵(寂顶)，作出度化无数天人的事业。继此即降生于此间西藏。此师将在西藏以诸宝建造弥勒身像，上妙庄严，宛如绘像。并为获得至尊弥勒的摄受，回向佛教隆昌，发广大宏愿。由于这样修力，使得此间佛教与众生都得到广大利益。依菩提心的力量此师将生起特殊通达，播下了法缘善种，以此将出现不少能依显密教义修学、住持佛法的弟子，对于一切有情，发生广大利益。功德美名遍于十方，佛教诸法门，将得到弘扬光大。此后将往生兜率为至尊弥勒的殊胜弟子，名天子嘉色领波(静藏菩萨)，作广大菩萨行，利益众生，最后成佛号绛比旺波(义为慈王如来)等语。这是大堪布勒季多杰亲自问于金刚手而说出的记别。至于喇嘛乌玛巴(中观师)问于至尊妙吉祥，所示记别，大体如上面所说。

后来，喇嘛绛伯嘉措，长久祈祷至尊妙吉祥，他启问妙吉祥菩萨，关于阿阇黎扎巴绛称前后诸生本事，以及对此间西藏佛教能作怎样的利益、享寿多少、驻锡何处能利众生与增益修行，至尊妙吉祥记别说：“扎巴绛称过去多生以前，生在印度为婆罗门子名哥滂时，供消除邪信如来所化身的辟支佛上妙食一钵，祝愿自己一切生中受持佛正法，生边区地方，度化难调众生，宣说正法，安置彼诸有情于三乘正道中。以此愿力，他多生为边区国王，作出度化无量难调难伏众生的事业。在释迦世尊降此世时，他生为比丘杜瓦朵(义为戒顶)，成为一位善巧三藏之大德。从此以后，多生中都生为班智达，以及出家僧，善巧三乘比丘等身，在那时即与四论师生起师徒因缘。此后往生三十三天，生为天子名细瓦朵(义为静顶)。此后，即生在此间西藏。在此由于过去与四论师有师徒因缘，获得无上坚固敬信，依菩提心获得生起殊胜现证，宣说清净显密教义，对佛教将能发生广大利益。由于多生中，白色不动如来是他的本尊，以此生于西藏以来，本尊都仍然摄受，亲自或梦中，常为他示现。光明母多次为除灾障。多生中得著密集及黑茹迦的加持。三生中虽是都得到白色妙吉祥摄受从而加持，但因对一犯戒者授灌顶，因此略生灾障，应修忏净法来化解。又以诸宝书写《妙吉祥增慧陀罗尼》一百遍，出资请人诵修，并祝愿祈祷加持，能利益其他有情。享寿不过六十多岁，最后往生弥勒法座前，名寂静藏菩萨，并与四论师相见，共住在胜乘法会中。”

这样的大德扎巴绛称护持宗喀巴大师善妙宗风，使不衰颓中，作出广大弘法利生事业；仅是持律美名，对于佛教也生起增益。这位大德此生应化事业圆满后，年满六十三岁，岁次丙辰(公元一四三六年，明正统元年)五月二十日在宗谟察寺中圆寂，往生兜率法院弥勒妙吉祥藏座前。
