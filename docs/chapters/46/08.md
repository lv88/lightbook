# 宗喀巴大师简略年表

宗喀巴大师丁酉（元至正十七年，公元一三五七年）十月廿五日生。

七岁起在大德顿珠仁钦前受得能怖、胜乐、喜金刚、金刚手等灌顶，并熟修仪轨，梦见本尊。

十六岁起得顿珠仁钦资助到卫藏地区，学习广大经论，及二大车轨诸经论，在家乡安多地区早已熟习慈氏诸论，并为他人讲说。

十九岁起即广游桑朴、极乐寺等大辩场立宗，此后仍听授经教，及立宗辩论。此后得恭噶伯瓦介绍其弟子仁达瓦座前，学各经论，并为众讲《集论》，并随众上殿诵《般若经》即能一心专住性空三摩地。继在萨迦寺立四难论宗，很多三藏法师均起敬信，求作弟子，二十岁受具足戒。

此后著作《现观庄严论广释》，复继作听闻、讲说事业，特别是为众每天从早到晚讲十五部大论，后增二部共十七部大论，三个月讲完，下座后仍修能怖二种次第、及胜乐法、督谟风息和合等，生起很多内证功德。

此后邬玛巴与宗喀巴大师相会，彼此互传法要。宗喀巴大师从早就有求学所有圆满密宗经教的意愿，申年同邬玛巴在嘎栋寺闭关专修，在此其中复听受很多文殊菩萨法门。

宗喀巴大师想到依圣龙树父子的究竟正见，以及《密集五次第》以及此中极难通达的幻身道次第，通达则能获大义，不通达则易堕邪见险处，以此大师不怯艰苦，求师问法，并得文殊菩萨亲示应成派中观正见及显密共与不共的差别，及五次第中极难通达的不共要义。

此后文殊菩萨指示宗喀巴大师应舍事专修，从此亲见文殊。三十六岁时带八大弟子到阿喀地方却隆寺舍事专修，并对克主杰说："我从现在起将进入如《华严经》中诸大菩萨那样的佛子行，毫不畏怯。"

此后修精奇寺。

此后与上师南喀坚赞相会。（时上师已七十五岁）

此后大师作整兴戒律事业，一切依戒而行。

此后感觉到有著作《菩提道次第》的必要。

此后大师祈祷文殊，细研教理，得到加持，并获得佛护所著《中论释》适当修习，于是获证龙树师徒正见，而造《缘起赞》。

此后大师广为很多三藏法师及大众讲显密经论。

此后大师到热振狮子岩闭关专修，并经众劝请造出《菩提道次第广论》，造论时获得诸菩萨的加被，护神等也来助顺缘。在著完广论后对侍徒们说："我今后想讲授密法。"

此后大师闭关专修，得文殊菩萨指示，嘱对于龙树所著《密集教授建立次第》作释论，大师如命著作总示五次第教义，特别开示第三次第幻化身修法等不共教授，过去古德多年示说也只说其少分。

此后大师应请著作了开示整体四部密续的大著《密宗道次第广论》及《能怖金刚胜伏魔军》等仪轨。大师在专修中，任来何种因缘，都不能使内心散乱，大师说此种功能，是从在绛巴岭修法时生起的；至于一心注观修的时候，也生起这种功夫，是从来就是这样。

此后明永乐遣使迎大师，大师辞谢而派大慈法王赴中国。

此后从丑年大师培修拉萨幻化寺，直到第五年神变节完工，于是兴供养大会，直沿传到现在。

此后大师建甘丹寺。

大师著作全集内容约一百二十种。

大师示寂期己亥明永乐十七年十月二十五日（公元一四一九年）。
