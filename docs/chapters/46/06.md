# 附六、大慈法王释迦耶喜略传

大慈法王释迦耶喜(义为释迦智)，这位法王于甲午年(公元一三五四年，元至正十四年)五月初一日，诞生在察贡塘地方察巴嘎巴官家中，幼年时能记忆起多生史事，虽具有这样通达功德，但仍然依止很多善巧上师，精研一切经义，得彻底了达。特别是在宗喀巴大师座前，听受很多显密甚深教授，而成为智王。当时中国大明永乐皇帝闻得宗喀巴大师的美名，为迎请大师到中国内地，特派胡辛等四位大人为首率领捧金书上谕使者多人，携带皇帝召命及丰富供礼，来藏迎请宗喀巴大师。那时宗喀巴大师正在色拉寺闭关专修，捧金书上谕使者虽已到来，最初大师暂避隐寂静处，没有令使者等见面，后经再三上书请求，大师才来到色拉和使者见面。收受供礼后，大师对来使详细说明他到中国内地灾障很大，利益不多的原因。于是派与中国皇帝有缘的弟子绛清却杰(义为大慈法王)代表大师应来使的迎请，同四位大人及一行多人，从康区南方理塘，渐次顺道来到中国明帝宫中，和永乐皇帝相见。

永乐皇帝对法王也十分崇敬，隆重供养。并降下旨意：“在中国内地，弘扬宗喀巴大师所示佛法心要，并供修总一切显密要法，特别是四部密续诸大曼陀罗。”于是大慈法王遵命从新年二月初头开始建立密集、喜金刚、胜乐、大千轮、九面阎曼德迦、药师佛等供修加行仪轨，从初九日起一直供养诵修了三个月之久。发现修法瑞相，如空中出现天乐之声，五彩虹光环绕，状如宝幢、金刚轮、各种莲花、金刚杵等相，为僧俗大众所共睹。晴朗空中，出现天雨花等瑞相。永乐皇帝自己也常在梦中，梦见海音寺(译音)空中，现起十方诸佛菩萨。法王自己也亲见曼陀罗中诸本尊容颜。从此永乐皇帝更生起无量信心，供法王以金轮印等无量隆重礼物，并赞颂法王功德。此后，为了增益永乐皇帝福寿，特为皇帝灌佛母所传长寿法灌顶，及大成就者德诺巴所传胜乐驱除死厄(长寿)灌顶。当灌顶时用净瓶置于皇帝头上时，甘露自然盈满，溢出瓶口，灌顶仪轨中所用的长寿丸等物也发出灿烂的光明，种种修法瑞相，为众目所共睹。永乐皇帝认为十分稀有，心生大信。特供法王以金银诸宝严饰的座位、凳椅、足榻、座垫等无量供物。法王复为中国内地及蒙古地方所有出家众传授比丘戒；为在家大众传授近住斋戒、优婆塞戒。并随各人根机宣说佛法，使宗喀巴教义，普遍弘扬于各方。此后，由各方前来拜谒法王的喇嘛、长官、大小僧俗人等，隆重供养法王，恭敬承事。法王也随其根机传授出家比丘戒，以及灌顶、传经、讲授修要；并授近住斋戒、观音斋戒等，使各各愿望均得圆满，令其成熟，获得解脱。

继后，法王上书永乐皇帝，以须得叩谒宗喀巴师颜，供养承事，并须启问很多甚深法要，请求准假返藏。永乐皇帝准如所请，并派使者及人员多人护送。于是从县省(译音)大道渐次来到理塘的绛佳却柯等处。复由此西上到达前藏色拉与宗喀巴大师相见。当即供上永乐皇帝所赐各方所制丝织佛像、美如林园般的帐幕、金银所制曼遮(坛供)上堆诸宝、大批各种绫罗绸缎等物，并恭敬祈祷，请师长久住世。又在拉萨释迦像上供涂金，及项饰璎珞、各种供具。又于以甘丹寺为首的一切僧伽大众前，供施茶饮等物。在遣返护送人等回中国的时候，上书永乐皇帝，问安好。在过去宗喀巴驻锡色拉寺时，法王虽已在大师座前，听受过《根本智论》、《辨了不了义》、《四百颂》、《菩提道次第》、《密道次第教授》、《根本十四重罪》、《事师五十颂》等很多要法，现在复在大师座前，听受《密集释明灯注》等，及一些密集经文传授、五次第教授、六加行详细讲授、《时轮广释无垢光论》极详讲授、那若六法、《入中论》、《释量论》，《胜乐根本续经》等无量深广要法。从此每年都上书永乐皇帝问安好，并赐正法教授，令辗转增上。永乐皇帝也每年上书法王并赐隆重供物。

此后，到宗喀巴大师将示寂的时候，大师由堆隆的巧清而渐次来到哲蚌寺，复由哲蚌来到拉萨的时候，法王这里立即准备好迎接大师法驾前来色拉。恭迎大师驻锡色拉后，极端恭敬，承事供养。那时，宗喀巴大师对大慈法王详细教诲，嘱咐在色拉寺设立僧伽后，必须建立一说修并重基础，特别是西藏讲说清净的密续经教久已废弛，虽是有宗喀巴所讲言教甘露，使具慧心者得以饱尝，但是现在看来，专为讲说与听受密续部教义的学院，过去是没有的；以此如果能建立一讲说与听受清净密教的基础，那是再好没有。大师这样一心以圣教为念，发起这般猛利愿望的时候，也就对大慈法王嘱咐在色拉寺建一所讲学胜乐与密集的密宗院。大慈法王当即允如师命，将这一重任负担起来，也就吩咐在色拉大乘寺内建立一所以清净戒学为基础，专为讲学密集与胜乐根本密续的学院，并选出行法首要当事人等。为了令缘起殊胜，宗喀巴大师特在寺中修长净斋戒法，并讲说两种密续王经的首篇，各讲一座，以作缘起。

过了不久，宗喀巴大师示寂，法王谒大师灵，供上项饰、明灯等广大致祭供养。色拉寺中，法王亲自作主率同众多僧伽开建密集、胜乐、阎曼德迦三种曼陀罗。对上师与金刚持无别座前，供奉内、外、密广大供养，并行自入法，传授灌顶等，及守护清净三昧耶与戒律。这样不仅完成了自己的心愿，并使上师智慧之灵得见生喜，同时发起任于何时与师永不分离的大愿。由此天空常时出现虹霓，天雨花等很多稀有瑞相。子年十月间在甘丹寺中，由很多持密金刚大师供修无量曼陀罗，供纪念节日盛大供养的时候，藏王朗喀桑波(义为虚空贤)在惹喀扎迎请以大慈法王为首的很多善知识，前来作纪念日(宗喀巴圆寂日十月二十五日)广大供养，并发愿祈祷。当时，天雨诸花，有如珍珠色样花雨，细花雨堕地如积雪般，此外有六瓣雨花，其中有一些是白螺色、一些是金色、一些是黄丹色、一些是靛青色，其大如掌，大量降落。大慈法王作圆满宗喀巴大师意愿的供养，而发现这样稀有瑞相的原因，这是由于大慈法王是获得宗喀巴大师加持的得意弟子，与众不同，才有这样的象征，这真是稀有的史事。

此后，大慈法王再度应永乐皇帝之请，去到中国，对永乐皇帝尽量布施法物，使其满意。并在中国示现很多神通事迹。同时使宗喀巴无垢宗风，得到普遍弘扬于各方。由于宗喀巴大师的慈悲与大慈法王过去的愿力，计从永乐起到宣德之间，经四代王朝，师长与施主的供施因缘，始终未断。大慈法王享寿八十二岁，在乙卯年(公元一四三五年明宣德十年)十月十八日，向格西阿谟嘎及索朗协饶(义为福智)两弟子，吩咐了很多话后，随即闭关静修，于二十四日，在卓谟喀圆寂。由很多善知识，为圆满意愿，修广大善行与供祭师灵法事四十九日。那时，天空出现虹霓，天雨诸花等稀有瑞相。由格西伯敦巴为首召集很多善知识及大臣、文武长官、僧俗人等，在察萨地方荼毗法王肉身。当由格西伯敦巴举火，仅一作举火姿势，其火自燃。当时天空出现五彩虹霓，结为伞盖、幢幡、八吉祥相等瑞相，满布虚空，为众目所共睹。

总说起来，如前面所说宗喀巴大师的一切得意弟子，都是持戒清净，以菩提道次第为修要，进入地道诸果，辗转增上。有一些已证道究竟，示现化生，再作利益众生事业。这些也都是不染犯戒垢秽，具足教证功德，弘扬佛教事业的大德。在这里不能一一详细写出。至于克主·玛尾利玛格勒伯桑(义为善成说日福德贤，即克主杰的全名)，以及坝索·却季绛称(义为法幢)、杰伟。协饶生根(义为智师子)、一切智根敦珠巴(义为僧成)诸大德，由于列入本著《菩提道次第师师相承传》中，以此他们的史事，将分别在师师相承传中述说。

意乐菩提道次第修心的人们，应当对于诸佛菩萨的悲、智、力三者的总聚体——法王宗喀巴大师，勤行祈祷，并效法大师任修何种法要，都根据大车轨诸经论所出的无垢理智来获得决定，继住寂静处所依所得定义，解决疑网，专修法要。同时守护教之根本——别解脱戒，如护眼珠的当中，取一切佛语及大车轨诸经论作殊胜教授。不是爱乐于道之单一支分，而是对整个圆满佛道都作研习；更不是视显密两教为相违，势成水火，而是能显密互助，于法益彰。这样应对从依止善知识法门起，直至究竟果位——无学双运位之间，整个圆满道果，自己心中，每日尽力精勤不断薰习修行为极要！
