# 附五、妙音法王扎喜伯敦略传

妙音法王扎喜伯敦(义为吉祥德)，这位大德在己未年(公元一三七九年，明洪武十二年)生于桑耶地方，哲当寺中出家后作掌管座位次序者。在桑朴，梁阁仁桑(义为宝成)及敦玛。根却生根(义为宝狮子)二师前，听受《现观庄严》、《因明》。在觉摩隆寺大堪布四论师座前，听受《毘奈耶》、《俱舍》等。在甘丹寺宗喀巴大师前，听受《辨了不了义》、《入根本智论》、《菩提道次第广略两论》、《密道次第广论密集根本续释明灯论》等，五种释论、略论、经义合释、次第建立、金刚萨埵修法、五次第、加行要略、五次第明灯、五次第修座圆满、胜乐欢喜金刚法类、瑜伽法类等，对于经论广大多闻，以此智慧博通，难有比伦。宗喀巴大师为作亲教师，持律师为作羯磨师，贾曹杰为作教授师，使他得受具足戒。

一切智宗喀巴大师先后命这位法王，及敬法藏王朗喀桑波(义为虚空贤)师长与施主二人，建立寺院。法王在梦中也梦见有一名朗特噶波(义为白天陛)的天神，对他指示建寺地址说：这里你将得一寺院，我供赠你五千出家众。法王立刻走过那里，见有名叫“受用泉”很多池水。特别是见著大象山梁处有很多池沼，池边坐著宗喀巴大师向他说这些池水名“闻思池水”，汝可取饮等稀有象征。在这样内外缘起都顺适的时候，法王年满三十八岁，岁次丙申的那一年建立起哲蚌寺(米堆寺)，法王亲自住在这一大寺中，选出各扎仓(僧院)教导师，由信喀勒乌每年兴立大宏愿会与白伞盖法会，并如律建起夏制、冬修，对僧房、讲说、听闻法院中，供养衣服饮食用具等。

确是如贡巴玛瓦所记别那样，法王对于各僧院整兴戒律，闻说两宏，所有事业，辗转增上。并开讲关于显教经论八大部，每部配合藏文释论来讲，总的说来共讲说一百三十部大论。还常时专修密集圣传教授鲁、那、枳三师承传胜乐法门、欢喜金刚法、三种阎曼德迦法、度母等很多本尊法门。每天不断念诵文殊菩萨五字真言两千遍、《文殊真实名称经》三遍、大悲观音六字大明咒一万遍、后来发展到两亿多遍。法王曾对一学习法相者说：“持诵六字大明咒以我为最多。”由于专修本尊的修力，他常时见得自己头上现有文殊，右方有龙树，左边有寂护，前面有宗喀巴大师。在梦中也时见龙树为首的诸德围绕，有法王松赞岗波及其王妃等，有宗喀巴大师、智慧六臂明王，护神兄妹，四大天王等前来摄受，不可思议诸瑞相。由于依宗喀巴教授，完成二次第瑜伽修行，内心生起乐空无别，甚深圆满次第功能，亲见五色光明现起等证得幻化身的象征。这在一位通达密续经论的大成就者看来，确是不可思议的史事。以法王现时的作风来说，他所获得的财物，分作三份，以一份作购买书籍和建造佛像、经、塔等之用；以一份为救治一切患病者，作施药的费用；以一份作修缮僧房住舍及教养门人之用。

此后，法王年满七十，岁次戊辰冬季法会终结的时候，应哲康瓦的迎请，前去住了几天，仍返哲蚌寺，说法两座讲完《集学论精进品》的末篇。看来这是示精进终结的意思，是暗示在哲蚌一生到此终结的征相。从这时起法王也就身有小病，但是哪怕行动已经困难的时候，法王仍然一心想念弘法利生的事业。渐次去到信喀过年，并赶赴拉萨宏愿大会，朝拜释迦及不动如来两尊佛像，及十一面观音等像时，说道：“不知今后是否再能到此朝拜？”猛利地发无量宏愿。就返哲蚌寺之便，在布达拉宫住了三天，有一时间当他坐在朗索施主的座垫上说道：“宗师现证如意树，示说此义上师恩，念时信泪每长倾。”并说：“不能洞悉两位师长的内心，远离《五次第明灯》的密意，是因此而堕泪！到如今能演说此义者已很难得，虽是有一根清净的教尾，但没有能握持著这根教尾的人，现在我的口才力量，已是这般用尽。”说不成声，泪如雨下。朗索王臣们都也因此感动而堕泪。后返回哲蚌寺中，朗索王臣及弟子大众都经月广大诵经修法祈祷，并请求法王住世，法王答道：“昨天宗喀巴大师来此邀我到中国五台去，现在正启请宗喀巴大师讲说三藏及四部密续。”说而举手加额，合十顶礼，同时悲泪长倾。

继后，在二月末有一晚上，法王对侍众等说：“我梦见宗喀巴大师前来，赐我一铃，说这是文殊亲手用过的铃。”并说：“现我们师徒二人共住一起。”以此虽不知何月何年，但显见是以月为期。此后到将圆寂的象征现前时，法王到自住室中，结跏趺坐，手作入定印，专注三摩地中，体温从下身渐次收摄而上时，他亲见文殊菩萨现身前来，命将文殊菩萨画像挂在前面，有问：“至尊文殊是否已来？”法王眼不作观看，但以点首作顶礼。过了一阵，想来是不须念想，命将文殊画像移挂在他的身后左边。总之依命将画像挂在身的左上方后，这样过了几天，以身体的神色来揣测，或许也生起了一些幻相。在己巳年(公元一四四九年，明正统十四年)四月十八日，法王方往生兜率弥勒内院至尊妙吉祥藏座前。

法王为了利益后世应化众生起见，阐明宗喀巴意旨的著作，计有《一切智宗喀巴大师秘密史事》、《初业有情易修般若无倒圆满教义》、《在热振宗喀讲授集学论笔录》、《甚深道猛火教授指南》、《法王日常课诵文殊赞》、《时轮本续释分解》、《略示胜乐略本密续五十一品中第一品经义》、《密续王密集圆满次第五次第圆满座导修教授》、《密集五次第圆满座导修讲义中隐义备忘录》、《密集五次第圆满座导修讲义》、《密集五次第明灯论中一些讲说》等不少的著作。妙音法王圆寂时，天气晴朗天空出现白虹，以及五彩虹霓交织成幕，出现在哲蚌与甘丹两寺间，天雨花等瑞相，为众目所共睹。为哲蚌说法院长住缘起，法王肉身装入银塔内，奉安在哲蚌寺佛殿中，作供养福田。
