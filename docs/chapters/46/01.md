# 附一、首要弟子贾曹杰·达玛仁清略传

首要弟子贾曹杰·达玛仁清(义为盛宝)，这位大德自往古以来，即生起菩提心，从学修广大菩萨行中，为在此间刹土从弘扬文殊菩萨即宗喀巴大师教法，乘愿而降生此土。这位菩萨所降生的地方，为很多大德所加持，具有多种吉祥象征的后藏娘堆区日浪地方，又叫日浪区“弄纳卓切”。此师于第六甲子的甲辰年(公元一三六四年，元至正二十四年)在很多吉祥现象中而诞生，父亲为坝大臣的后裔，名达本巴，母亲名觉谟协饶。满十岁的那年，岁次癸丑，在勒宁大寺中，请大堪布仁清绛称(宝幢)，及扎妥巴。须鲁楚称(义为童戒)两师为作和尚及教导师，受得沙弥戒，赐名为达玛仁清(义为盛宝)。从此在和尚及教导师前，对于所受的别解脱戒学，守持如护眼珠。并在阿阇黎伯贡巴座前，学习念诵和书写藏文。次依智王恭嘎伯(义为庆喜吉祥)为师，精研《释量论》及《量决定论》等一切本释各论。又依智王日浪巴“仁清多杰”(义为宝金刚)为师，研习《般若》诸经论。又依智王正玛扎喀瓦。法王顿珠仁钦(义为成义宝)座前，精研《俱舍》、《集论》。此师为娘堆人，与宗喀巴大师受沙弥戒时的和尚法王顿珠仁钦同名，而实非一人。又依智王洛卓让波(义为智贤)，一般称作四论师洛色(义为智明)座前，精研《毘奈耶》。此外，复依止诺钦交却伯桑(义为胜依吉祥贤)及香巴。棍钦巴等很多善知识，听受很多显密经教。特别是他礼敬在西藏大车轨师至尊仁达瓦的莲足下，一心依止，听受般若、因明、毘奈耶、俱舍、中观等显教诸经论，以及密集等密教诸经义，并对自他各宗的教义大海也通达无余，成为善巧自在，要算是仁达瓦大师的博通经论得意首要弟子中七位善知识中之一。此师广游萨迦等后藏所有大辩场，立十部宗论，从此十论师的美名遍于当时大地之上。继后，年满二十五岁时，岁次戊辰的那年，求得后藏那堆垛妥巴。法王恭嘎伯瓦(义为庆喜吉祥)为作和尚，仁达瓦大师为作羯磨师，贡金。恭嘎伯瓦为作教授师，以及持律师伯敦洛卓(义为吉祥智)，与洛卓冲默等，具信僧伽二十二人之前，受得具足戒(即比丘戒)。受戒后，持戒如护眼珠，俨然是往昔圣优波离尊者再来此间雪域西藏。

此后大德达玛仁清游前藏各辩场，在哲当辩场立宗后，随即前往那时宗喀巴大师驻锡地“娘堆惹宗”谒见大师。仅一瞻师颜，即生起感动身心的敬信，遂住依座前，请求赐授法要。宗喀巴大师观知此师是最胜大宝法器，于是根据经论要义及诸难处等无垢智理，详为开示。以此对于宗喀巴大师生起坚固信心，而自叹舍依止宗喀巴这样的大德外，任于何处难觅这样的大德。因此想到舍这样绍隆佛种的善知识，而往他处于理不合。于是一再顶敬在大师莲足下殷重启请大师允许他从此直到未死之前，依止在莲足之前。大师也极生欢喜，允其所请。此师从此以后，即常住在宗喀巴大师座前，听受菩提道次第导修教授，以及密教圆满次第等所有显密教义中一切经教圆满教授，并且对于这些教义都能深入完全领会于心中。以此大师每次任说何法，此师都得到如瓶倾注甘露，不遗余滴完全领会牢记在心中。宗喀巴大师在朗哲顶详讲戒律学处时，所有讲义，他完全领会牢记心间，随即记录备忘；此一纪录，即是众所称赞的名著《朗哲顶师授戒学录》。又宗喀巴大师在色拉寺，讲授圆满次第《春点》时，所有讲授，此师完全牢记心间，随即作出记录，即是《圆满次第春点教授记录》。继后，在己丑年大神变节供养完后，新建甘丹朗嘉岭(兜率尊胜寺即三大寺之一的甘丹寺)，大菩萨达玛仁清及持律扎巴绛称(义为名称幢)两师担负建寺任务。所有启白僧众，僧众许已，地基奠石、造房轨则、遣授事人等事务，无不依戒律来办理，以建寺工作也为振兴佛教之基而作。总之这位大菩萨确如往昔常啼菩萨依止法圣尊者，不惜身命财产受用，任于何时毫不放逸，都依宗喀巴上师所教而行，以此成为宗喀巴大师首要弟子。自宗喀巴大师住世时，所有大师弟子，大都亲近在此师之前。宗喀巴大师给徒众授出家具足戒等一切事业时，都由此师承办其事。

继后，到了宗喀巴大师将示涅槃时，也如兜率天子圣善白幢(释迦前生)将降生在赡部洲时，为弥勒灌顶授权补处佛位那样的胜事，宗喀巴大师以尖峰黄帽及僧氅授给这位达玛仁清大师，也是授权补处佛位之意。算来是贾曹杰·达玛仁清年满五十六岁的那年，岁次己亥年十一月吉日，由宗喀巴大师授权补处其佛位起，一直主持寺座十三年之久。在此期中，从说修二门教导众生获得成熟解脱。中间有一时期去到勒宁寺，对寺僧众供施广大财法二施；复供大堪布仁清绛称，及大堪布仁清珠巴两师各僧衣一件；对僧众供上好饮茶，放衬钱；对研习法相及说法师，供施常用基金及僧衣各一件。特别是在他将示寂的头一年，他来到勒宁寺，在大堪布仁清绛称的内藏极珍佛像前，供上景泰蓝嵌镶诸宝的曼陀罗，并对僧众供施饮茶，及分放好茶等物。又在大堪布仁清珠巴前，供银制五佛冠，及银制水壶、僧衣等物。继即与克主杰相会商谈前往甘丹祖寺的事宜。到利若默曲喀时，在克珠。贡桑巴前，供黄色上缎一疋。总说起来这位大德住勒宁寺中，还未去到甘丹寺前，及到甘丹寺时，这段时间共转四次法轮。继后，这位大德年满六十八岁，岁次乙亥十月吉日，将甘丹祖座法位授与四远驰名的克主杰。格勒伯桑(义为福善吉祥)。

这位大德为利益后世有情而著作的论著是很多的，计有关于般若波罗密多教授的论著《现观庄严论释明义心要庄严论》、《中观宝鬘要义明显论》、《中观四百颂善说心藏》、《二谛建立与正见教授宝鬘》、《中观根本智论中八大难义解说》、《量决定论大疏密意极显论》、《因明正理滴论释善说心藏》、《释量论品类分说解脱道正义显明论》、《大乘最上要义论疏》、《集论疏善说对法海藏》、《入菩萨行论释入佛子道岸》、《因明本论解说》、《宗喀巴语录因明备忘详录》、《现观次第修法胜乘开显论》、《八种现观七十义庄严等修法》、《现观庄严论摄义宝鬘论》、《释量论摄义显明解脱道正理论》、《六十如理论疏》、《六十如理论讲录》、《观相属论释日藏论》、《因明理路整编》、《因明违顺建立论》、《因明现量品备忘录》、《中观庄严颂备忘录》、《入菩萨行智慧品备忘录》、《比丘学处朗哲顶宗喀巴讲授录》、《在朗哲顶宗喀巴讲授沙弥学处笔录》、《三十五佛名称功德》、《密集师承启请垛居玛》、《密集妙吉祥金刚曼陀罗仪轨成就花穗》、《修法全妙义解说》、《密集难义讲录》、《时轮要道二次第修法迅入大乐道》、《四手印讲录》等著作。

此师年满六十九岁时，为度化他方世界有情，于壬子年(公元一四九二年，明弘治五年)五月初八日，在拉萨布达拉示现圆寂。从示寂后三七日，所有卫藏各处，特别是甘丹寺及拉萨勒宁寺等处天雨金花、赡波花，还有如红宝石蓝宝石色的大雨下降。在迎奉肉身到甘丹寺去的时候，以及荼毘时，天乐齐鸣，天空出现虹光，天雨花等稀有瑞相，为众目所共睹。那时，依克主杰所安排，在甘丹寺及勒宁寺等处诵祈祷经文，供众饮茶，放衬钱等，尽力供养。肉身迎奉到嘉康哲荼毘时，出有很多舍利广施大众，作为后世应化有情及具敬信众生虔诚供养祈祷之所依。荼毘后灵骨整个放入银塔中，也就奉安在甘丹寺尊胜洲内，作为应化众生供养的福田。
