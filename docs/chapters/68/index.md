# 六十八、格勒伯桑大师的历史

颂句中赞说：“讲说日光善妙贤。”

值得这样称赞的甘丹寺座主极乐院大师格勒伯桑(义为善妙贤)，是在乙丑年(公元一五○五年，明弘治十八年)降生在峨喀江萨地方。他从幼出家，研习诸经论，成为大善巧师。后来他前往上密院中，精研密续四部，特别是对密续之王《密集法类》作了很好的钻研。继后，他请求一切智根敦嘉措大师为作亲教师受持比丘大戒，并在师前听受菩提道次第指导教授，依教授修行，获得悟达。此外，他还依止了很多善知识广闻显密一切经教，成为极大善巧的时候，也就升登上密院座主。他敬仰追踪大密师恭迦邓珠(义为普喜成义)的清净行传，严守三律，精研《密集》闻说法类。继后，升登“侠哲”(甘丹副座法王)法王位。继在戊午年，他年五十四岁时，升登甘丹寺座主法王位。他追踪随持宗喀巴大师事业行传，在冬季讲说《菩提道次第广论》，拉萨宏愿大会的时节中，讲说《释迦世尊行传三十四事》。他任甘丹座主法王位中，总是常时不断地为汉、藏、蒙三族所有对宗喀巴大师教法及住持导师等供养承事诸人士，作回向功德，对所有各方前来求学教法大众，广宣宗喀巴大师显密诸教授。特别是广说三世诸佛所趣唯一大道《菩提道次第》讲授，多次传授，大弘圣教事业。又在甘丹尊胜洲寺中，建造了一尊至尊弥勒鎏金大像，留下了使后人效法的功迹。后来他年满六十岁时，在甲子年，辞甘丹座主法王位，退居极乐院，以此都称他叫极乐院法王。这位大师的事业是很宏大的，一切智索朗嘉措(达赖福海)也是在这位师前，求作亲教师，受比丘大戒，并听受很多教法。这位大师他护持教育谟卓仁清岭(大宝寺)及帕谟却德(亥母寺)等寺院的很多僧众，广宣圣教事业。后来他圆满这生教化事业的时候，是在丁卯年(公元一五六七年，明隆庆元年)，享寿六十三岁，在甘丹尊胜洲寺中，示现圆寂，往生兜率陀宫。

意乐修行菩提道次第的人们，应当谨向这位甘丹座主法王格勒伯桑大师，祈祷求加持，并应效法他的清净行传，严持宗喀巴大师的纯洁宗见和修行，依菩提道次第修心为要。
