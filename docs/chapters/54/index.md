# 五十四、金刚持根却绛称的历史

“三宝悲智聚一体，成为弘持第二佛，宗喀教证说修幢，师尊座前我启请。”

值得这样赞颂的金刚持根却绛称大师(义为宝幢)，是在壬子年(公元一六一二年，明神宗万历四十年)诞生在那堆区日喀则地方，为措葛。伦珠贡钦勒的公子。由于往昔的善习力，少年时代也就不贪恋于自己官家的富贵，生起学习正法的志愿。为官的父母和所辖的民众，对他的志愿也不作阻难，成其顺缘，在扎什伦布大寺中，班禅一切智洛桑却季绛称座前出家受沙弥戒，命名为根却绛称。他住在寺中侠哲扎仓内，最初启发智慧，学习“性相”、“名相”建立，及“总”、“别”建立等摄义(即摄类学)。由于他与生俱来的智慧特高，经过不久时间，无碍难地就连辩论方式都已学会，进而依据衮钦勒巴顿珠(义为善成)大师的论著来研习《释量论》中决断总义等，继即增长了很大的无垢理智。复依据贾曹杰。达玛仁清所著《阐明解脱道论》，及一切智克主杰所著《智明海大疏》来精研《释量论》，获得善巧通达。在扎什伦布寺有诸阿阇黎导师和僧伽大众的当中立宗，与妥桑岭寺院中负有善巧盛名的伯楚(义为吉祥戒)法师相辩论时，运用无垢智理，使对方无言答辩而失败，于是善巧之名遍于各方。

继后，复研习《波罗密多现观庄严论》、《中观论》、《毘奈耶》、《俱舍》等大论，学成善巧精通时，实现诸经论义皆为修行教授。先启请班禅一切智洛桑却季绛称为作亲教师受得圆满具戒，用正知正念谨守二百五十三条戒律，丝毫无犯。继在班禅洛桑却季绛称座前，听受三世诸佛所趣唯一大道——菩提道次第甚深讲授温萨耳传教授中所有除障增益等圆满法门。复听受《修心七义论导修讲授》、《启虚空门灌顶》、《“觉”法施身断执供施法讲授》、《噶当大手印四大加行讲授》等法。继听受灌顶、传经、教授无边法义；特别是很好地听受了胜乐、密集、能怖三法灌顶及生圆二次第诸讲授。

此后，对于显密二法圆满道体获得无误决定时，想到决定要效法瑜伽自在师密勒日巴及大成就者温萨巴父子德行高风那样斩断此生事务纠缠，安住寂静处，毕生修行；于是在上师洛桑却季绛称座前，请求救助，也就住在温萨寺中毕生闭关专修。当时由修而得的通达，逐日增长，心生猛利希愿，由身语意三门提起正知正念守护三种律仪，哪怕是细分罪过，丝毫也无违犯。并自我鞭策，作了这样的誓约颂言：

“南无姑如呗。

上师本尊与三宝，请于我顶严安住，我今所思之诸义，迅速得成求加持。

谨守誓言护法众，静听我今所商榷，如所商量生灾障，敬礼现时速消除。

有类人面兽心者，惭愧无益宜一听，我与汝心作商量，为此揭罪说三言。

难得人身获暇满，难遇佛法今已遇，具相上师众恩赐，法财不断以培养。

汝与暇满邪途合，垢秽染污佛圣教，并欺具相上师众。见汝如是诸大恶，

汝若从今至以后，刹那不作如律行，外表虽作如佛徒，仍受信供与亡财，

暇满人身弃邪岩，对诸具相上师众，辜负所传三戒恩，汝虽不欲犯根罪，

然于佛制极细律，汝极愚钝治力弱，以此染污佛圣教。昔对金刚乘戒法，

以及菩萨诸学处，犯根堕罪如雨降，对余粗细支分戒，大半明知而轻视，

少分不解遂邪行，身心沉堕秽泥淖。汝堕如是出家众，比丘任作何事业，

及灌顶等密师时，亦无顾畏堕险处。以此染污佛圣教，深广诸法甘露流，

纵尽注入汝器中，谤句义故难容受。有何较此更为欺，或者由生如此因，

四句法义犹未通，自矜善巧堕我慢。身心已沉罪过中，犹持自尊之邪见，

心已随彼贪瞋转，犹认自贤生矜骄，勤世八法不自省，且自矜骄为善心，

魔因随彼心而入。魔入彼心之根本，全身亦被把持住，不经魔语听魔使，

志不合者亦随合。有无此过自问心，是否彼因回忆知，昔昧诸过因心腐，

以故昔作无义过。今至晚年如空电，暇满人身求心要，自欲求入善道时，

出恶境法如是作。句法不知之智者，彼与愚昧牛相比，智与非智由何分？

彼牛对智无执著，以此一法牛胜超。罪染身心尊严僧，彼与食秽猪犬比，

是否尊严由何别？猪犬无视于尊严，以此一法猪犬胜。作尽损害善全者，

相比失羞残破物，是否善全由何别？此二全残虽无别，残物彼无贪全念，

以此一法残物胜。作世八风之佛徒，相比奸诈之俗人，是否法行由何别？

二非法行无别中，俗人无借法骄念，以此一法俗人胜。毁汝贪智尊贤心，

矜善己作颠倒念，较汝卑恭人为谁？知已正好持卑谦，不拘不急守卑躬。

此身退出人丛中，趋依无人尽边处，决断此生诸纠缠。衣食之上人受损，

辟谷难行甘露食，知足而衣粪扫衣，舍贪食僧物毒泉。身具三律受牧众，

慈悲增上广牧场，正知牧者来善牧。今虽一细支分戒，亦不失守烦恼敌，

戒德增机应广作。心依上师与三宝，时刻不离常求加，如法闻思修正法，

察断执实颠倒心。教世八法善说人，其语一言亦勿听，于其反面尽力行，

彼虽不悦亦无悔。今应远离闲杂语，与及种种恶劣友。暂乏养生资具等，

世物与法不顺缘，种种不欲虽纷至，至心正法依志行。揭恶与心作此议，

为恐自犯而宣说，所商记心勤修悟，常怀志愿得以成。”

当班禅洛桑却季绛称来到温萨寺的时候，根却绛称请求班禅传一那若六法详细导修教授，班禅洛桑却季绛称本来就十分喜悦住寂静山林专修的行者，特别对于根却绛称如爱护自己眼珠般爱护他，因此，班禅对根却绛称说：“如果你开关出来听法，会使所修善行散乱。”于是班禅亲到根却绛称的关房中，传授那若六法详广导修讲授。为令修行能达究竟的原因，并将六法道中除障增益等法都一一详细传授。此外，还迎请修成自在师勒居饶江巴。根敦绛称(义为僧幢)来到自己关房中传法，他听受了很多教授要诀，特请彻底传授了关于那若六法中幻轮法门等，依法修行获得可靠工夫。

经过这样长久修习，修证通达与日俱增，正想如大成就者侠瓦日巴那样此生中对于亲眷资财受用任何亦不贪恋，毕生彻底专修的时候，班禅洛桑却季绛称正在扎什伦布新建密宗学院，召集博研经论的善知识住密宗学院中，命根却绛称作密宗院主。那时大德根却绛称虽是毕生闭关专修，但是想到经中说供养十方一切诸佛之功德不及供养上师一毛孔之功德为大；以及对于密经中，与诸大成就者的论著中都称赞依金刚阿阇黎师教而行，即是速速趣入佛地之道的说法，他已获决定，毫无怀疑。以此他即出关谨遵师命前往扎什伦布作密宗院法座。同时在上师班禅洛桑却季绛称座前，求得依《密续教王密集释》、明灯注、摄义、决择等四种论著来解释《密集》的宗喀巴大师所传诸教授，对于六边、四法中的诸难义，哪怕是细小的怀疑都得到解决后，大德根却绛称这才对住在密院中所有博研经论诸人，如流不断地开讲法要。主要讲说《密集》，同时也广传《胜乐》、《能怖》、《时轮》诸法灌顶、传经、教授等法。以此所有住密院博研经论的高僧，以及各方来院求学的人士，都得到饱餐大密金刚乘甘露法味，对大德根却绛称都生起了真实金刚大持想，异口同声都对他叫作“金刚大持”。当时，大德洛桑却季绛称因将近百岁高龄，对于各方前来求学的人士，未能广说法要。也就由金刚大持师随各种不同的根机，适应赐授《菩提道次第讲授》、《修心讲授》、《噶当大手印详细讲授》、以及《胜乐、密集、能怖三法生圆二次第讲授》等无量显密法门。

此后，大德根却绛称在上师班禅洛桑却季绛称逝世后，仍旧主持密院法座，继续弘持上师洛桑却季绛称所传的一切教授，使不颓废。继后，大德根却绛称遵照第五世达赖喇嘛指令：“关于寻觅班禅化身之灵童一事，饬班禅大师首要大弟子住持扎什伦布密院法座去作观察寻认为佳。”等语，去到祝仓地方观察，寻得班禅真实化身灵童。当即为灵童沐浴，以及作延寿缘起法事等。此后，迎班禅灵童到扎什伦布坐床受人天众生怙主之位，事毕退密院法座职位。得赐香区新建喀觉圣吉寺与博瓦巴寺院，僧众等住新寺中，弘持宗喀耳传教要。继后，班禅化身活佛洛桑耶喜(义为慧贤智，实际是班禅第二世)满二十岁时，迎请金刚大持上师根却绛称到自住高幢宫中，祈请上师传授前身班禅大师洛桑却季绛称所有圆满教授。金刚大持上师根却绛称欢喜应请，驻锡高幢宫兜率室中，最初为班禅洛桑耶喜传授比丘戒，继即传授依成佛所趣坦途——《菩提道次第导修剖解详授》，即温萨巴大师耳传教授口诀等圆满法要，以及《噶当大手印详细讲授四种加行讲授》等，特别传授显密圆满深道《上师瑜伽导修详讲教授》，及密集、胜乐、能怖三法灌顶、传经、生圆二次教授等，与由枳布师传内外曼陀罗灌顶及甚深讲授。此外，还传授了有关四部密续中一切灌顶、传经、教授，以及为众所称之诸护法随赐灌顶等法要。

这样传法教主的衣钵交付与班禅洛桑耶喜后，大师根却绛称此生的弘化事业已到圆满时，正是丁卯年四月初十日(公元一六八七年，清康熙二十六年)寿届七十六岁，在扎什伦布高幢宫中，示现圆寂时，适合内外俱净诸大次第收摄，而现证光明法身。当时，正如《胜乐本续》中所说那样现证光明法身之内外诸相缘起，完全相符，天空清朗，虹光遍布等相，为所有人士有目共睹；以此一切尊卑众生咸生敬信，并对宗喀耳传教法，尤生决定信念。班禅洛桑耶喜为训示大众供养上师的意义较供养十方一切诸佛的功德为大起见，在上师肉身前，供养无量供养，并为了令温萨耳传法流长久住世缘起，奉安上师肉身于银塔中，供置在扎什伦布密宗院内。金刚大持根却绛称对于上中下三根无量众生广传显密甘露正法，以此也获得不少承传弘持法流弟子。其中首要法嗣，则为显密圆满教主班禅洛桑耶喜。此外还有金刚持格勒饶杰(义为善广)、金刚持洛桑贡波(义为贤慧怙主)、谢安。绛央却迫(义为妙音法尊)、吉学。夏仲。敦真称勒(义为持教事业)、章嘉呼图克图昂旺洛桑却敦等许多持教大德。

金刚大持根却绛称为饶益后世应化众生起见，著作有班禅洛桑却季绛称的教授口诀《噶当大手印甚深导释四大加行讲释》、《修心苦作道用及七义论释》、《胜乐轮曼陀罗仪轨》、《胜乐身曼陀罗现观法门》、《坛场南门仪轨》、《枳布师传五尊现观法门》、《密集彩土作法》、《启虚空门灌顶法》、《供施龙王垛玛法》、常用《烧食供施仪轨》数种、《百字明释》、《俗人祭祖仪轨》、《菩提道次第颂奢摩他注等》、《薄伽梵三誓句尊修轨全编》、《文殊法门随赐灌顶仪轨》等论著。

意乐修学菩提道次第的人们，应当谨向金刚持根却绛称祈祷求加，并应效法大师的清净史事，依一切福善之根本怙主上师，对显密圆满要道，得到无误坚固决定后，断绝此生纠缠，住寂静地，勤修整个佛道心要。
