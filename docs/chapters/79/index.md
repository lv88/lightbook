# 七十九、大堪布邓瓦伯的历史

大堪布邓瓦伯(义为乐吉祥)是在癸卯年(公元一三○三年，元大德七年)诞生在后藏绒雅德地方中。自幼身入佛门，出家为僧，也就学习读诵，闻思学业，并精习禅定。他年满二十岁时，在壬戌年由大堪布妥扎巴。绛秋伯(义为菩提吉祥)为作亲教师，阿阇黎索朗桑波(义为福贤)为作教导师，阿阇黎旺秋扎巴(义为自在名称)为作轨范师，在僧伽众中，受得具足戒。他对于四部《毘奈耶》中所说的比丘所有粗细诸分戒学，如护眼珠般守护。他从一座精修苦行功德中，在亲教师座前，听受大堪布所著《花鬘大疏》及《入行论》等显教方面的很多经论及教授。特别是在大堪布绛秋伯座前，听受了由内邬苏巴大师传来的《菩提道次第》，以及三种缘念法门等《不动佛修法种字等》，及由法王班敦所传来的《白文殊法》、《白度母法》、《白色胜乐法》、《尊严救度母法》等很多要法。复在阿阇黎云敦伯座前，听受了大乘甚深修心教授。在阿阇黎扎喜索朗(义为吉祥福)座前，听受了由那索瓦传来的《大悲观音修法》，又在喇嘛仲朴瓦座前，听受了《不空羂索修法》等。他复依止雅德译师及垛朴阿阇黎根却扎(义为宝称)、卓衮帕巴(义为众生怙圣)、堪布生根时伦(义为狮威惮)、仁波切措普瓦等师前，听受了很多经论及教授。继后大堪布绛秋伯逝世后，约有三年的当中，由阿阇黎任他为僧伽会众中的领经师。在这段时间中，他在迦栋寺雅唎玛准珠(义为日精进)大师座前，听受《般若》。继后，在庚辰年，他年满三十八岁时，升任为主持全寺的大堪布，一直任职二十七年之久。在丙午年，他将寺主位交给四论师后，退寺主职，一心专修摄一切经论教义于整个修行道体的《菩提道次第》，以及道次心要——《自他相换修心法门》，对圆满道体，生起了彻底的证达。亲见大悲观音及尊胜佛母。戒香不断四溢，护法毗沙门天王，常护持成就他的事业，在己酉年，他年满六十七岁时示寂。荼毘时心脏火烧不坏并发出声音，至今仍存寺中供养。
