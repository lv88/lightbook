# 十一、古萨利大师的历史

“普持佛教古萨利。”

值得宗喀巴大师这样称赞的大师古萨利，他的真名叫仁清桑波(义为宝贤)。这位大德身入佛门受具足戒后，依止阿阇黎狮子贤为师，在师前圆满听受了从至尊怙主弥勒传来的般若教授；并圆满听受了从圣龙树传来的中观诸教授。在当时赡洲中任何地方所住的大德前，他大部分都依止而听受所有显密诸教授。此中听受从至尊怙主弥勒传来的所有教授。这节如《噶当卷帙》中所说：“慈尊无著及世亲，二解脱军最胜军，调伏军及寂护师，师贤宝贤及宝军，根本上师金洲师，广大行派前敬礼。”根据过去的佛教史中说，颂中所说的“宝贤”即是大古萨利，“宝军”即是小古萨利。关于所有从龙树传来的诸教授，特别是密续《密集》诸教授。这位大德是在“正理杜鹃”(亦译智鹃)大师座前听受而获得的。这正如《噶当卷帙》中所说：“龙树月称及智鹃，大小两位古萨利，中观五师前敬礼。”关于佛智师传诸教授，这位大德是在阿阇黎佛寂座前，听受而获得的。这正如《噶当卷帙》中所说：“佛智师及佛密师，佛寂及二古萨利，密教无余全赐我，具恩五师前敬礼。”关于《瑜伽密续》诸教授，这位大德是在佛寂或佛密两师中任一座前，听受而获得的。这正如《噶当卷帙》中所说：“佛智师及佛寂师，佛密及二古萨利，瑜伽教授全赐我，具德五师前敬礼。”关于从善巧成就大师佛护传来的诸教授，这位大德也完全听受。这正如《噶当卷帙》中所说：“善巧成就佛护师，佛智师及佛寂师，佛密师及大古萨，具恩本师古萨利，加持六师前敬礼。”又这位大古萨利大德，在阿阇黎慧坚座前，听受了大乘道次第诸教授，这正如《噶当卷帙》中所说：“慈尊无著及世亲，慧坚大小古萨利，金洲师等发心教，赐我七师前敬礼。”由于这位大古萨利富有这样显密一切教授，所以宗喀巴大师想到他的这一功德，而称赞说：“普持佛教古萨利。”这位大德，是一位成就普持佛正法愿力的大德，他将自己听受的一切显密教授，完全传授给小古萨利。小古萨利复将一切教授，完全传授给阿底峡尊者，而使尊者成为显密圆满教主，都是从此师而来的。以此总说对于赡洲一切信众，特别是对于西藏大众，这位古萨利大德的恩德是无比的。

以此意乐修行菩提道次第的人们，应当谨向这位阿阇黎大古萨利虔诚祈祷求加持。应当求得从佛世尊起直到传法上师中间，没有断缺，传来的菩提道次第圆满诸教授后，于寂静处所，一心勤励修行菩提道次第。
