# 七十二、昆敦。伯觉伦珠大师的历史

颂句中赞说：“遍主光明金刚前。”

值得这样赞颂的昆敦。伯觉伦珠(义为圆满运成)大师，是在辛酉年(公元一六二一年，明天启元年)，诞生在唉区觉喀地方中，父为土官名泽旺洛杰(义为寿宝盛)，母名嘉谟仲。他刚一生下，就口诵“底”及“啥”种字真言、及文殊咒。由于多生习气，他对俗家的喧扰，不生爱乐，对正法生喜，并对他人，每作说法及灌顶的动作形相。对书法及读诵，只略加指导，即能领会。他才七、八岁时，就能总对于一切轮回生处，生起厌离；特别是天然地对俗家，生起如同牢狱的感想。他在街道中，由见一病犬作增上缘，对一切有情，常生大悲。他年满十岁的时候，谒见到一切智索朗嘉措大师，也就在大师前，首先听受皈依发心讲授，继听受了很多灌顶、传经教授等要法。在其他上师座前，也听受了不少的显密要法。继在一切智索朗嘉措座前，剃度受近事戒，命名叫索朗朗嘉。继后，他在很多善知识大德座前，听受了很多教法。他年满二十岁时，在善巧自在师峨喀瓦。洛桑嘉措(义为慧贤海)座前，受沙弥戒。他前往达波僧院，仍依止善巧自在师，精研《般若》、《中论》、《毘奈耶》、《俱舍》、《释量论》等经论。由此成为彻底通达的善巧师。继后，他复前往色拉大寺上院，依止伯觉索朗伦珠(义为圆满福成)，及赤勒伦珠(义为事业运成)两师座前，精研色拉寺法王杰准巴所有著作中，大车轨诸经论要义，通达了自他诸宗如海般的理义，游辩场立宗辩论。继后，前往特达寺，他心行两种如理依止善知识京俄。却伯桑波，听受了所有阿底峡尊者，及法王宗喀巴两大师的心髓教授，摄一切经论教义的《菩提道次第指授》，获得悟达。继在法王朗喀绛称座前，听受《能怖金刚大灌顶及二次第导释》，并修得通达。

在甲午年，他年满三十四岁，前往甘丹大寺中，法王伯觉嘉措为作亲教师，法王根敦绛称(义为僧幢)为作教导师，受得比丘戒。取名叫伯觉伦珠。继后，他前往下密院，心行两种如理依止克珠。朗嘉伯桑(义为尊胜禅贤)大师座前，精研《密集根本续释》，并听受所有从宗喀巴大师传来的胜乐、密集、能怖三种法类的一切教授等，很多要法，约有四年之久。继后，他复在很多善知识前，听受了宗喀巴大师的显密诸教法。继后，他的善巧成就的声誉，遍布于诸方的时候，桑朴利玛塘寺迎请他主持寺座，在那里讲学约有一年时间。继后，色拉寺上院迎请他主持克芒扎仓(多善巧僧院)的法座，也就常时宣说教法。当一切智云敦嘉措(达赖功德海)迎请一切智班钦。却季绛称(义为法幢)来哲蚌寺兜率宫日光室驻锡，听受所有显密教法时，这位伯觉伦珠师也来到却季绛称大师座前求法，他听受了金刚鬘全部灌顶，却季绛称大师对他极端称赞。

继后，他辞色拉寺上院法座，前往颇章喀专修了很长时间，以此普遍称他为“颇章喀昆敦。伯觉伦珠大师”。所谓“昆敦”是从族姓安立的名称，是说妙音“昆”姓。继后，他对很多具缘大众，广传宗喀巴大师的心髓教授《菩提道次第导释》，及胜乐、密集、能怖三种法类的灌顶和生圆二次导释等，很多教法。五世达赖也依止他为师，作为遍主金刚持顶敬。这位大师为了利益未来应化众生起见，著作有《阎摩法源史》及《皈依讲释》等很多论述。由于这位大师广弘圣教，以此他的承传弟子是很多的，主要弟子是雪域众生怙主第五世达赖喇嘛；及受命菩提道次第事业的弟子，为伯觉称勒饶杰(义为圆满事业广弘师)。他这样做弘法利生事业，到达圆满度生事业的时候，是在丁丑年(公元一六九七年，清康熙三十六年)示现圆寂，享寿七十七岁。

意乐修行菩提道次第的人们，应谨向昆敦。伯觉伦珠大师祈祷求加持，并应效法他的清净行传，彻底听受显密经论后，勤行专修菩提道次第。
