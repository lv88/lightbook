# 七十、一切智索朗嘉措大师的历史

颂句中赞说：“持莲观音福海师。”

值得这样称赞的一切智索朗嘉措(达赖福海)降生在堆隆区的康色贡(新屋地)。父名朗嘉扎巴(义为尊胜称)，母名伯仲布泽(义为德合子)。是在癸卯年(公元一五四三年，明嘉靖二十二年)正月二十五日诞生，生时发现很多稀有瑞相。特别是生下的是一团肚包，婴孩包在如晶白亮的肚包里面，如日光照射莲苞那般，刚一生下，包团自开，现出具相好悦目的孩身来。那时彩虹如幕，遍满虚空，诸天人降雨瑞花。刚生就能喝白山羊奶，他的父母就赞颂吉祥，并给他取名叫热鲁录却(羊乳辟邪)。刚生就能口诵六字明咒，完全没有一切凡俗的行动，有时做出说法手印，有时做入定状态。他刚三岁时，就能忆念一切智根敦嘉措的事迹行传，天性中完全作出那种种行态，他口中也说出如事迹那样的一些话，以此各方都传称他是一切智根敦嘉措的转世化身。继由仲清。暑饶巴(经论师)，与哲蚌寺所有大喇嘛商得同意后，在丙午年三月上弦木金二星会合行事良辰，由哲蚌大寺所有僧众捧持各种供品，迎请灵童前来哲蚌诸方尊胜洲寺中，登喜足宫无畏狮子大座。继在阿阇黎索朗扎巴(义为福称)大师座前，受全优婆塞戒，命名叫索朗嘉措(全名福海吉祥贤诸方尊胜教法之日)。继在五月初三日，由哲蚌起驾沿途对所有人众，结下见闻思念的善缘，六月初五日，到达嘉区的默朵塘(花原地)。那时，吉祥军刀天女示现喜悦的各种神变，他并在嘉区寺中佛塔经像等前，供养发愿，复对僧伽大众，普施大法甘露。

返回哲蚌后，继在己酉年四月十五大节日，由班钦。索朗扎巴大师(义为福称)为作亲教师，桑朴。法王勒巴邓珠(义为善成义)大师为教导师，使他受得沙弥戒。他继在班钦。索朗扎巴大师座前，听受《长寿灌顶成就法》、及《黄毘沙门天王法》、《欲界自在军刀天女法》、《具德狮子师传贡波护法法类》、《六臂怙主法》、《具誓护法外修随缘灌顶》等。又在领堆。法王勒邓巴(义为善义师)座前，听受《能怖金刚咒集》、《事师五十颂大疏》、《菩提道次第广略二论》、《菩提道炬论》、《菩提正道》、《毘奈耶学处广略二论》、《三事仪轨》、《羯摩仪轨》、《中论及入中论以及大疏》、《释著明义论》、《要义庄严论》、《释量论》、《解脱道显明论》、《俱舍》、《经根本颂》、《辨了不了义论》、《喻法》、《五次第明灯论》、《五次第圆座法类》、《克珠大师著作拾零》、《生起次第悉地海》诸经论等诵授。又在侠哲法王勒邓巴座前，听受《白文殊法》、及《四臂观音法》、《贡波护法入心法》、《八轮母法》、《马头金刚密修法》、《铁发法类》、《邬扎热雅法类》、《四臂观音法类》、《白度母法》、《长寿五供法》、《智慧花色金翅鸟法》、《伯格扎法》、《红色三法》、《古汝古里密修法》、《度母二十一尊赞》、《兰马毘沙门尊法》、《有棍毘沙门法》、《红枪毘沙门法》、《第四标帜》、《殊胜舞者》、《白色忿怒明王长寿法》、《香热玛纳》、《竭地洛迦林度母法》、《狮相佛母法》、《秽积金刚法类随赐灌顶》、《能怖金刚明咒集》、《文殊和威合修法诵授》、《密集妙音金刚法》、《观自在两尊灌顶》、《噶当十六滴法及经卷》等经教诵授。对于以上诸经义，由闻思以决择，并作修习。

继后大师也就轮番驻锡嘉区寺，及哲蚌寺中，并为沿途诸寺院大众，广施法雨。继在壬子年班钦。索朗扎巴退位，由大师继登甘丹大寺法座，遂由政教两门来治理。继在癸丑年拉萨宏愿大会时节，大师到大会僧众中，上午广讲《释迦世尊行传三十四事》，下午则作发愿回向等诵事，这样随持宗喀巴大师事业作风，令不衰退。那时，诸天善神皆大欢喜，发现天雨瑞花等稀有瑞相。大师继在法王索朗扎巴座前，听受《密集不动金刚灌顶》、《大梵母随赐灌顶》、《恭嘉瓦大师所作噶当教法史》、《兰犊瓶册根本释》、《百一羯磨论》、《花鬘续》、《噶当教法史》、《十圣地修行文书》等诵授。复在成就自在师格敦扎喜(义为僧吉祥)座前，听受《观音不空羂索法门》、《十一面大悲观音法》、《长寿九尊及三尊灌顶》等法。

继后，关于《金刚鬘灌顶》法传，过去虽是出有很多师传，但与“枳雅萨摩住”合一曼陀罗四十五种从圣传灌顶法流合而为一的这一法门，是除法王金刚持师唉旺巴(方便智慧师)师徒外，其他传金刚鬘灌顶著名诸师，虽是对此法行境没有变更，仍不及唉旺巴所具有的为殊胜，他将这一法门全部传授与大师。此外，还听受《隐藏灌顶》、《圣传及智慧师传二种密集法类》、《鲁峨师传胜乐法类》、《枳布师传外及身两种曼陀罗》、《桑补扎》、《喜金刚教传及峨传》、《无我母十五尊》、《金刚幕法类集》、《具威猛座》、《惹师传能怖金刚法》、《黑敌》、《柳师传八起尸法及黑敌》、《香师传四十九尊法》、《伯真师传红阎摩十三尊》、《瑜伽自在师传红阎摩五尊》、《金刚手花色金翅鸟》、《大千轮金刚》、《威猛金翅二十一尊及花色四尊共二十五尊法》、《普明法类》、《不动金刚》、《白伞盖》、《五尊护法》、《弥扎师传观音法》、《时轮灌顶》、《金刚手五尊金翅鸟》、《卓桑师传邬旃延那》、《能摧金刚》、《住嘉师传长寿佛法类》、《财源天女法》、《光明母法》、《藏跋拉法类》、《叶衣佛母随赐灌顶》、《萨惹哈师传三面怙主及六臂怙主四灌顶》、《十三尊怙主明王随赐灌顶》、《四臂佛母及药刹等随赐灌顶》、《护法入心不共随缘灌顶》、《四臂观音布绘及身曼陀罗灌顶》、《金刚幕具善三处》、《胜乐及能怖咒集》、《元音》、《缘起心咒》、《白色种字灌顶》、《毘沙门密修绿黄身相及猛威相，以及天龙八部法类》、《毘沙门黄白二种法类》、《四魔母法类》、《阎摩如意成就法》、《威猛步行母》、《弥枳师传六法随赐灌顶》、《智慧六臂怙主明王黑白二法集》、《大垛玛法轮等作法及要诀等》、《惹博法类》、《阎摩咒轮法》、《具誓护法六十分供作法教授等》。总之，所有灌顶、经传、导释等教授次第，如瓶注水般地全得传授。

大师继允北部蒙族大众的请求，前往蒙族居住的地区，对于那粗暴作恶的人们，都施教将他们安置在十善法戒中，使宗喀教法获得大弘。继后，他前往热振寺，得见白毡衣尊者前来欢迎。在热振寺僧伽会众中，传授《噶当经卷》及《经义三要》等很多要法。大师继即前往哲蚌寺中，和班钦。却季绛称(义为法幢)的弟子虹霓身成就师，金刚三昆仲中的堆隆巴。伯敦多杰大师(义为吉祥金刚)相会，在此师座前，听受了宗喀巴大师许多耳传教授。继在甲子年佛世尊的三大节日会合的时节，四月十五日，由退位的甘丹寺座主克珠格勒(义为善成福善)大师为作亲教师，甘丹在位座主为博多瓦化身的根敦登巴大杰(义为僧教盛宏)大师为作轨范师，法王却勒朗嘉(义为诸方尊胜)大师为作教授师，拉准巴。索朗伯桑(义为福德贤)大师为作报时师，在足数的净信僧众中，大师受得比丘戒。他对所有传戒教师等，都作隆重的供养承事。那时，他在戒师前所承受的一切戒律，都严守不犯，成为释迦能仁的代理大德。

继由扎什伦布寺院喇嘛等，及大众启请大师前来后藏，大师应请前往后藏，沿途为难以数计僧俗大众，广传增上善及解脱道教法种子。到温寺时，大师在温萨巴大师的灵骨塔前，大兴供养，并发宏愿。由克珠。桑杰耶喜(义为佛智)的启请，大师为温寺僧众传授了很多要法。由扎什伦布寺僧众捧持各种供养，迎接大师登无畏狮子座，为会众讲说传授了很多显密教法。大师继即前往噶当教法发源地纳塘作供养发愿，并为僧俗大众广施法雨。继前往扛金却迫寺(雪域法增寺)中，在吉祥军刀天女护法前，作盛大的供养及劝行事业，并为僧会大众说法。继前往措普寺，在弥勒大像前作供养发宏愿。继前往萨迦寺，在所有经、塔、像前，作大供养，特别是寺中的犀皮所制的护法神面具，谁也不敢抚摸，大师用手取下，将尘土拭净，手捧面具，注目观想时，发现护法发生欢喜稀有瑞相。继前往喀乌，在贡谢护法前，催请行事业，得到护法示现欢喜的征相。继返哲蚌大寺主持教法的重心。继由色拉寺僧众虔诚启请，大师前往色拉大寺广传很多显密教法。就这样大师为弘圣教不避辛苦，足迹遍游卫藏各区。对于佛法还没有生信的大众令其生信，已生信的令其增长，使宗喀巴大师教法，普兴于诸方，他主要是主持哲蚌寺和嘉寺两寺，并轮替驻锡两寺，由财法二施之门来作教抚。

他在作这样弘法事业的一切时间中，从来没有间断过他的精修次第。以一天来说，他的修行次第：是先修毘沙门供沐法，继修皈依、礼拜供养法、菩提道次直观修法、北俱卢及大小贡波长寿法、四尊合修灌顶、入心往生等法、黑文殊法、上师瑜伽法、发心仪轨、禅定眠诀、胜乐身曼陀罗及根本咒百遍、心咒及还心咒三百遍、不动金刚咒百遍、甘丹四尊诵修法及咒百遍、赞颂及愿文类、无量寿生圆二次第、长寿法指授、白度母法、文殊法、妙音母红白二法、空行母法类诵修、胜乐四座进修三百遍、长咒二十一遍、主要修菩提道次第、修菩提心法、观修“觉”法、生圆二次第诸法类、多种护法圆满供及赞颂、劝请事业等法，都是不断地精修。

继在辛未年，阿尔泰王闻大师的声誉，心生敬信，启请大师前往东蒙古。大师观察自己度化的机缘成熟，也就应请前往，并约将来他和施主在青海地区相会，暂派持律师准珠桑波(义为精进贤)为那边供师处所的总管。到了起程前往青海去的时候，前来送行的有甘丹寺退位座主，及色拉、哲蚌两寺导师、峨喀瓦大师、后藏班钦、日巴生根、温萨。桑杰耶喜、扎喜仁巴师徒、嘉寺的朗喀绛巴师徒等，总括说有唉达雅鲁一带的很多师徒等，及哲贡迦的代表，及很多部落的代表，蒙王扎喜饶登(义为吉祥坚)等。大师对送行人们，大都说：预计从那边随即返藏。大师从热振起身上马的时候，扎喜饶登王手握大师的马镫作颂说：“教法吉祥师寿固，持教大德遍十方。”由于仓促地作颂两句，也就流下泪来，不能续颂下去。大师在马上续颂说道：“圣教施主权威增，教法久住吉祥来。”于是动身到达孜曲喀(长江上游)的时候，由于鬼神作变，江水突然波涛大涌，彼此两岸都难渡过，大师只略示忿怒神相，并作克制手印以镇伏，一切人畜都得安全渡过。继到达业措(鱼湖)上区的时候，以寺院为首率同所有僧俗大众，齐集大会，以三千两黄金为主的盛大供养，供于大师座前，大师为大众传授了《上师瑜伽法》、及《六字大明咒》诵授，并对将近千人的出家众，传授比丘戒，将大众都安置在解脱道中。继续到了黄河岸边的住地时，人们都说河水太大，暂时恐难渡过。待到明天黎明时，一看河水，不过箭筒那样的深，以此大众都发生莫明其妙的惊异。渐次来到阿日迦波草原支幕住憩的时候，阿日大众前来供养大师马千匹，及其他牲畜将近万头。天空彩虹作幕，天雨瑞花。大师对那里的所有人众，广说教法，播下解脱种子。

渐次由过去委派去作蒙王阿尔泰的供师处总管法王准珠桑波，及译师国师二人为主率领五百马队，从蒙王驾前，前来迎接大师。渐次到了五月十五日，所有旗队、乐队，各级执事人等，以及堪作蒙王上师的诸大德、才德智力等都十分高超的蒙王驾前侍从人员等，在各级执事的后面，不是任意乱走，而是上流行态彬彬有礼，如大象徐步沐池中那般安详稳步。他们的左右及后面，有数以千计的汉、蒙僧俗的很多马队围绕，地动山摇般地走了约一次午餐的时候。那位依长寿天运作这诤劫时中的转轮王阿尔泰本人，为表示将黑暗的边区变为白净的善土，他特穿白缎服，率领仆从约有万人，以及他的王妃也率领很多仆役，一同来赴庆祝师宾与施主相会大会。会开始时，是用银五百两所制曼陀盆，上供一可容一升量的金碗，碗中盛满各种珍宝。此外五彩上缎二十疋、以装饰诸宝鞍镫的白色骏马十匹作领先的良马百匹、市中所无的极品五彩缎十疋、白银千两、绸布等难以数计的物品，供献在大师座前。于是在千百市场集会的当中，师宾和施主犹如日月双星一齐来到。由皇太极(译音)发言，国师译师坝根喀翻译说：“过去在切迦地区的种姓中，以切族的势力为大，以武力将汉、藏、蒙三族人众统治在权下。也就与萨迦派连系上师宾和施主的关系，使佛法大兴。后来，从帖木耳王朝佛法中断，作的是罪业，吃的是血肉，成为如血海般的黑暗世界。现在得到如日月双星的师宾和施主的恩德，指示出正法的大道，变血海为乳海，这样的恩是很大的，这里地区中所有的汉、藏、蒙三族大众，都应当守持十善法戒。从今天起，特别是对蒙古‘切迦’制定法规如下：过去蒙人死后，不管贵贱的人们，是把自己的妻妾奴仆牛马等，杀来作牺牲品。今后，应对杀作牺牲品的牛马等凭心作一适合的代价，供于僧众及上师，请求为亡者作回向祝愿。绝对禁止杀害生命来追荐祭祀亡人。如果仍照旧习行事，所杀的是人，则依法处死刑，如果所杀的是牛马等畜类，则依法全抄其财物。如果对于喇嘛及僧装者，捶打鞭鞑，对动手者全抄其基业。过去在木主上写上亡者的姓名，每月初八、十日、三十这三天中，杀牛马等来作血食祭祀，依贫富来作杀牲的多少。从今后起，将所有木主烧掉，逢年月时中的供祭，绝对禁止杀生，如有犯者，依法处以随他所杀的牛马生物十倍的处罚。不烧木主者，处以抄家。木主的供奉，代以供一六臂怙主护法神像，对于这一神的供奉，也只能用三素食来作供品，绝对不许用血肉来作供。此外，一切人等都应勤行善法。逢每月初八、十五、三十这三天应持斋戒。汉、藏、蒙所有大众当不作不必要的劫夺杀害。总的说来，这一地区也应当如西藏卫藏各区那样的作法。”宣布了这样的很多法规。大师也为大众传授了《六字大明咒》，由译师用蒙语翻译，令众得知。以此不管贫富贵贱所有大众，都诵《六字大明咒》，发现彩虹作幕，天雨瑞花等瑞相。那边地区中，宗喀巴大师的教法，获得大弘增长，发现很多善神欢喜的瑞相。

继在这师宾和施主相会的地方上，建立起佛殿，供起佛像、经、塔并安置了很多僧众。在庆祝大会中，供大师的供物：有以市中所无的三件极珍贵的大披风为主的缎料披风一百件、五色彩缎一百疋、以珍宝的珠串三串为首的珠串一百串、各种兽皮一百张、满盛珍珠一大金碗、蟠龙银印全套七颗、白银千两制成的器具，金帽及全套服装等蒙王自用的服饰、每件白银五两所制的碗和碗托七套、马蹄及羊蹄形的银宝五百两，布一千束、以装饰有珍宝鞍镫的白马三匹、领头的良马一百匹等物作供养。大师对那边所有僧俗大众，按他们的根器传授适合的法雨甘露，使所有大众都对怙主观世音菩萨及宗喀巴大师，一心虔诚信仰。在那大片蒙区中，居住的人们，过去喜吃血肉，唯造作杀害生命的罪恶行为；以及由于受巫道的愚惑，人死后杀害很多生命，来作供祭的罪恶行为，经大师将这类罪恶邪见的人们调伏后，所有那边各区中，都建立起佛、经、塔像，都念诵六字大明咒和密集玛(宗喀巴大师心赞)，都建立起为荐亡作善，供养三宝的善规。

大师为了令宗喀巴大师教法久住起见，他在理塘慈氏洲寺及宗喀巴大师诞生地——塔尔寺(亿身寺)等寺中，建立了很多僧院。特别是他对于塔尔寺，宗喀巴大师刚生时，剪脐滴下血水所生出的旃檀树，这是世间圣神的供养福田，他用白银包起来造成塔相，并建立了显密两种极纯净的讲说僧院，使宗喀巴大师唯一的教法遍弘于一切方隅。洛桑却季绛称(义为慧贤法幢)大师对这位大师赞颂说：“大师调伏他难调，边地极恶诸众生，完成福慧大海中，佛陀事业前祈祷。”又洛桑耶喜大师赞颂大师说：“善导恶众解脱道，福海师前我祈祷。”大师为了饶益后世众生起见，著有《菩提道次第金熔论》，此外，还著有不少的祈祷文、赞颂、悟道歌等。

继后，色拉、哲蚌、甘丹等三大寺，及卫藏地区所有僧俗大众极力启请大师返回卫藏，大师也正准备返藏的时候，喀什米尔王遣使上书殷勤劝驾说：“大师对边区所有应化众生，大半都已作完满愿的事业，以此请法驾前来我土为祷！”如像释迦世尊在拘尸那城示寂那样，大师回复了喀什米尔王允到那边去的书信，也就渐次移动行辕，前往蒙王的宗祠祀宫“香多”遗迹地方，为一些王臣人等，传授了婆伽楚金刚灌顶，对大多数人众，传授八支分戒等。到了蒙王大供的节日，在一间白银建造竖立两柱的屋中，陈设大师座位，以此大师说：“虽是暂时不需，还早一点，但是适合意愿，也就可用。”大师心念中是想到奉安灵骨银塔的缘起预兆而说的。供师供品有金银绸缎、马匹、铠甲等数以千计的供品。那里安置有僧众，大师在那里做了广大的开光法事。随即到了戊子的新春年节，作了广大的宏愿。在正月底，大师略现病相。这时大皇帝派来坐八人抬舆的使者，捧来金书封大师以极高品位“灌顶国师”的名号。迎请大师前往皇帝的宫中。大师想到这是很好的缘起，也就应允了前往皇宫的请求。在三月间，大师病体转重，对全体信众，亲笔写下最后的遗教。圆满了他的度生事业的时候，是在戊子年(公元一五八八年，明万历一十六年)三月二十六日，黎明拂晓，示现圆寂，往生兜率陀宫至尊弥勒，及妙吉祥藏座前。

意乐修行菩提道次第的人们，应谨向索朗嘉措大师祈祷求加持，并当依照大师所著《菩提道次第指授金熔论》中所教授的那样，勤修摄一切经论要义的菩提道次第。
