# 六十九、善巧成就大德拉准·索朗伯桑的历史

颂句中赞说：“善巧成就福德贤。”

值得这样称赞的，善巧成就大德拉准·索朗伯桑(义为王子福德贤)，降生在阿里的芒玉上部王族中。他从幼在伯土寺中出家，继后来到后藏扎什伦布大寺中，研习《释量论》，及《般若》、《中论》、《毘奈耶》、《俱舍》等经论，达到善巧精通的时候，他也就前往前藏杰塘等辩场立宗辩难。继在成就自在精密大师根敦扎喜(义为僧吉祥)座前，听受《金刚手大轮灌顶》等很多经教、灌顶、教授等要法。又在一切智索朗嘉措前，听受《教义三要》指授等很多要法。他心行二种如理依止甘丹座主法王格勒伯桑，在法王座前，听受了摄一切经论要义，为一补特伽罗修行次第，宗喀巴大师心髓中所出的教授——《菩提道次第指授广释》。他舍离了此世中所有放逸散乱诸务，住寂静处，专修《菩提道次第》胜法。继后，他的名声，也就遍传各方。他对于前来求学教法的很多人士，依他们各自的根机，为他们讲授合机的教授。特别是夏巴却杰(甘丹寺副座法王)，贡邓。朗喀绛称(义为虚空幢)法王，及甘丹座主根敦绛称(义为僧幢)，一切智索朗嘉措等很多持教大德，都摄受在他的门下，广弘《菩提道次第指导教授》。主要是这位大德在这生中，全不放逸，专一修行达到彻底证达。

意乐修行菩提道次第的人们，应谨向这位善巧成就大德王子索朗伯桑祈祷求加持，并应效法他的清净行传，很好地求得菩提道次第的教授后，也就舍弃此世事务，住在寂静处，专修菩提道次第，获得彻底的证达。
