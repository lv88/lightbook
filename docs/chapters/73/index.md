# 七十三、伯觉称勒饶杰大师的历史

颂句中说：“恩德无等西菩提。”

值得这样赞颂的伯觉称勒饶杰大师(义为圆满事业广弘师)，诞生在甲辰年(公元一六六四年，清康熙三年)，仲区地方的仲曲种姓中。父名须鲁邓珠(义为童成义)，母名意正(义为心持)，给他取名叫却杰罗布(义为法王宝)。他学习书法、诵读等，不觉困难也就能通晓。到了七岁时，在法王昂旺耶喜住巴师前(义为语自在智成)，剃度取名叫昂旺扎喜恭迦(义为语自在吉祥善庆)。继后，他也符合父种(密种)，听受了很多新旧密法。特别是他得到昆敦。伯觉伦珠大师的摄受，传授他近事戒，中间成全他出家，给他取名叫伯觉称勒饶杰，并命他常住在身边，暂时免除服役。他满二十岁时，就给他传授沙弥戒和比丘戒。总括说来，他听受了很多显密教法，特别是详细地听受了一切显密经教的心要——《三士道次第导释》，心中获得悟达。继后，他复听受了《四注合释》，《五次第明灯论》、《胜乐隐义明灯论》、《克珠洛桑所著的时轮总义》、《密集生圆二次》等论后，前往哲塘寺游辩场，立宗辩难。

继后，他驻锡颇章喀僧院中，听受了《噶当经卷》、《教法次第广论》、《兰犊瓶册集》、《喻法三种》、《修心法类》、《噶当六论》、《慈氏五论》、《中观六论》、《密道次第广论》、《密集阎摩法类及胜乐、喜金刚、时轮等曼陀罗、生圆二次等法》、《菩提道次第广略二论》、《中论、入中论释等》、《持律师全集》、《广略学处等》、《普明大疏》等所有追踪宗喀巴大师的很多著述。以及《密集五次第》、《往生法导释开金门论》、《修心七义论导释》、《菩提道次第》、颇章喀大师所著的《认识所有宗见直观导释》、克主杰所著《三界尊胜能怖金刚四种事业幻轮》、《六臂怙主小册》、《金刚鬘四十五种灌顶》、《密集不动金刚》、《鲁枳两师传胜乐法类》、《能怖金刚》、《大轮红阎摩法》、《普明法类》、《不动金刚法》、《无量寿等法类》、《成就法百种》、《二十一度母法》、《怙主护法十三尊》等很多灌顶、传经、导释要法，又在班钦。洛桑却季绛称大师前，听受了《鲁师传胜乐灌顶》，及《四面怙主护法灌顶》、《大手印明灯论》诵授等法。这位大师这样成为教授海藏时，他也就对很多具缘大众，广传要法。继后，他前往玛耶巴大师所建耶巴波迦寺及贡塘法座妥觉僧院。一切智五世达赖喇嘛也依止他为师，在他座前听受很多显密要法。特别是听受《菩提道次第导修广释》，以此尊崇为恩德无比的根本上师。这位大师就这样作弘法利生事业后，在他圆满度生事业时，是在丁酉年(公元一七一七年，清康熙五十六年)，享寿五十四岁，示现圆寂。

意乐修行菩提道次第的人们，应谨向伯觉称勒饶杰大师祈祷求加持，并应效法他的清净行传，心行两种如理依止一切福善根本——善知识师前，求得显密教授，就当勤修这样显密完整道体的心要。
