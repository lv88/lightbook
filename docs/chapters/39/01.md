# 附一、岗波巴大师略传

岗波巴系在丁未的那年，诞生在梁区上部播皇村中。父亲名乌卓桑坝，母亲名学绒萨。他二十六岁时请求达波绒玛那里的玛裕洛敦作亲教师，侠哇岭巴师作他的轨范师而受了具足戒，命名为洛军(义为智慧)，可是一般都称他叫索朗仁清(福宝)。岗波巴他依止嘉裕瓦大师、侠哇岭巴、嘉云达、格西楚巴、柳绒巴大师、甲嘉。日贡喀哇大师等大德听受了所有噶当派的教授后，想依教授而修，于是在父亲和祖父创建的基业地方上，修筑起他的住室。而以父亲遗留下来的产业田地作养生顺缘，一心专修。经过长久时期，获得菩提道次第的修验，心中生起了真实的厌离轮回的出离心，与及慈心、悲心、菩提心，并通达了空性正见。他能专住三摩地中经过很多日数而不起座。他绕行甲嘉山时，从三位乞丐口中，闻得密勒日巴的美誉名声生起敬信。于是将父业田地变卖成黄金，到噶当派诸上师前作告别礼拜后，也就去到了至尊密勒日巴的座前，听受了那样所有无上密续部的心要精髓——《那若六法》，与及属于六法中的支分教授，依之修行而获得修证通达。他知道度化众生的时机已到，于是兴修达拉贡波寺，作利济一切有情事业。那时都称赞他汇合噶当教授与密勒大印两种法源于一流。他所摄受的弟子中，也出了不少的善巧有成的门人。

以此意乐菩提道次第修心的人们，应当对于善知识嘉裕瓦大师勤行祈祷求加持。并效法这位大师的德行——心行两方面都如理地依止万善的根本——上师大德，而尽力勤修三士道次第。
