# 三十九、善知识嘉裕瓦的历史

根据宗喀巴大师《师承赞》颂文中说：“如法依师者，当推童光师。”

值得这样赞叹的大善知识嘉裕瓦，降生于堆隆过阁隆地方，父名雍中坝(恒焰)，母亲是堆隆巴的姊妹名季江萨。在属卯的那一年(宋高宗绍兴五年，公元一一三五年)诞生，起名叫绷达(义为亿常)。由于他过去生中长久修道的薰习力，自知远离孩童行为而自然地勤求正法。他在七岁的时候，就值遇堆隆巴大师，因为他是一位能如法依止善知识的特殊人士，堆隆巴大师十分喜悦他而尽量传授教法给他。继到十二岁时，在察脱寺中，由伦觉巴的弟子贡巴绛扎作亲教师，及慬哦瓦大师的弟子耶喜绛称(义为智幢)作阿阇黎给他受了出家戒，取名叫须鲁窝(义为童光)。他十三岁的时候，任过阁隆寺的管事僧一年。他十四岁的那年他去到将要临终的母亲住所，为母亲传授皈依发心，他亲见母亲死去的因缘，对于一切世间的贪著，生起了很大的厌离心。十六岁那年他来到堆隆巴所住的地方麻卓萨，他很好地听受了《集学论》及《入行论》等道次第教授中一切论著，而使内心生起了定解。他心行两方面都很如法依止于善知识堆隆巴承事服役了五年之久。

有一次堆隆巴同他师徒二人去到慬哦瓦大师住的却巴地方拜见慬哦瓦，慬哦瓦以神通观察而再三说：“我的怙主大师！你有这样好的侍徒，真幸福啊！”堆隆大师说：“善知识你如果喜悦的话，就将他供侍于大师座前吧！”慬哦瓦说：“我的怙主大师！真的你能供舍吗？”堆隆巴想念善知识既是悦意这门徒，也就奉上一疋净绫而将嘉裕瓦供侍于慬哦瓦座前。过了一年之后，慬哦瓦对嘉裕瓦说：“我的怙主大师自己需要你。”给嘉裕瓦穿上一件氆氇衣服，仍命他回堆隆大师那里去。他回到了堆隆座前的时候，堆隆巴向他道：“你做了令善知识不喜悦的事吗？”嘉裕瓦答说：“我没有做使善知识不喜悦的事，而是善知识说，上师你自己需要我，所以命我回来。”堆隆听后说道：“这是怎样说的。我早已经将你供于师座了的，因此，你不要在我这里住，明天立即仍回善知识的座前去。”嘉裕瓦说过去他受上师的呵责，有时心中会生起一些恐惧，而这一次的呵责，他感觉心中生起得未曾有的快乐。于是他回到了慬哦瓦的座前，以此慬哦瓦说：“现在我们两师徒才应当说是很安乐的。”

他在慬哦瓦座前如法承事服役了九年之久，慬哦瓦曾赞说过他许多悦意的话。有一晚上他供曼遮而作祈祷，以此因缘慬哦瓦所有的舍利增长了很多。慬哦瓦复乐而对他说道：“但愿你这生中获得安乐。”博多瓦对他的侍者说：“那边下面(指慬哦瓦)，有一侍者师比你们的态度更令人喜乐。你们不信到那边去看，最低限度也等他做一笑容后才放他过去。”慬哦瓦又对嘉裕瓦说：“我愿你将会用你的智慧认清圣地业塘的史事。”又说：“愿我不得上升都可以的，而你是必得到解脱的。”由于慬哦瓦大师很喜悦嘉裕瓦的缘故，他说：“嘉裕瓦他来到我这里的时候，曾经发生过人们因嫉妒而说我这老头如同狗一样的话。”有一次堆隆巴去拜谒慬哦瓦大师的时候，他问说：“嘉裕瓦这一青年僧是怎么样的？”慬哦瓦说：“等他到门那边去，我说一说。”嘉裕瓦如命转到门外，慬哦瓦也就说道：“以嘉裕瓦这样的人来说，信心比我还强、智慧比我大、精进力也比我强、悲心也比我大，真如向空旋矛，全圆周到。”慬哦瓦说一切法要时，都是把嘉裕瓦安置在自己的座前。有一次在令普寺中芒惹贡巴同嘉裕瓦二人一起得到慬哦瓦大师教导开光正仪轨法缘时，却只是善知识阁钦波及芒惹贡巴二人；后来慬哦瓦驻锡柳绒时，对嘉裕瓦说：知道你需要这一仪轨，这是我特别将开光正式广仪轨教导给你的最初一次。

又慬哦瓦对嘉裕瓦说：“嘉裕瓦我每想你将会成为一个修行者的时候，就会来一次很庄严隆重的僧会。”嘉裕瓦禀师道：“有一晚上我梦见有净水瓶上面盖著许多镜子。”慬哦瓦说：“这是你应当说话令人悦意，常时必须照拂众人的象征。的确要有这样真实的心，在善知识前承事服役的时候，应当对如是若干的僧人做照拂，现在对如是若干人众应当起照拂作用。”嘉裕瓦说：“在外人想来，我完全负起慬哦瓦的服役事务，哪能通晓教法。这样的话在我的耳中早已听够了的。”

有一天早晨嘉裕瓦去叫抹灰人来，他刚走到木梯第三梯段时，心中豁然开朗，所有一切经藏教义完全显现，顿然入于三摩地胜境中。因此他对于为上师服役的功德生起信心，而说道：“季墨下院的善知识们不勤做为上师服役，而纯粹努力于闻法，这是错误。”有一次慬哦瓦对嘉裕瓦说：“你是怎样来办理了那些穿著的？”嘉裕瓦答道：“我昨天和今晨生起了一些气力，计算一下月中共供师十三件冬衣。我并不是以这些物品和信智来供养，而使大宝上师喜悦，我是尽我身体所有的力气来鼓足干劲来服事上师而使师欢喜的。直到现在所有善巧戒严的导师和修行人士们对我都有意乐，这点也是由作到令师生喜而来的。”有一次嘉裕瓦到乡土中努力勤奋而获得黄金十二两，堆隆巴复给了他黄金八两，共计二十两全供于上师慬哦瓦座前。临到慬哦瓦示寂的时候，他请求慬哦瓦上师对他慈念不忘，慬哦瓦说道：“诚然直至法身未灭之间，我们两师徒是永做父子的，我的愿望也就是这样的。”慬哦瓦示寂后，嘉裕瓦在朴穷瓦及博多瓦两师座前各寄去黄金一两以作供养。博多瓦说：“我这里的住房也在建筑，虽是温饱，然我是结合做事中而进入修行的。”堆隆巴惟恐嘉裕瓦受申斥，叫他不要住在这里。

据说嘉裕瓦他去到普湾的时候，亲见不动怙主现身，不动怙主是慬哦瓦的本尊，因此他揣测是已得到忧苦消除的时候；有一次他复亲见持钩刀颅器怙主明王现身。又亲见大悲观音多种现身，继后复亲见许多佛菩萨现身。又有一次他住在讲经院的时候，到了休息消遣的当中，他会见了阿阇黎罗迦菩提，阿阇黎并对他说法，于是他及时去到里面速修供养而作祈祷，以此他亲见许多空行母起舞而来。当慬哦瓦大师示寂时，对他说了三次：“你如意……”复说：“你不要往俗人所居住的地方中去，不必作比丘。”到后来芒惹贡巴对他说：“嘉裕瓦你应当作比丘。”因此，他祈祷慬哦瓦而观梦征。当即梦中开示说，得一佛塔不必作两种规制式样。当他想这是未许作的象征时，善知识很不以为然，以此复行祈祷仍须作比丘时，复梦著上师赐了他一尊身著比丘法衣的印度佛像。以此他想这是许可他作比丘了。于是求切乌巴作阿阇黎，芒惹作羯摩师，嘉。协饶坝(义为智焰)作教授师而受具足戒。继此他在朗日塘巴座前听受了《律经》一遍，复在嘉。协饶坝(智焰)座前听受了二遍，又在堆隆的阿阇黎协饶上师前听受了一遍共计四遍。有人问他听法的时候，是否记录笔记？他答说：“依靠笔记通达不到那里，须得在一时中大体知道一切法义。”

他在慬哦瓦大师座前承事服役了九年，他同常啼菩萨依止上师法圣，及种敦巴依止上师阿底峡尊者一样，如对于道之根本——依止上师法，的确做到为诸佛菩萨所值得赞叹的一位修行者。他到了二十九岁的时候，慬哦瓦示寂，他也就闭关专修了四年。在将要会集僧伽大众之前，他迎请敬。达玛罗达罗萨来说法。继后他想到须得修建寺庙，适逢嘉裕区的后方有修密士两夫妇将那里地基供于夏巴师，夏巴复供于朗日塘巴，朗日塘巴观察后说：“那块地基是很危险的。”而未收纳。后来复由夏巴转供嘉裕瓦，嘉裕瓦心中十分欢喜，于是作了迁地主神祇往他方的仪轨法事。并在一恶龙身上镇以卧具等而作调伏，在那块地上碰著一些大磐石，一些被击碎、一些被掩埋起来等工作，确实作了很大的努力。也就在甲午年而才在那里奠定下能建立起十二根柱子的中间高顶大殿，及安立四十二柱子的回廊基础。在第十三年岁次丙午的那年内，修建完成垛楚殿以上的寺院。霞惹瓦也很关怀修建事项，派遣了他那边的僧众去作修建佛殿的工作。侍者师协生(义为智狮)复从梁波下林边运来木材。中间高顶大殿建成后，侍者协生说：“一件大工程算是完成了，现在愿迅速完成修建工程以满心愿。”善知识嘉裕瓦说：“尽管装修进去吧！”在上回廊修完，而下回廊还未修成时，有名勒敦生穹(译义为小狮)的俗人对协生下毒，当协生侍者死的时候，善知识嘉裕瓦对他说：“你不必恐怖，我也将和你一起来的。”说后为他修了瓶仪轨，据说以此功德可以出离三恶趣。

佛殿很好地完工后，当中的高顶大殿中，以将近七十部十万般若经卷，及由上区迎请来的塔像等，来尽量安置上下殿堂，遍满庄严。其中也有如高竖旗杆的银制灵龛，龛中奉安慬哦瓦大师的心(系荼毘时经火不毁，而遗存的心)等许多塔像，系善知识嘉裕瓦亲自建立的。有一次在僧众会集中，善知识嘉裕瓦说道：“据说修建佛殿本来是国王大臣、菩萨的事业，而不是出家人的事业。可是过去的时代里，阿阇黎察杰耶喜(义为佛智)曾经修建过佛寺；又阿底峡尊者在尼泊尔也修建了塘毘哈日寺院，由此创立了很好弘法事业。特别是由于阿底峡尊者的记别教言，而善知识种敦巴修建了热振寺。我们为了满足一切上师的心愿，与及承事三宝，并饶益其他有情起见而修建寺院。我们在这十二、三年中，向其他信众，常时都在宣说‘死无常’。对于我自己来说，时到而今内心生起了一种真实的内外无常观念，对于业果生起了一种真实的信心，对于轮回生起一种真实的出离心，与及生起一种真实的慈心、悲心、菩提心，并由如幻的世俗谛对于真实性毫不颠倒地生起了一种真实的决定知。因此，我自己是有这样一种了解的啊！”善知识塔细贡准(义为四边精修)说：“所谓‘净行菩萨’这一名号，确是指嘉裕瓦而言。”当嘉裕瓦驻锡普穹时，芒惹贡巴说：“现在普穹地方中，有了一位用声闻的神变而作成熟有情的菩萨。”

有一次医生钦贡请问善知识嘉裕瓦道：“善知识！你心中生起了什么样的二谛？”嘉裕瓦答道：“我心中生起的是世俗菩提心和胜义菩提心。”钦贡复问道：“关于此点，是否由观察自心而解空的，抑或是观察外境而解空？”嘉裕瓦答道：“本来箭节是断在内脏里的，反而在外面去做一些涂抹伤口药的事，这样于事何济呢？又好比本来强盗已经逃入山林中去了，而我们反而到河边去追寻，这样也是于事无补的。以此应知能解空性的即是自心，自心通达则外边的枷锁脚炼自然解脱，一切皆为空性。”钦贡复问道：“善知识这样的通达是何时在内心生起的？”嘉裕瓦答道：“我最初在慬哦瓦大师座前承事服役时生起的。”又杰。岗波巴问嘉裕瓦道：“大宝上师你作了很多为师长承事服役的事，与及修建寺院等不少的事业，这些繁多的事务能不妨害你的静修吗？”嘉裕瓦答道：“不妨害我修业的。”又有一次有一门人到后藏去的时候，嘉裕瓦对他说道：“我整个一生中，是没有生起过世间的分别心的。你向我勤行祈祷，可以灾障不生而获得加持。”

有一次善知识嘉裕瓦说：“噶当派中，有很多善知识不知密咒，知道的人士，复未在善知识前，求得经教的传授。我们是知道密咒的，而又是在善知识前获得经教的传授。”他做了这样的指示也就传授了许多密宗的教授。善知识霞惹瓦虽是一位对何人也不表示亲热爱悦的人，可是他也曾经这样说：“嘉裕瓦之心，谁亦不能度量。”当霞惹瓦在野贡驻锡的那一时间，嘉裕瓦前去礼拜，继在回程上道的时候，霞惹瓦短送他一程，嘉裕瓦在短送途中对霞惹瓦说：“这以后我俩在兜率再见吧！”霞惹瓦说：“我们两人，并非老迈，在一短时间中还可相见的。”从此别后未得相见，嘉裕瓦也就圆寂了。嘉裕瓦曾经对嘉裕地方的人们说：“如果你不来到我的跟前，也就没有可以带来的顺缘资具。要是明年我圆寂的话，你须得今年当我的眼前，用手拿起那合量的糖，就把那圆寂的供祭供了吧！否则到得明年你能否成办那样的供事是不能决定的。”在修夏解制的时候，他对手下的办事人员和司供僧等说：“这下你们努力做一下应办的事吧！本来需要以后办的事，恐以后来不及啊！”又在诵戒后，长老准珠多杰(精进金刚)作了一次开光法事，嘉裕瓦对他说：“这是我最后一次开光法事。”他说出了这些示寂的话语。此外，嘉裕、隆学、扪卓三寺同于一时请他去作首座领经，与及安多地方昂昌寺和达波地方，侠哇岭巴修建的塔都来请他去开光。以此他吩咐他们：“在某天某时，你们陈设起广大的供品，念诵祈祷文，我就在我这小静室中作开光法事。”到了说的日期，在众目共睹之下，都见著他来到寺中和塔的前面，因此都传称那是他的化身。至于他为很多非人说法，与及具有生圆二次第的坚固定力，和广大的神通事迹，更是多来不胜枚举。

这位大德在很长久的期中，作了很多利济有情的事业。享寿六十有四，在戊午年(宋宁宗庆元四年，公元一一九八年)十月十八日示现圆寂。在他临终的时候，觉窝巴。钦季启问他说：“大德示寂后，我等当如何做？”他答说：“你们都应当清净守护应守的戒吧！对我应修起虔诚的敬信。我圆寂后的肉身把它荼毘吧！”继后他连说：“我们的善知识。我们的善知识。上师在金刚座很久了啊！”继后他的面部已无热气，作了一次自入仪轨，他复说：“还未到死的时候，不须悲哀！”说后作跏趺坐而凝视专注，继对贡巴降纳毘作亲切状，对他说：“我应作狮子卧状。”于是他的顶门有大股热气向上腾出，头上汗珠下落。此刻示现圆寂已。时在十月十八日，享寿六十四岁。示寂后第二日空中出现无数彩虹。二千僧伽中只是由温。协饶等诸上座来把持占有大德嘉裕瓦的肉身，其余僧众无权过问。继后由于善知识霞惹瓦说：“大菩萨的肉身如果使它腐烂，臭气四溢使嗅著者生厌而犯轻侮菩萨的罪过，以致会堕入地狱的危害，迅速净沐后荼毘吧！”诸上座也才许可净沐肉身，上身用石绵缠裹后，从下身举火荼毘。烟火迷漫而起时已发现舍利，灵骨中并有右旋螺、尊胜塔、度母等像。嘉敦师获得舍利二百五十七粒，贡巴。准珠绛称(精曲幢)获得舍利一百二十七粒，芒惹。须鲁雍仲获得舍利六十粒，格侠狮获得舍利一百五十粒，雅陇巴。达敦师获得舍利二百粒，梁波须侠所得舍利一粒当即发生了九粒，达侠君故获得舍利三百粒，廓阁隆银塔中奉安舍利一百零八粒，觉准绛巴获得舍利三十粒，造佛像工人廓嘉获得舍利三十粒，安巴获得舍利十五粒，在满堆的骨炭中复发现舍利七十粒以满足其他诸有情的愿望。嘉裕瓦大师教化下的二千五百僧众中，承传大师所广弘的菩提道次第法传衣钵的大德，为杰贡巴大师。此外还出有岗波巴等很多住持教法的大德。杰贡巴大师的史事将在下面述说。
