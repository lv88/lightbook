# 七十五、甘丹寺座主昂旺伯桑大师的历史

赞颂中说：“真实文殊语祥贤。”

值得这样赞颂的甘丹寺座主敬巴嘉措，别名昂旺伯桑(义为语自在吉祥贤)大师，诞生在垛康地区黄河北岸。他从童年起就有正法习气，不恋喧扰的俗家，身入佛门而出家。对宗喀巴大师一心敬仰，因而他效法宗喀巴大师的清净行传——先学习诸大经论，彻底地听受诸法，次将所闻经义结合自心，彻底实修。然后以所修成果作弘法利生事业。他生起这样的意乐，也就前往藏中哲蚌寺，住过芒札仓(多门僧院)中，精研《般若》、《中论》、《毘奈耶》、《俱舍》、《释量论》等，成为彻底善巧时，在拉萨宏愿大会期间游辩场，在善巧海众的当中，立四难论宗。继后，精研密教，驻锡下密院中，总对于四部密续——特别是对于无上瑜伽部，此中复对于父续《密集》，及母续《胜乐》两种密续释论等作了精研，成为善巧精通，由他的才德升登下密院座主。他依据密续之王——《密集根本续四家注释》来广说密法，复根据密续诸大疏来对如宝根器的人士，传授生圆二次第修行教导，以此大弘金刚乘教法。

此外，这位大师还听受了《甘珠尔》全部经藏及《噶当六论》，以及印度诸大班智达、大成就师的多种著述，《宗喀三师徒全集》等的诵授。因此，那时这位大师被称誉为雪域西藏中，听受经教诵授最多的一位。继后，他想到所闻经义，应取作修要，于是在圣观自在化现一切智五世达赖大师座前，详细听受了《菩提道次第导释》，依此专修，获得通达。到了自己身心得到成熟的时候，他也就为其他具缘的人们，广讲《三士道次第广释》，并随各自根器，普施显密法雨。继后，这位大师即升登宗喀巴大师所立甘丹大寺主持金座，讲说显密《菩提道次第》，以及在拉萨宏愿大会中，广说《释迦世尊往生事纪三十四事》等，使宗喀巴大师的贤善事业，常住不衰。他也就在甘丹寺座主任中，示现圆寂，往生弥勒，及妙吉祥藏座前。

意乐修行菩提道次第的人们，应谨向这位甘丹座主敬巴嘉措大师，祈祷求加持，并当效法他的清净行传，勤修显密经论要义菩提道次第。
