# 三十六、善知识门扎巴的历史

根据宗喀巴大师所作“师承赞颂”中，有颂句说：“透达对法海，当推门扎巴。”

获得这样赞叹的善知识门扎巴是降生在门地与措那地方之间的门扎地区。他少年时代，由于秉赋著很厚的正法习染，对于自己的乡土和亲族等也就不生贪恋、弃如唾秽，而来到僧院中大堪布措那巴的座前出了家，起名叫楚称扎喜(译义为戒吉祥)。他心行两方面都很如法地依止大堪布措那巴(系以地名人)，而学习解释三藏的大车轨诸教典，获得善巧精通的地位。特别是对于对法七论，和释论等都学习得来彻底精通，获得对于对法教义的无畏辩才。他复从措那巴座前受具足戒，并听受毘奈耶一切学处之后，他也就依戒实行，遂成为最胜的一位持律大师。就这样他钻研对于经教大海而无别彻底的善巧精通中，他更行在措那巴前听受依噶当教典派讲规而宣说的菩提道次第导修教授，随即实修起来而生起特别的修验，以此成为善巧、戒严、贤良三德具备的一位大善知识。措那巴大师也见他将成为能住持佛教中德行堪赞的主要人物，常时对他说：“你得作学院中的法座主持人。”

可是由于这位门扎巴大师对于菩提道次第获得彻底的修验，哪怕是梵天、帝释荣耀福德，他也不生羡慕。对于此生的名利恭敬，更不待说，是一点羡慕也没有的，因此他婉言辞谢说：“我怎样能够继持上师的法座。”到后来大阿阇黎措那巴临终时，曾经召集僧众做了广大的训言，并说这一法座交付与门扎巴来主持。说后而示寂。因此上师最后所说的话成为遗嘱，无法不遵。于是由门扎巴继登学院法座，主要广讲毘奈耶及对法；并按照旧规来讲说般若、因明、中观等教义，而使大车轨诸经论的教理得到很大的弘扬。对于一般具缘的人士，依噶当教典派的说规来详讲《菩提道次第导修教授》，以此许多人士都得到饱餐妙法甘露。他为了利益后来应化众生起见，复著有《菩提道次第导修释义》。由这位大堪布门扎巴教育而出的善巧有成的弟子，有佳钦。勒季多杰(义为大成就者。业金刚)，及堪钦。却季桑波(义为大堪布法护贤)等，对佛教作出了广大事业的许多弟子。

以此意乐菩提道次修心的人们，应当对于善知识门扎巴大师祈祷求加持，而效法这位大师的高风史事，由精研大车轨诸经论，而使内心体现一切经论皆教授。同时勤修所体现的经论中的教授——菩提道次第来调伏自心，并对其他应化有情也应做出决定的饶益。
