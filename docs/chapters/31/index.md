# 三十一、大菩萨吉布瓦的历史

根据宗喀巴大师所著的赞词中赞道：“具足教证师，菩萨吉布瓦。”

堪受这样赞颂的大菩萨吉布瓦，他是在辛丑年降生在梁区上部的达玛岗村，“生”是他的种姓。由于他在过去生中长久修学正道的习力还未失掉，所以他从少年时代起，就用不著由他人来启发和劝动他，他就能油然地生起猛利的出离思想，而在善知识恰巴的座前出家，到了合格的年龄他也就请求恰巴大师为作阿阇黎而受了具足戒，起名叫却季绛称(义为法幢)。以他与生俱来的绝顶聪慧，对于三藏经典所说的一切要义，很快也就学习得来善巧精通。那时他生起了这样的一种决定思想——他想佛说的一切佛经，与及解释佛经的一切论著，都是为了调柔此心而说，而调柔此了知的心，最殊胜方便法门，确为菩提道次第，及菩提道的心要——大乘修心法门。因此也就想去亲近具有大乘修心教授的主宰——大菩萨切喀瓦，他准备彻底地一次请求传授修心的教授，以后不须再在师前多番烦问，自己也就能终身专修这一修心教授。他生起了这样强有力的意乐后，也就去到善知识业。切喀瓦的座前，恰是善知识切喀瓦住在拉顶的时候，他和切喀瓦大师相见，也就开始听受修心教授。据说他依止切喀瓦有二十四年之久，专一地闻思修习修心教授。总之他从与善知识切喀瓦最初见面时起，直到切喀瓦示寂的时候，他都没有离开切喀瓦，一心依止请求所有修心教授，他的身口意的一切行动，都唯一地对于修心生起助益的作用，而进修整个的菩提道次第；特别是他对于大宝的菩提心生起了真实修验，而获得不退失的定解。他对于具足善缘的其他许多人士，也赐施正法的甘露。他如过去切喀瓦为他作的记别那样——“时在甲申年，建新切喀寺，并建切寺中，所有内依供，师佛三宝像，外依所供物，一切佛塔等。会集僧伽众，常在切喀寺，拉顶等地区，广说诸正法。修心秘要法，亦在集会中，对众作宣说。”继后他在有一时间很意乐去到最寂静的处所住的时候，当他刚迁移到静修处所时，比丘杰乌穹对他说：“大善知识你有了许多弟子，在这短促的一生里，我想任何一次领受何法，在显密两法中，都没有较修心教授为精深密要的，现在既将这样的深法作为可以对大众公开宣说的法门，我想这下这样的法门，这次决定是能得著的了。”吉布瓦答说：“现在说来真实的，比这一法门精深密要的，是没有的，本来不是对众公开宣说的法，但是大善知识切喀瓦无暇来聚集赡洲一切地区所有为了希求修心教授的被化众生，一一都作指导解说，因此作为对众公开宣说的法，也就是这样成为法规的。”他作了这样很端正的解说。继此由于他很喜欢寂静处所的缘故，在隆学地区，建立吉布寺，他摒除一切纷扰散乱，上至喀贡山顶，下齐梁位岗地划为关禁地区，而严谨地闭关，一心专修菩提道次第修心教授七年之久。当他住在季地区的当中，对众宣说修心教授，仅说过三次，可以说是就以时间因缘而论，也是不适合对众宣说修心法门的，都因为他不忍碍难大人物们的再三请求宣说的情面，而才说了三次的。所以他对众说：“现在在会众中宣说后，以后将不再说，你们都当谨记著吧！”吉布瓦大师曾经这样说：“在这‘季’地区自己也没有佛堂的当中，我的想法，是以这修心教授作唯一修行的；我的本尊也是以这修心教授，作唯一的本尊，以此任来什么散乱等缘，我的修心教授也不曾失掉。并且一切通达证悟，也是在教念修心句义中而生起的。”此后由扎迦勒敦(义为白岩寺上座)等切喀人众来迎请他，他应允许在冬季法会中赴请以满大众的愿望。从此以后到他示寂的当中，都是在吉布地方修夏；在切喀地方中，作冬季法会，遂成为定规，吉布大师他从切喀瓦示寂后的第二年丙申年起直到己酉年间，算来他在上下寺中共驻锡十四年，享寿六十九岁，于己酉年夏月十三日在吉布地方，如商主从大海中得宝归家，与游子从远方还乡般的喜悦而示寂，往生兜率说法宫中。这位大菩萨是《噶当宝笈》中很清楚地授有记别的人士。《噶当宝笈》中说：“有一时中作一吉布(义为小屋)而安住，由此会集许多比丘与沙弥菩萨众，依止白竭地罗村山中竭地罗林度母作加持的一位大德座前。”菩萨众说：“你是过去我们上师佛生(即种敦巴)的上师，名生准的那位大师的化现，也是那位大师的种姓。现在请你降临到隆学区内的吉布地方去，那里是天神等众加持的地方，你将住持佛种。由‘二拉’而生起广大的事业。”以这记别来看，对于地方等名称都很明显地授了记。由于这记别中(二拉)是对拉。隆根旺秋(义为经教自在)，及拉。卓瓦贡波(义为众生怙主)二人，也授了将成为主持噶当教法大师的悬记。吉布大师所有许多主持教法的弟子中，他的菩提道次第全圆教授，如瓶水全倾般得著的首要弟子确为拉。隆根旺秋。

以此意乐菩提道次第修心的人们，应当对于这位大菩萨吉布瓦祈祷求加持，并应当如像这位大菩萨的作风史事一样，聚集一切精力而勤修菩提道次第。
