# 八十一、大堪布索朗扎巴的历史

大堪布索朗扎巴(义为福称)，在癸酉年(公元一三三三年，顺宗元统元年)诞生在业谟彭松地方中。那时这位佛子的祖父在梦中，梦见一株花果满枝的大树，有很多美树周匝围绕，以此他说：“看来我们的这一孩童，如果住俗家的话，将是一个富聚人、财、物三者的人，如果修行正法的话，将是拥有广大徒众的人物。”他在幼年时代中，就能任有何物都给他人，对他人有极大的饶益心和悲心，甚至戏玩中，也是一种善法行动。

继后，他年满十八岁时，根却交(义为宝救怙)为作亲教师，须鲁达(义为童盛)为作教导师，完成他出家受沙弥戒，他在戒师前所允许的诸戒学，如理守护之中，精研闻思学业。在辛卯年，他年十九岁(连住胎期共计作为二十岁)，由大堪布邓瓦伯为作亲教师，大堪布四论师扎巴须鲁为作教导师，阿阇黎须鲁达为作轨范师，他受得具足戒，对所承受的诸戒学，能谨守不犯。也就在两位戒师前，很好地精研《现观庄严论释》及《戒经大疏讲规》，并听受《对法集论》、《入行论》、《密教内外修行法门及教授》等很多教法。又在大堪布四论师前，听受由杰岗大师所传来的《菩提道次第》、《修心七义论》，及阿底峡尊者的教授《中观真实略论》、《中观教授》、《度母四曼陀罗法》、《白度母修法》、《不动如来缘念三法》、《不动如来观修广法》、《中观派发心诸法类》等，以及《入佛子道》、《坝日瓦师传成就百法》、《药师仪轨及实施法类》、《阿底峡尊者广传》、《菩提道次第》、《修心法类》、《不动如来三种观修种字》、《缘念三法》、《麻衣马头金刚四种法门》、《慬哦瓦大师所传开光法》、《那索瓦所传大悲观音修法及教授》、《大宝九字等措普瓦师传教授》、《时轮六支法导释》、《中观修次三种》、《龙树所著经集论》、《十六尊者祈祷法》、《阿底峡尊者所著道炬论及自注释》等很多法门，以此对四论师作为受恩极重的根本上师。

又在阿阇黎须鲁哲座前，听受《般若十七法类》、《五地品》、《措普瓦师传成就百法》等。又在阿阇黎索朗耶喜(义为福慧)座前，听受《四部律经》、《律根本释》、《中观明句论》、《入中论》、《中观庄严论》、《中观显见论》、《中观二谛论》、《集学及入行二论》、《阿底峡尊者略法百种》、《霞惹瓦师传道炬讲义》、《兰袖珍集及觉敦古巴所著兰袖珍集释》、《切喀瓦所著各宗广论》、《纳塘巴所著胜道论》、《阿底峡尊者传及诸大德上师史事》、《唯识宗起愿发心》、《三士道导释》、《中观广释》、《修心七义论》、《修心八节》、《康垄巴所传修心八段》、《纳塘巴师传开光法》、《十六尊者观修种字广论》、《现证百法》、《上师时供修法》、《不空羂索十六法类》、《密续略疏》等很多经教。又在嘉裕瓦。桑杰觉窝(义为佛陀怙主)座前，听受《嘉裕瓦师传广略开光法》、《八臂救度母》、《誓句三严五尊及三尊修法》等。又在大堪布释迦须鲁(义为释迦童子)座前，听受《阿底峡尊者所传六臂马头金刚羯磨会供》等法类。又在喇嘛扎巴协饶(义为名称智)座前，听受《阿底峡尊者所传纳波巴胜乐法仪轨及鲁亨巴胜乐法释》、《喜金刚灌顶》、《阿底峡尊者所传摩诃玛雅曼陀罗仪轨及修法等》。又在堪布却季伯瓦(义为法吉祥)座前，听受《拏错师传教法次第》、《阿底峡尊者所传菩提忏悔法类》，又在喇嘛恭噶楚称(义为普喜戒)座前，听受《大悲观音法直观教导》、《阿底峡尊者所传不空羂索法类》、《坝日瓦师传不空羂索五尊法门》等。此外还在阿里巴。桑杰耶喜(义为佛智)，及喇嘛达摩西班遮(义为法吉祥金刚)，旺诺。洛卓登巴(义为智坚)，阿阇黎索协(义为福慧)，大堪布绛称伯(义为幢吉祥)，堪布土巴贡(义为能怙)，堪布扎巴伯(义为名称吉祥)，绒巴。协饶生根(义为智师子)，绛央仁嘉(义为文殊宝胜)，喇嘛达里钦波(义为佛大师)，纳钦恭洛(义为普智)，喇嘛克准巴(义为善巧严)，喇嘛恭噶绛称(义为普喜幢)，喇嘛邓约绛称(义为不空幢)，伯敦喇嘛当巴(义为具德师)，喇嘛恭噶生根(义为普喜师子)，喇嘛恭索巴(义为普喜福)，哲乌特巴堪布觉谟伽，阿阇黎仁清桑珠(意为宝意成)等，约有三十位上师座前，听受了很多显密教义和教授。

这样他的闻法学业，达到大海的彼岸时，他如过去古德们的行传那样，多闻的教义，用作自心修行的心要。于是他在大堪布邓瓦伯及四论师两位上师座前，求得发菩提心教授——《阿底峡尊者的修要三士道次第》，及所有一切《修菩提心教授》，一心专修。以此他心中生起了殊胜的证达。对于苦乐尊卑荣辱任何来到，都完全纳入在大乘修心的法门中，以此他的菩提心中，任何时候也能安定不乱。此外，他还听受了《般若法规导释》、《轮回涅槃平等性讲释》、《中观广释》、《缘起讲释》等诸教法，心中领会加以精修，由此心中悟达一切法远离八边戏论，如梦幻水月等，安住在大光明三摩地中，任何时间也不散乱，并获得甚深圆满次第三摩地。总说起来，这位大德，他外表示现的威仪，是以正法戒律为基础，沐浴清洁，三衣和滤水、襌杖、钵盂等比丘诸用具，不离身旁，实行三事作风，等同圣优婆离尊者的德范。他内心修持的精要，则为两种大宝菩提心及生圆二次第三摩地等，以此确是一位坚住比丘金刚持的大师。

继后，在丙寅年，他年满五十四岁时，任却隆(义为法教寺)寺堪布职，一直任职有一十八年的长时间中，抚育僧伽大众。他由四摄之门，作弘法利生的事业，门下弟子中出有如萨迦教主大喇嘛恭洛(义为普喜智)、及喇嘛邓约绛称(义为不空幢)、伯敦喇嘛(义为具德师)、喇嘛恭噶勒比绛称(义为普喜善幢)、佛子妥默桑波(义为无著贤)、智王布顿仁波切(义为布顿大师)等，不可思议的善巧成就的大德等。他对汉蒙及康区上下所有作恶多端的人们，用各种方便摄受他们入于善法加行中，对所有在家的人们，则使他们修学优婆塞等戒学基础。总之，他从悟会和法缘请求及加持等门中，完全作饶益众生事业。由这些德行的力量，权摄一切人非人等诸众生，而成办他的事业。曾经发现多次毗沙门天王来守护他和助成事业的事迹；复有护法摩诃迦那兄妹也在他的住室房顶，发生将塌危险时，前来撑著横梁和房椽的一段故事。他去到桑耶(圣迹地之一)的时候，大近事护神也来作绕护，是一般人们也能见著。他到吉仲地方的时候，正遇著那里发生剧烈的瘟疫和灾荒，使人们受著很多痛苦，这位大师当即向圣者瓦底那作供养祈祷，以此断绝了瘟疫的传染。又还有漏分粮食，立刻发现粮食等很多奇迹故事。

又有一次他在堆隆区朗瓦寺中，在沸水释迦佛像前，作供养法事，先调和好红花水，继请动佛像上长廊，安置在水中的时候，水立刻如溶化的铁水那样沸腾起来，形状如宝珠堆积起来那样。以此大会僧众，都油然地生起了敬信，前来求释迦佛像和这位大师加持的人们，多得来不能容纳。朗瓦寺的前辈近侍师对大师说：“这一尊释迦佛像，任来多少人作沐佛供养，从来没有听到像今天这样水极沸腾的话，我也是一个干枯的老朽，可是一见你的面，油然地就生起敬信来。”大师答道：“由于你也是噶当派中一位好善知识，以此我当敬献你由阿底峡尊者传来的一种法门。”说后也就传授了近侍师《大乘修心教授》。继后，他年满七十岁时，略生一病，他也就将手中所有物资，完全拿来供养僧伽及三宝。身体获得康复后，他将寺主职交给善知识索朗桑波(义为福贤)，心中愈谦卑安住。那时他说：“从此以后，我虽死也心安，随我所想的一切都已成办。”继在乙酉年(公元一四○五年，明永乐三年)，他年满七十三岁时，示现圆寂。
