# 七十四、一切智昂旺洛桑嘉措大师的历史

赞颂说：“遍智慧贤教法海，云集袈裟新众中，幻化持莲作救怙，众生导师前祈祷。”

值得这样赞颂的一切智昂旺洛桑嘉措(义为语自在慧贤海，即达赖五世)大师，在丁巳年(公元一六一七年，明万历四十五年)，诞生在穹杰地区中部达哲地方中，父名霍。对杜饶敦(义为伏魔坚)，母名泽江。恭迦拉哲(义为普庆天美)。从初生也就没有一般孩童恶习，对大众作说法手印等，很明显地表示出化身活佛的天性。亲见阿底峡尊者及宗喀巴大师等很多上师本尊示现。如《噶当经卷》中所记别的那样，班钦。洛桑却季绛称大师，及一些护法都说，与记别符合，确是云敦嘉措(功德海，即四世达赖)大师的化身活佛。由于那时，时风不靖，怕出灾障，以此班禅。洛桑却季绛称大师很善巧地通过藏王摄政迎请到哲蚌大寺中。在壬戌年二月二十五日，大师灵童年满六岁时，由藏王摄政索朗却迫(义为福法增)，及色拉、哲蚌两寺首要喇嘛等，以及僧伽会海中，幻现大德等数以万计的大众排列仪仗从哲蚌大寺中，迎接大师灵童来到甘丹宫中安住。大师年满九岁时，由班禅。洛桑却季绛称为作亲教师，甘丹寺座主根却却迫(义为宝法增)为作教导师，传授沙弥戒，命名叫洛桑嘉措(义为慧贤海)，于是在班禅。洛桑却季绛称座前，先听受《沙弥学处》、《诸法行经教》诵授，本尊大灌顶文殊菩萨法类，随赐灌顶等很多要法，以及《菩提道次第广略两论》等很多经教诵授。此外，还依止很多上师，听受了很多显密教法。复研习《五明学处》得到通达。继后，大师年满二十二岁，在戊午年三月初五日，在大昭寺迎佛释迦世尊像前，由班禅。洛桑却季绛称大师给他传授比丘戒，成为释迦能仁再现于雪山丛中。

继在辛巳年大师年满二十五岁时，由国师敦真却季嘉波(义为持教法王)，摧毁了摄政藏王，将所有西藏十三万众都收归权下，而献给一切智第五世达赖大师手中，建立普陀洛迦宫作达赖住所。同时也将西藏唯一圣大悲观自在菩萨天然现出身像，迎到普陀洛迦宫奉安供养。大师继依止伯觉称勒饶杰大师座前，听受《菩提道次导授广释》。继迎请班钦。洛桑却季绛称大师来后，在师前听受《金刚鬘法类》，特别听受了胜乐、密集、能怖三法类等，结合四部密续的灌顶、随赐灌顶等要法，以及《温萨巴全集》诵授，所有温萨耳传教授等。继应允国师敦真却嘉的迎请，前往后藏，为扎什伦布大寺僧众等，广施法露。师与施主二者都对班禅。洛桑却季绛称，作了隆重的供养承事。并对难以数计的僧俗二众相见，广施法露，对所有见闻接触的一切众生，都作摄受加持。

在壬辰年，大师年满三十六岁时，应大皇帝之请，前往清宫，为汉、满、蒙无数大众作饶益事业。回布达拉宫后，为边区和内地难以数计的人士，各依其根器，广转大法轮。特别是传授了无数次的出家戒和比丘戒。大师在很多大僧院中，创立宗喀巴大师的法传，并建立了不少的密宗僧院，如为众所传称的一切智五世达赖大师所新建的法轮极峰寺等十三大寺。此外，对原有的僧寺，布施学法基金，使其向上增长。他对所有一切寺院，都严整戒规。鉴于应化众生的身心不一，他也听受了不少的旧有的密法。他又在雪域西藏一切地区中，建造很多佛像、经、塔。为了令佛教久住，在众多寺院中，轮流不断地传授《甘珠尔》经藏，又在迎佛释迦世尊像前，供上各种珍宝所制的佛冠。并使康藏所有上中下一切人士，都念诵《六字真言》，对所有寺院中，都制定不断地修诵《药师八佛诵修仪轨》，及《十六尊者供养仪轨》。大师为了令佛法久住起见，著作有摄一切经论要义的教授——《菩提道次第导释文殊语教论》、《道之三要注释》、《噶当十六滴灌顶导授优越意严论》、《密集玛疏释》、《般若慧贤意庄严论》、《中论释》、《现对法藏引宝车论》、《毘奈耶羯磨仪轨金色尊胜论》、《别解脱戒学处》、《经仪轨如意王》、《十方仪轨》、《装脏实施法》、班禅洛桑却季绛称等很多先德行传，以及《听经录恒河流论》、《大师自传都拉姑上妙衣》、为了以政教治理康藏起见著有《西藏王臣记政法规》，另外著有很多本尊成就法等共约三十卷帙。

这样雪域怙主圣观自在化现出家身相的一切智五世达赖大师昂旺洛桑嘉措政教兼治此间西藏，作出了伟大的弘法利生事业，圆满他的度化事业时，是在壬戌年(公元一六八二年，清康熙二十年)示现圆寂，享寿六十六岁。所有大师的详细事业行传，详见于大师自己所撰《大师自传都拉姑上妙衣》中。

意乐修行菩提道次第的人们，应谨向五世达赖昂旺洛桑嘉措祈祷求加持，并应如他所著《妙音语教》中说：

“离器秽染正直耳，得闻正法美妙音，出自上师净语门，求得经劫成就福。

特是印藏诸善巧，具四大要心髓法，能益随类有情药，难得如日光显道。

由闻思修作修习，如是胜道诸贤士，舍离此世菲利心，猛厌贪欲心策励。

前往寂静山林处，幽林野花芳草地，容身石屋独居中，唯我与月影相俱。

仅闻潺潺山泉声，与彼呦呦野鹿鸣，摒绝三毒空谈语，无扰所缘禅定心。

衣粪帚衣乞食行，离恶毒泉染养生，三门励力净善业，攀登究竟乐峰顶。”等语。

当把握如是教言，在这仅一次获得的暇满人身的时机中，尽力薰修全圆无倒的菩提道次第教授心要。
