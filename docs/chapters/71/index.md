# 七十一、京俄。却伯桑波大师的历史

颂句中赞说：“深教受命师法祥。”

值得这样称赞的京俄。却伯桑波(义为法吉祥贤)大师，是在特地区的扎朗康村中，为京俄。洛卓绛称等善巧成就的大德传出的杰族中诞生的。他少年时也就不贪恋喧染的俗家，投佛教下而出家。依止索朗伯瓦(义为福吉祥)师，及却季绛称(义为法幢)等师，精研大车轨诸经论。特别是他对于索朗嘉措大师，心行两种如理依止，在大师前听受了摄诸经论要义，为三世诸佛所趣大道——《菩提道次第导释》，获得一切显密经论，都是补特伽罗取以成佛的教授的决定。舍离此世心，去到桑杰温敦大师所建的特达寺，一心专修菩提道次第。由于专修多年的修力，从依止师起，直到双运果位，对于所有显密两种完整道体、功用及无功用等，次第获得证达。在自己获得不退转的定解时，他对于有缘的大众，也广施大法甘露。以此他的声誉遍布十方。那时，求学菩提道次第的具缘大众，都会集在特达寺中。由于这位大师广弘圣教的关系，所出的承传教法的弟子，是难以数计的；受命菩提道次第事业的弟子，是昆敦。伯觉伦珠(义为圆满运成)大师。这位普遍颂称的大善巧成就师京俄。却伯桑波他广弘圣教，圆满了他度生事业，也就示现圆寂，往生兜率陀宫。

意乐修行菩提道次第的人们，应谨向京俄。却伯桑波大师祈祷求加持，并效法他的清净行传，摄一切经论要义于一完整道体，一心专修菩提道次第。
