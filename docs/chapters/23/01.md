# 附一、善知识康垄巴略传

康垄巴是乙丑(宋神宗元丰八年，公元一○八五年)的那年，在彭裕的穹瓦村中诞生的。族姓名“岗”。他是居士身起名叫释迦云登(义为释迦功德)。少年时代也就学习过经藏，他曾经这样说：“我在拉萨业塘地方，非牛非马的当中，也就把我的人生渡过。”他在业塘和阿底峡尊者相见，到后也就在热振寺长期依止善知识种敦巴。传说他有三位或四位弟兄。博多瓦曾经这样说：“穹瓦村的这位善知识岗。释迦功德，他能掌握主持真实正法而虔诚皈依，以此现在穹瓦地方中，没有比他快乐的。”这样的善知识康垄巴直活到九十岁之间，都是竖起修行法幢，而作利益一切有情事业。在乙未的那年(宋孝宗淳熙二年，公元一一七五年)他享寿九十一岁，七月十四日，在“康垄”示现圆寂。他有名的《八座修法》，经常有聚会的信众，约有一千人之谱。由于他生起了清净菩提心，所以凡是和他见面的人士，没有对他不生信仰的。从各方而来的人士，朝拜他的时候，他问他们说：“你们的地方中没有老头吗？”朝拜他的人答说：“老头是有的，可是没有你这样的老头。”总的说来他是一位凡是对他见面，与及听说他的事，和忆念他，都定能得益的大士(不是通常人士的话)。至于噶当三昆仲的史事，将在后面来详述。

其次，关于四位伦觉巴的简历：所说四位伦觉巴系指大伦觉巴。绛秋仁清(义为菩提宝)，及伦觉巴。衮巴瓦。旺秋绛称(义为自在幢)、伦觉巴。协饶多杰(义为智金刚)、伦觉恰达敦巴(义为除净师)等四位大师。他们的史迹，已在前面叙述阿底峡尊者的史事中说过了，这里不再重述。

其次大善知识迦瓦大师，与及桑朴瓦、勒比协饶、耶巴、善知识觉窝勒(义为善怙主)等大菩萨的不可思议的稀有史事，是很多的。但恐文繁累赘篇幅，在这里从略不叙。

由此来说，一切意乐修菩提道次的人士们，应当在对大悲观音胜者种敦巴的一切史事忆念不忘中，心中观想起种尊者的具德身相，常作祈祷求加持。特别是应当忆念种尊者所开示的舍此世心、与及为遍虚空法界如母有情的意义而修慈心悲心教言，每天勤修，内心应尽量种下菩提道次第的良好薰习。
