# 五十七、霞仲拉巴仁波切洛桑称勒的历史

“慧贤悲智千光力，开启谁之慧心莲，具缘事业如蜜宴，我师大德前启请。”

值得这样赞颂的霞仲拉巴仁波切洛桑称勒(义为慧贤事业)，先是依著班禅洛桑却季绛称的得意弟子，著名的大成就者霞仲拉巴。洛桑敦巴达杰(义为慧贤教盛)示寂时，及示寂后净身时，所现的象征，以及依许多上师与本尊护法所示记别，而在前藏地方寻获此师化身灵童。此师由于过去善业的薰习力，从幼年即不贪恋世间利乐，身入佛门而出家，他亲近班禅洛桑却季绛称门下的许多得意弟子，特别依止仲巴师徒听受显密无量经教。他复从具备教证功德的仁清邓珠大师听受班禅洛桑却季绛称传于大成就师朗喀多杰(义为虚空金刚)的《菩提道次第导修讲授》温萨耳传教授口诀等。依此教授薰修，获得殊胜通达。还有一本特殊的由朗喀多杰传来的教授，上师仁清邓珠笔记的《菩提道次第导修讲授》。

这位霞仲活佛由于夙世薰修善业的习力，出离心特强，并能谨守三律，清净不犯。复具自他相换的菩提心，以此能对无边具缘有情广种解脱及成佛之种子。班禅洛桑耶喜也对此师特别重视，将《菩提道次第导释》、及《上师供养法导修讲授》、《三种教要导修讲授》、《噶当大手印导修讲授》等法，十分欢喜地传授给他，并派他为纳塘绛清寺(大慈寺)的主持上师。他将赴绛清寺时，班禅观察知其对广大僧俗能作大饶益，特别在自驻悦意持法宫中，为他独自一人传授了观音斋戒法。霞仲仁波切也能完成班禅的使命，每年都在纳塘绛清寺中，为数以千计的僧俗大众，传授观音斋戒；此外在神变节日及转法轮纪念日等殊胜时期中，还为求学教义的善知识们传授观音斋戒法，就这样大悲观音法门，得以大弘。

特别是霞仲仁波切常时传授摄一切经论的要义，为诸佛所必趣之大道，即《菩提道次第导修讲授》，这样作出了大弘圣教的事业。对于《菩提道次第》修心而获得坚定方便的人来说，当以圣龙树解释《般若》经教要义，而作出的了义诸论，根据缘起离一切戏论边无垢理路，而示所有教诫，这一教诫是无比优越的。以离世务修行自在师洛桑朗嘉(义为慧贤尊胜)为首率同许多三藏法师，在霞仲仁波切座前请求传授《菩提道次第导修讲授》时，仁波切从依止善知识法门起，至修胜观之间的每一缘念法门，都详讲了修时经验，续讲一月之久。特别对于甚深中观正见，引用无数离一切边理智，来作出了决择的教诫。对于修法教授要义，是如怙主文殊菩萨传授宗喀巴大师那样的耳传教授来作指授的。霞仲仁波切在讲授《菩提道次第》中，总指示整个成佛圆满道体的修法，特别指导究竟中观见，是结合《般若》经教，深入解说《八千颂》义，以此他对于宗喀巴耳传圣教，所作的事业是有无量恩德的。关于霞仲仁波切整个一生的事业史料，尚未见有详细的明文记载，以后觅得时，在此篇中须得补充。

意乐修学《菩提道次第》的人们，应当谨向霞仲仁波切洛桑称勒祈祷求加，并效法他的德风，主要精修宗喀巴耳传教授，不空此暇满人身成为有义。
