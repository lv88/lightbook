# 三十三、善知识拉。卓瓦贡波的历史

根据“菩提道次第师师相承启请赞颂”文中有颂句赞道：“三界诸众生，怙主大宝师。”

值得这样赞叹的大德拉。卓瓦贡波(义为众生怙主)，生在颐章康玛(义为红宫)那里。系在丙午年诞生的，父亲名爵坝，母亲是枳贡巴王(西藏王族之一)的公主，名文领敬(义为赡洲美严)。他从童年时代也就能勤求正法，到六岁时在挡律公大师座前领受近住斋戒法。继后他见著俗家如牢狱一样，在强有力的出离心策动之下，十六岁时也就在切喀寺里，他的叔父隆根旺秋前受了优婆塞戒。随即请求觉摩隆那里的坝底大师作阿阇黎，卓萨哇善知识勒敦作教导师而出了家，起名叫旺秋窝(义为自在光)。继后他从齐波多请来善知识勒敦为作亲教师(即受比丘戒的戒师)；从兰古多迎请来善知识嘉察为作阿阇黎；请爵准巴为作教授师，而受了具足戒，并很好地学习毘奈耶诸学处，而按照著戒律实行起来。他心行两方面都很如法地依止叔父拉。隆根旺秋座下，总的说来他听受了许多正法，特别是他听受了从阿底峡师徒(徒指种敦巴)而到善知识博多瓦承传下来的噶当教典派的教授——“菩提道次第”从依善知识起一直到止观道中所有每一所缘念法门耳传教授都一一的认识；与及对于一切佛经和大车轨诸经论，彻底地引生定解的方法，都通过内心的修验体会而获得定解。

他在叔父拉。隆根旺秋示寂后，也就随即主持吉布及切喀两寺。计从癸巳年起一直到己未年间，他一共住持了二十七年，负起了教主的责任。继后博多上座和噶当教典派中的各善知识共同商议后，将博多门下所有母寺分寺都供献给他。公波那方面也供献达巴寺；弟子曲、江、隆三人带头约有三十个寺庙团体，也将佛庙的锁钥全交出来而作供献；其他达根方面复供纳达寺；根纳谟学区为首的寺团，也将寺庙僧众等全供于座前。后来很长久的时间中，都还在委派这些寺庙里领导人和执事等。由梁区那里让波伽人众复迎请他作“十亿佛寺”的开光法事，并将让波伽母寺分寺等都全作供献而交出了佛庙中的锁钥。仁哲迦寺也迎请他作大佛殿的开光法事，而将母寺和分寺等都全作供献。到后来让波伽与及扎图寺也因此发展出了许多护持吉布宗法的传徒；唉寺区也发展出许多如布达等施主和传徒。

这位大师他在共通道方面是修学菩提道次第；不共道方面是修学金刚乘道而闭关专修，以此亲见许多本尊，特别是获得不动金刚的成就，因此都传称他是不动金刚的化身。这位大师他在亚隆地区贡波山中亲见狮子吼佛现身；在博多时，这位善知识身中，有一尊说法智慧尊像也来入住其身中。由于他以佛法的内要宝藏——毘奈耶为主的缘故，所以他于吉布寺，在一安居持戒的当中，感得十六尊者亲身来到。因此胜缘，后来卓瓦贡波大师那里也就增多了许多有十六尊者围绕的画像；并且在修夏的时间也兴起受取十六尊者的一根筹木，与及在法会中供养僧众的茶饮时，读诵十六尊者祈祷文的规矩是没有断过的。他在拉萨获得迎佛释迦牟尼为之说法的加持。他到热振寺时，阿底峡尊者为他亲自现身而恩赐他许多教诫和未来指示。由于他闭关专修本尊法是很彻底圆满的缘故，以此名叫当的地方中，有一位大贵妇，魔入她的身中，谁也不能驱出那魔，他一去到那里作驱魔法事后，那贵妇的两腋下各飞出一鸽鸟，这两鸽直飞向江根地方而去，大众都亲眼见著，他随即很好地作了开光加持。当法王八思巴到外地去的时候，其他的所有送行善知识都挡驾请回，而只是对这位大师说：“我和善知识卓瓦贡波仁波切实不忍分离，请同行一程吧！”他也就直送到侠颇察哇地方，才转回来。

继后这位大德他复作了许多利济住持师和大宰官们的事业后，在己未年九月二十一日，他在吉布寺示寂，享寿七十四岁。于是他的弟子们为他做大供养后，火化他的遗体骨灰中发现许多佛本尊等像，特别是发现心、舌、眼三根未燃，眼珠装入了吉布寺的内供珍像——他的金身像的中间，奉安供养；由切喀寺迎请他的心到峨扎大殿中，奉安供养；舌则由荒古多寺迎请去奉安在大菩提像中而供养。并发现有四支右旋螺，其中一支奉安在汝巴寺的金像中；有一支奉安在邦萨哇大殿中，系峨扎寺所有；另一支奉安在吉布寺内而作内供珍物。

拉。隆根旺秋和拉。卓瓦贡波两位大师，与及住持这两位大师法传的吉布寺，和切喀寺的主持三师等人，在《噶当宝笈》中有很明显的记别。从为生。吉布瓦授的记别语句录意中，可以看得出来的是如说：“你未来将从一护持佛种的‘二拉’开始，由五德而发展出不少的龙象。”这位大师他所作的弘法利生事业，特别广大而普遍的缘故，所以一切智宗喀巴大师也赞说：“三界诸众生，怙主大宝师。”卓瓦贡波大师他固然是拥有众多不可思议的弟子，但首要弟子能护持噶当教典派法传的大德，确为善知识桑钦巴。

以此意乐菩提道次第修心的人们，应当对于拉•卓瓦贡波大师祈祷求加持，并且应当效法他的高风史事——护持清净无染的噶当史迹，而种下如他一样修共通道菩提道次第及不共通道二者的习气。
