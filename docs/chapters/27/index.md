# 二十七、大堪布朗喀生根的历史

据宗喀巴大师所著的赞词中有颂句说：“精进以虔修，虚空师子前。”

这样的赞叹妥扎大堪布朗喀生根(义为虚空师子)他系弘法的藏王赤松德赞座下信奉佛法的大臣须普伯的后裔，诞生在妥扎地方中。他的家族虽是旧密教的传系，但是由于他过去生中，长久时间修行佛道的薰习力，从他一生下，就唯能想念得起佛法，而说得上从幼起，他对于正法毘奈耶，就发生胜解。并且对噶当所传来的菩提道次第，生起专一的信念。他十三岁的时候，也就亲近依止阿罗汉坝底。爵色(义为怙子)的座下而出家。对毗奈耶作了彻底的听受和研习。由过去生中的善业因缘，他和持律大师塔玛巴相见，他很恭敬地祈祷求摄持，持律大师塔玛巴说，他将能尽形寿守护清净戒律。他于是心行两方面，都如法地依止持律大师塔玛巴，听受了一切佛语的心要——噶当教派的讲轨《菩提道次第指导修学释义》，而完全体会于心中。为了他在成熟共通道基础的上面，还进学不共道——金刚乘，塔玛巴大师给他讲说了《白色不动金刚本尊陀罗尼》，并传授了这一本尊的修法和教授秘诀。他也能依师传授而精修，以此得见本尊。这样他对于共与不共的道次第，在长久时间中，都作了猛勇精勤的修学，获得彻底的修验，所以宗喀巴大师是思惟他的这些有意义的史事而作颂句赞说：“精进以虔修，虚空师子前。”继后大堪布朗喀生根在善知识邓顶巴座前求得救度母法门。此外还求得三誓句庄严本尊，及藏巴拉(系财神名)，毗那夜迦等法门而精修，都获得亲见这些本尊。朗喀生根大师就这样勇猛精进地在长时间里研修，自己获得不退失的定解。他对侄儿大堪布朗喀嘉补等具缘的无边大众，广弘《菩提道次第导修释义》；并在妥扎那里树立三事的作风等，令戒律仪得以清净向上增长。他曾经作妥扎卓瓦寺等处的堪布；总的说来对于藏南地区，特别是须普伯世族的传嗣，次第而出了很多住持噶当教法的大德，应该说这些都是从大堪布朗喀生根的恩德而产生出来的。

因此，我们意乐修行菩提道次第的所有人士，应当谨向大堪布朗喀生根祈祷求加，并且应当追踪他的清净史迹，严持清净制戒以为基础，如水长流不断地精勤学修菩提道次第。
