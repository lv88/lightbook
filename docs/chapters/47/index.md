# 四十七、成就自在上师绛伯嘉措的历史

根据菩提道次第师承传中的颂文赞说：

“奉行文殊语，显密教海王，美严宗喀教，曼殊海前礼。”

值得这样赞颂的成就自在上师绛伯嘉措(义为曼殊海)，于丙申年(公元一三五六年，元至正十六年)诞生在安多区宗喀地方(与宗喀巴大师诞生处同)。由于过去生中的善习，从少年时代即能一心寻求正法，心中忆持《月灯经》等很多佛经与经论，特别是经常不断念诵《月灯经》。并由于往昔长远生中修行佛道之力，影响此生不待他人劝说，自即生起猛利出离心，皈依佛教而出家，持戒精严，如护眼珠。

那时，此师一心为求正法，以此年仅十八岁时，即来到前藏，住诸僧院中，但虑事务与人众的纷扰，加以思惟暇满难得，以及死来无定期等义鞭策内心，于是生起如常啼菩萨一心寻求正法的愿望，常时想念亲近依止很多善知识，听受显密经教。特别是想能亲近宗喀巴大师，听受一切教授，以便晚年获得修成究竟通达。据说继后宗喀巴大师在得瓦金(极乐寺)讲《大乘最上要义论》时，他前往听受，获得很好的了解。继后得到宗喀巴大师开示他说：“对于修行心要来说，还须获得了解整个道次；达到这般了解的程度后，当研习大车轨诸经论，须得做到能以无垢理智来辨别道与非道，以此对于因明等论也当精习。”这位大德依著宗喀巴大师的开示而行，他在桑朴等很多寺院中，研习诸经论教义，得到熟悉。特别在宗喀巴座前听受诸经论教义，获得理路。心念：“对于诸经论，既已彻底领会，现在应当一心专修。”于是在很多上师前，听受导修教授，依教专修而在修中去领悟。特别是在觉摩隆寺中，观修上师乌玛巴(中观师)及宗喀巴大师所传授文殊法门中的胜乐修法，据说因此得到梦游中国五台等很多地方。

继后，他住在喇嘛云桑瓦那里的时候，他曾经想念我现在应当去到人间净土——“色谟垛”或喀什米尔分区“更垛那”(义为神殿)等修行地方中，尽形寿修行。那时，宗喀巴大师也来到后藏与喇嘛乌玛巴相会，获得文殊菩萨的指示暂决定不讲说，舍世事专修。到宗喀巴大师从后藏动身的时候，这位大德心中想到宗喀巴大师既是离世事专修，我当作他的侍者追随大师而修，比这样更好的机会是再不会来的。于是拜谒大师，详述自己的情况。大师对他说：“我也要专修，你来吧！关于道果中诸支分，你还有须得要问的。”据说此师由此也就来到大师座前。宗喀巴大师离事专修时，启问文殊菩萨随带哪些弟子为宜。至尊文殊菩萨指示应随带弟子中，即有这位大德，及喇嘛绛噶瓦、喇嘛协饶扎、喇嘛仁嘉瓦(宝胜)、阿阇黎桑炯(义为贤护)、喇嘛绛生瓦(义为菩提师子)喇嘛绛伯扎喜(义为文殊吉祥)、阿阇黎伯炯(义为吉祥护)等人。

继后宗喀巴师徒从堆隆往达波方面前进，一直到达曲兄那的喀达那阁。随即来到阿喀，“阿喀宗”长官为首所有善信都请师徒各住经年。在却隆宗喀巴大师自住一茅蓬，其余弟子共住一大茅蓬中。那时，宗喀巴师徒如噶当派诸师之作风，依共通道修心为主，并心念：若不由以别解脱戒为基的共通道而次第登峰造极，初步即进入密法，那将为害特大，不获成就，如“无二狮子”那样的结果。以此都没有携带关于密教典籍和佛像等。当时这位绛伯嘉措大德由于对于《道果》教义将有所启问，以及他对于至尊文殊菩萨十分信念的原因，他带有文殊菩萨像一小画轴及《道果》教典一本外，没有带其他经像。依照喇嘛乌玛巴所说的最初将文殊菩萨各种修法传授与这位绛伯嘉措的指示，宗喀巴大师也就渐次将文殊修法，完全都传授与这位大德。大德绛伯嘉措即依大师所传一意专修，以此获得常见文殊菩萨身语明显坚定的净相示现。据说后来这位大德以此法门传授其他诸人专修，也获得加持的征相。

那时，众弟子每七天每人轮流在宗喀巴大师前服役，有一次轮流到绛伯嘉措时，传授以喇嘛乌玛巴记别传来的一种法门，同时启请对其他弟子也得传授。于是唤其他弟子等来大师前，陈设诸供，诚祈讲授后，众弟子都发生忧虑，于是请求宗喀巴大师及喇嘛绛嘎瓦不必参加这一苦行，其余诸人都服柏叶丸行辟谷苦行。而且这一苦行，先从这位绛伯嘉措大德开始做。为了敬重戒律的原因，这种柏叶丸须用的马乳酒，是以水来代用。这位大德每次服约三十丸即可支持，其他诸人每次则须八十丸。达哲巴说他资具足够，不乐意这种苦行而未行持。这位绛伯嘉措大德服了三年柏叶丸，以此原因，大众都叫他为“须珠瓦”，义为服柏丸者。就这样这位大德以“行供”来令宗喀巴大师心生欢喜。

由于此师长久依止宗喀巴大师，他完全获得所有摄一切佛语的要义的教授——菩提道次第教授口诀、除障增益等法；以及密集、胜乐、阎曼德迦三尊生圆二次导修教授口诀、除障增益等法；甚深道《断执供施》法门及此中一切支分；特别是兜率耳传法中，正见修要指授及其支分等一切教授，并决断所有疑网。至尊文殊菩萨以摄所有显密二教道要的耳传教授《幻化宝笈》赐与宗喀巴大师，以及这位喇嘛绛伯嘉措，在赐少数兜率天人后，《幻化宝笈》也就到了这位大德的手中。

当宗喀巴大师度化众生的一切事业，轰轰烈烈极盛的时候，这位大德以一心专修的意趣，念想现在自己应当寻觅一所寂静处所来修行，于是他去到默卓嘉乐地方住修过一段时期，此后应邦萨堪布的迎请，去到日哲康先谟(山顶独室)中，暂住过一时，继由邦萨京俄供赠这位大德一所“色瓦绒”的静修室，绛伯嘉措大德也就在那里住下，为以京俄为首的一切具缘善信讲说菩提道次第等很多法要。但这位大德心念还未到证得圣位之间，为人说法，对于他者利益不大，并且是成佛的障碍；于是泥封洞门，专修以度时光。他对黄金与尘土，怨与亲，亲与疏，世间八风等均作平等观。远离名闻利养贪欲恶见，住禅定以度日。那时，由于这位大德有显见至尊文殊菩萨身语意的声誉，四方前来拜谒启问未来授记的智巧、戒严、贤良的僧侣，以及高官显宦，大都难得赐见。有个别拜谒到此师的，也是首先自己破除边见，拜见时，他也根本不提见本尊等事。当时西藏执政“帕谟住巴”的大官们，特别是阿喀宗长官前来迎请这位大德到他们各自的别墅中去，并供养随此师所意乐的寂静处所时，这位大德说道：“我在此间寂静处，不需要任何人的情面，过著远离二边的生活。为什么要抛去这种行藏，到那边去呢？他们对我这样的恭敬承事，我不喜欢，须得负生命危险的责任。”他严词拒绝请求，不允前去。有一次一位受近事戒的居士对这位大德说：“从你座前拜见后归来的人们，每人总得受到你的一次呵责，他们反而以此生喜而归。特别是达惹喀伽见你时，你也呵责他说：‘我看你在这止贡巴的地方，也内外扰乱地倒乱起来了。’喀伽对我好，把你说的这些话，都对我说后，心中反生欢喜而去。”这位大德答道：“我是从未看过任何人情面的。”由于他是这样远离怨亲憎爱的一位大德，所以当时的人士，谁也感觉不出他有怨恨斗诤的表现。

又由于他忍苦与苦行的力量很强，以此一切时中，他都是如救头燃精进如常。当请他为僧众说法时，他说：“应当是对我说法，由于对人生起悲心，是须得自己先生起悲心的。”这样说，虽是不允说法，但是他所说的话中，是意味深长的，包含有甚深法义的分量。此师任说何语，都如坚石般不再改变，特别是他对于密法是极为严谨的。由于这位大德内心具足修德，所以就是宗喀巴大师也把他所禀告的意见书等用作通知，他人更不用说了。他曾用呵责的口吻说：“不管排列在大师座前的善知识们怎样的理智，总得僧众说话。他们的智慧大，我对师的信心大。”此外，这位大德所得任何财物从不积蓄，看作是他人的财物一般，从不取作自己的炊事和饮食来用，尽数用于培修福善方面。他总是说眼前一切有情，都是毁灭为其自性，应观贪欲的过患。

他有所启问，是问于至尊文殊，如何主张而后可。并且自己已证得功德，以此关于消除魔障、增益福寿、权摄他者，及威猛法事等，都可以依照自己的意趣而修法。所以大众为宗喀巴大师及法王持律师等人修延寿仪轨法事时，应修何种法事，都是由这位大德来指示；以及对于佛教有益的善知识，以何为宜，也向他请示。他见著有最大意义的时候，也指示那些在家人作适合利益佛教的事。以戒律方面来说，哪怕是三种律仪中的细微罪过，他都如护自己眼珠般守护不犯。他于一切时中，具足不忘忆念力，并且远离疲乏、杂扰、散乱等。他常时观察自己身、语、意三业是否清净，特别在每月初一和十五，更加力观察在此期中身语意三业，发现过失时，即时发露忏悔，并生起以后纵危及生命也不再犯的戒心。由于他常时不断守持大乘长净斋戒法，以此对于应取应舍，从未散乱而放逸。这样行持之下，这位大德对于三种律仪毫未染犯，因此阻止烦恼之因生起，使他成为一位调柔祥和的人。此师在阿喀桑敦岭(禅定寺)寺中听宗喀巴大师讲授密集生圆二次第后，依法净修，即得到本尊主侍诸尊完全显现。他复在大师前为另一生圆二次甚深要法，陈设主侍诸尊，并供金曼遮以启请。得大师传后，关于生圆二次中，对于一切情器世界必须遮止凡俗执见，此师说：“我修这一要义，也经过二十六天的修习，始获得成功。”又此师昼夜一切时中，守持菩提无漏(即不遗精)，以此他的身体如壮盛童体一样，容光焕发，白中透红，现出获得坚固的空乐三摩地的德相。特别他虽是年满七十的高龄，真是如赞美诗中所说：“尊颜如莲花，日照开敷时，蜜蜂见飞来，毅然入憩止。”他的容颜有如白雪般清净，而两颧红如涂朱，起行坐憩十分轻便，身直如箭，没有一点腰弯背驼之相。

这位大德他已证得空乐三摩地的殊胜功德，自然常见很多诸佛菩萨，有如水中显现月影。他从过去多生中积下得到本尊文殊菩萨常时摄受的因缘，而此生复敬信至尊文殊菩萨，由于他获得一心专修文殊菩萨的坚固三摩地的力量，他何时意乐谒见本尊文殊菩萨，即能得见而断除心中一切疑虑分别。他对于所见诸佛菩萨，及彼对他有所宣说等，任何修悟境相，总是观如梦境幻相，不足凭依。对于此师的种种行证，宗喀巴大师也曾经为他观察，特别是此师对于甚深要法中的一切疑难，得到正确解答，生起信念，然后对诸疑问，是复经详问而始获得解决的。宗喀巴大师在自己病愈的某一时间中，得见至尊文殊菩萨，菩萨对大师说：“从此以后，勤修生圆二次第瑜伽，将证殊胜通达，你有七位具缘弟子，也将获得殊胜通达。”当宗喀巴大师说：“这是否为修行幻相？”想问一具足通达者的时候，这位大德即时对大师说道：“这无须再问至尊文殊菩萨，心中生起这一胜道之因，是先已生起空乐胜慧。现在是外缘——‘田生使者’将速来作助伴，以此迅速将证此一胜道。”这是启问至尊文殊菩萨，已得至尊这般开示，以此是可信的。又这位大德说：“宗喀巴大师座前，常有一身著华服，头戴红冠的美妇来到。看来不会是天神相貌。这对非法器者来说，将为泄露密法之过。”这是在大师著《鲁亨巴师传胜乐释如意牛》完毕后，来的是金刚瑜伽母等相，显见是来作殊胜助伴的。又说：“在著造禅定壁勒玛等佛母供养音乐赞诗等及建立甘丹寺佛殿时，见有很多天女到来。”

这位大德在本尊文殊菩萨前，启问宗喀巴大师本生事纪。得本尊文殊菩萨示说：“宗喀巴大师不可思议的本生事纪，主要是大师能极善决择诸法，以此通达一切甚深法义，并能运用空有理智，通达所有基、道、果三门。多生以来即已获得陀罗尼、辩才、禅定、神通、神变等功德，常得本尊文殊菩萨的摄受。他曾在红焰帝幢王佛前，立下弘扬金刚乘等一切法的誓愿，得到十方诸佛如愿加持，成佛名狮子吼声如来，以一生中安置众生于佛位。如果从现在修彼如来，发愿生彼佛土，将来能得生彼佛刹中而成佛。”由此这位大德依本尊文殊菩萨所说，一心观想狮子吼声如来像，生极大敬信，努力精修，十一日中获得狮子吼声如来明显现前，即时祈祷发愿，得到将如愿成就的征相。阿阇黎桑炯瓦(义为贤护)说：“宗喀巴大师亲见本尊文殊菩萨身相庄严，威光炽盛，发言宣说与人无异。大师常说得本尊这般开示。”

这位绛伯嘉措大德虽是获得上述那样的教证无量功德，但他仍然想到总一切功德，是依智慧而来，特别是断生死根本，须依赖智慧(般若)，而智慧复是从闻而生。以此他寻求善说法者，毫无疲厌，在这样修行资粮具足的当中，他努力勤修，以此心中证得共与不共的一切通达，获得不生三恶趣等的保证。有一些善信人士从侧面问道：“这位大德经长久时间那般精修，想来大概已获得一种特殊证德。”这样问的时候，大德绛伯嘉措答说：“我没有什么其他功德，只是对后世不生恶趣这点，我想可说是决定的。因为去年病危将死时，我从风息收摄情况观察，也没有看出有走向恶趣(地狱、饿鬼、畜生三涂)去的风息收摄情况。”不生恶趣这一点，在不通显密法要的人们心中，或许会认为不是什么大了不起的保证。实际那样保证的话，在精通佛经及大车轨经论的人士们观察起来，确是具有很高证德的征相。要知道如大车轨经论中说：“生恶趣的苦因等，为见道所断。”因此，断离恶趣诸苦因，是已证得见道位。非舍离恶趣苦，而能得到不生恶趣的保证，这也应当是证得加行道忍位，才能不堕恶趣。以此看来，这位大德是证得加行道忍位，不堕恶趣，因此内心有此把握而作出那样保证话的。并且经论中说：“证得大乘上品资粮道时，当已获得法流三摩地，能真实观见殊胜化身，以及百由旬内，小至极微尘以上所有色相，并能知下至蝼蚊微虫的心思，及获得神通、陀罗尼、辩才、三摩地、不可思议智慧等功德。”那么，证得大乘加行道时，所获功德，应胜过资粮道百倍功德。想到这般意义，无怪善知识柳绒巴大德说：“我说大乘资粮道的秘密功德时，现在不禁想到胜超彼功德的佛陀，是有怎样的功德啊！”

这样的大德绛伯嘉措建立起了文殊宗喀巴教法承传修行的源头，安排善合宗喀巴大师的说修法流如恒河滔滔不断的缘起，并高树起了能仁圣教无陨长辉的宝幢。他将整个耳传教授《文殊幻化宝笈》付与授有记别当住持耳传法流的首要弟子坝索。却季绛称(义为法幢)，并由他发展出得意弟子京俄。洛卓绛称(义为智幢)等很多住持教法的弟子，使显密圣教得到弘扬光大。到得他此生事业大都圆满，犹如勇士从战场获胜，商人赢得百倍利润那般，取得暇满人身要义，圆满完成此生修行志愿后，念想往生宗喀巴大师安住的刹土——兜率说法内院，于是在他年满七十三岁的那年(公元一四二八年，明宣德三年)岁次戊申，他事先说本来打算在本年二月内修供一种法，时间将在初五、六开始，但是订在本年正月中修，时间将在初一日开始。后来是他在所预定开始修法的那天示现圆寂的。圆寂时发现很多稀有征相。邦萨瓦寺众将他的肉身奉安在金塔内，以作供养的福田。这位修行成就自在的大德，宗喀巴大师的弟子大都对他恭敬承事。他的座下出有很多不可思议的弟子，其中住持他的法流承传的首要弟子，有为至尊文殊菩萨所记别的耳传法流主要大德坝索。却季绛称(义为法幢)，及勇猛佛子京俄。洛卓绛称(义为智幢)二人。坝索。却季绛称的史事将在后面详述。
