# 附一、京俄·洛卓绛称大师略传

大德京俄·洛卓绛称(义为智幢)，于壬午年(公元一四○二年，明建文四年)生在特隆巴的扎朗康那里，杰。文热特朗族姓中，父亲名杰。温波却交，母名觉谟纳绷。由于他有往昔长远修道的习性，生来禀性厌离世间，由猛利的出离心策动他一心求法，不乐其他世事。他年满七岁时，即在叔父京俄。仁清恭嘎洛卓座前出家，命名为“洛卓绛称”。出家后他如护自己眼珠般守护别解脱戒，并在一切智克主杰，及法王洛卓巴等很多大德前，彻底学习《因明》、《现观庄严论》、《毘奈耶》、《俱舍论》、《中观》诸论后，遍游卫藏各地辩场。他年满二十岁时，措庆波堪布云敦仁清(义为能宝)为作亲教师，阿阇黎洛桑巴(义为宝贤)为作羯磨师，以及在有轨范师等清净僧伽大众之中，受具足戒。一时成为如上座大迦叶尊者再来此间西藏之光景。此后，他来到默卓邦萨寺，在修行成就自在的大德绛伯嘉措座前，心行两者都如法依止的当中，听受宗喀巴大师所有整个显密教授。那时，修行成就自在大德绛伯嘉措依文殊菩萨对他指示说，应将《耳传教授》完全传授与弟子洛卓绛称的那般记别，大德绛伯嘉措也就对此师另外看待，爱护栽培，而将所有教授完全传授给他。

获得传授后，这位大菩萨洛卓绛称对此生圆满亲眷、资财受用等，无所贪恋，在寂静处所中一心专修，由此证得一切共与不共道次第诸通达。继后，虽经大众再再请求他作岗寺寺主，但是他观察到所有世间荣华圆满，如魔诱饵，心生恐怖，设法退避，未允请求，仍住寂静处所，一心专修。岗寺寺主轮换四次中，每次大众都来请求这位大菩萨去作寺主，但都得不到他的应允。到第四次换寺主时，那方面的所有学僧及僧俗大众一致声泪俱下地哀求他作寺主，而将寺钥交在他的手中启请说：“今后本寺之主，大德愿作与否？祈师慈念！”这时，这位大德念到宗喀巴大师法流，并谨守不缠世事，以及开示善法、护持噶当清净宗风等大事，而应允去作寺主。此后，这位大德常时闭关专修，并于上下弦日长净斋期中，来为众开示要法，间或讲授《菩提道次第导修教授》及《修心教授》等。他铸造了阿底峡尊者及宗喀巴大师金像，供养无量供养，及建立永不废失的常供。此外，还建造了很多佛像、经典、佛塔等，在这些身、语、意所依前，供广大供养，并立常供。此师作了这般广大的弘法利生事业后，到酉年患足疾，修法祈祷而得愈。

他整个一生净行，完全与正法相合。他曾经自己亲口这样说：“年方七龄即学法，净修之中精励行，亲尝殊胜正法味，此为我之善愿量。现已年近七十龄，获得三宝之加持，浊世得达安乐境，此为我之善愿量。殊胜七法之心要，妙观察智勤励力，可达一切显密义，此为我之善愿量。”此师对希求解脱的人士们，是示以妙观察智舍离一切疑虑分别，安置于观修清净正见中；对声闻种姓人士们，示应如护眼珠般，守持别解脱戒学而安置于戒律仪中；对大乘种性人士们，示以离我爱执的垢秽，生起他爱执的慈心与悲心而安置于菩提心中；对于密乘的人士们，示以密戒安置于三昧耶中；对一切凡俗有情，为获得善趣故，示以善法安置于近住戒法及十善法中。这样对于佛教，作出了广大事业。京俄大德自己曾经说：“弘持佛教阿底峡，尊者法轨我精研，勤修三士道正法，此即我之善愿量。”

这位大德作出了这般广大的弘法利生事业后，将示现圆寂的时候，他开示弟子们说：“为人师者，是有所谓遗嘱的。但是我乐许没有留下物质的遗嘱；须得在上师死后，不因大批物质，而闹出有损上师声誉的事。阿底峡尊者在业塘将示圆寂时，恰赤却向尊者请示道：‘尊者将示寂，在这以后，我想暂时推延说法不知可否？’尊者说：‘我看这样做是坏事，休做吧！’复请示道：‘那么，一心专修好吗？’尊者仍如前答说：‘是坏事。’更请示道：‘那么，怎样做才好呢？’尊者指示了简单的一句话说：‘应舍此世心。’由此恰赤却把尊者的遗嘱谨记心中；远离恶食，而去到热振须色(柏林)中，度过此生。与此情况相同的，还有在热振有一绅士专经行绕塔。种敦巴尊者见著说道：‘阁下绕塔，我心中虽是喜悦的，但是如果作一善法，岂不更好吗？’那人请示道：‘我行礼拜好吗？’尊者仍如前答复。那人复请示道：‘我诵经好吗？’尊者仍如前答复。那人最后请示道：‘那么，怎样做才好呢？’尊者答道：‘应舍此世心。’这样说了三遍。后来种敦巴尊者自己将示寂的时候，他也是去到须色(柏林深处)，远离世间八风而说道：‘我是希求获得解脱者，不须利养的缠绕。’佛说利养与非利养，有时只说首句利养，有时只说半分(世间八风之半)，有时全说。但种尊者他是观世音菩萨的化身，他不需要那样的警惕，这是对后学有情而说的。总之，一心学法，是必须舍此世心。我从上师座前听到这样的开示：‘侍徒们可喜是出家众，没有顾虑我死后将会有怎样的结果到来。我自己是想往生到兜率阿底峡尊者与宗喀巴导师的座前，我对于阿底峡尊者与宗喀巴的教义，如钉锭木，正直无误地谨记心中，以此而今是无过可言。你们也须得思惟上师与本尊是无二无别，虔诚祈祷，才能获得随业容受的悉地。特别是佛像、佛经、佛塔壁画等中，是真有诸佛菩萨住在其中。真实亲见、净修显现、梦中观见诸佛菩萨三种中，没有获得任何一种现见的原因，这是有情自己的业力不能容受，无法可设。你二人(指他的二大弟子——却季绛称及洛卓绛称)哪怕是没有广大的修学和见闻，但应对常闻的诸法要，思惟观察。在浊世中寻求上师，具足德相的大乘善知识是寥若晨星，因此，不可不择而随便听法。对于这些佛像、佛经、佛塔，供养不感困难时，我是作月供、年供的，你们可以随我这样的作风来供。你二人直到未死之前，不必离开此间，在这期中事务不多，应一心观修，要做到受生不为天觉，死去不为鬼知。’”

继后，此师在卯年内，将示寂的预兆是天雨诸花，特别是在五月二十五日，天雨花，能遮蔽日光，降满全寺，当天晚上扎寺、岗寺也都普降雨花。到十七的那天，此师问道：“住‘新瓦寺’的领经师叫什么名字？”答说：“叫勒敦洛扎(义为上座智吉祥)。”师说道：“可以唤他来给你们领经诵诸上师及诸佛菩萨完整无缺的祈祷文。”侍众答说：“今天上师体力不多，在师前共诵时，将大大消耗上师体力，可以明天去请那位领经师来，照师所嘱去做。”师复说道：“我想今天就办到这些事，因为明天将是忙乱的开始。”十八日的中午，此师还能走向日光处曝日，十九日天明时也就示寂，往生兜率说法内院。

意乐修行菩提道次第的人们，应当谨向大德绛伯嘉措，猛勇祈祷求加，并追踪这位大德的清净史迹，不让微细的世间八风来染污，当于寂静处，尽所有精力勤修整个圆满大乘道次第心要。最低限度也应当发心以绛伯嘉措行境为目的而作，努力种下其善习。
