# 四十五、大堪布南喀坚赞的历史

根据宗喀巴大师的《师承赞》颂文中说：

“运用菩提心，观众如己子，获得诸本尊，摄受常加持，

能作浊世众，殊胜善导师，虚空幢师前，我今诚祈祷。”

值得这样赞美的妥扎大堪布南喀坚赞(义为虚空幢)，于丙寅年(公元一三二六年，元晋宗泰定三年诞生)生于须普族姓中，父亲为教师南喀桑波(义为虚空贤)，母亲名仁清敬(义为宝庄严)。刚一生下即能诵梵语诸佛名号，示现是一如愿而来化身应世的大德征相。由于能忆前生之力，年方二岁即能仿效作供施垛玛诸供事。三岁时即能见很多诸佛本尊。七岁即在叔父大堪布嘉色桑波前受优婆塞戒。对俗家不生贪著，由猛利出离心的催动，在大堪布嘉色桑波前出家，受沙弥戒，并听受大悲观音诸法门。那时有一妇人以莲花碗盛乳糜美食来师前供养，而说颂词道：“生老病死相，闻亦生忧恼，难忍恶趣苦，请饮菩提露。”说颂后，即以莲碗所盛乳食供已，而向东方空中逝去，继此此师即闭关多修大悲观音法门。到十岁时，他即在叔父大堪布前，请求传受由内邬苏巴大师传出而由嘉裕瓦次第传来的菩提道次第，及大悲观音、不动金刚、四尊马头金刚、廿一尊度母等很多法门，获得很多殊胜征相。年满十三岁时，因有命障，昼夜勤修善法，傍晚则绕卓瓦寺佛塔，从他身中放出光明，住在远处的人们都说遥见有大光绕塔。到十五岁时学习毘奈耶；据说到十七岁时，曾一度作说法事业，但一心想念住旷野寂静处所专修善法。

到十九岁时到拉萨朝礼释迦佛像昼夜勤行绕佛，有一晚上，此师住在拉萨惹谟伽寺(文成公主所建的小昭寺)中，见寺铁门开后，有一身著黑绫凶狞可怖黑人来到他的面前说：“你本是事业金刚名具乐，现在你可以去到仁清岗寺，那里有一文殊菩萨化身大德，与此师值遇后，将能成就所愿。”据说那一黑人即是持钩刀明王。于是南喀坚赞来到了仁清岗寺，在扎喜嘉瓦(义为吉祥胜)大师前受具足戒，并听受菩提道次第修心发心法门，以及很多密法修规。那时，扎喜嘉瓦大师对他说：“你出家有年了，你自己修了哪一尊本尊、作了哪些修学？你将成为一个很好的学佛正法的人。”说后复给他很多悦意的事务做。继后，他去到日桑垛巴大师前，听受《律广释》，《噶玛侠达玛秘密教授》，《般若二万颂光明释》，《集学论》，《阿底峡尊者百法小集》，《日隐大师的度母二十一尊事业会供》等很多法门。继来到妥扎，并负责主要职位。此后到二十二岁的时候，来一白衣少年向他说：“你在过去生中，有异熟罪果，应修忏悔法来解除。”说后不久如虹消逝。遂随即修三十五佛忏悔法，许下每座七百拜的誓愿。有一晚上，他梦见来了年约八岁的幼年僧三十五人，口中说出这样的颂词——“沉沦苦海中，是此贪瞋念，多诸恶分别，若悟彼性空，即见无取舍，真实性法身。”说后也就向空而逝。由此他的修力增长，身心四大渐次收摄调柔，从而真实生起了菩提心和慈心，而且昼夜都能如常不断。

到二十五岁时，在卓瓦寺中，闭关六月，勤修祈祷文殊菩萨及不空羂索金刚。到二十五岁时，上师邓尾炯勒(义为乐生处)来到了喀曲地方的那时，他去到师前听受了很多要法。同时在他满二十五岁的那一年大堪布嘉色巴迎请门扎巴大师来转大法轮，于是他复在门扎巴座前，听受了金刚手五鹏灌顶等经教及修心八偈等很多要法。在他年满三十一岁时，大堪布嘉色巴示寂，他建造了鎏金大佛像，那时僧俗人等都启请他继续主持主寺，于是他来到卓瓦寺中主持法座。那时秘密主对他说道：“业金刚，汝应知，口头禅者难成佛，鸟无翅羽难飞翔，阳燄之水难解渴，海陆山中难存活。怙主慈尊有是教：复次大地与黄金，月火库藏如宝海。”说后复传授他发菩提心等二十二种教授。南喀坚赞大师到四十岁的时候，他向秘密主启请，而获得秘密主为他演说“犯三种律仪罪过及退失誓戒忏净秘密方便不可思议甚深教授”，此一法门到后来有文字刊行。到四十二岁时，秘密主对他说：“业金刚，汝应知，对上师还未修得十分的敬信，而说是已见本尊及心中生起通达，这是在撒谎。未从内心想念过死无常，而说是能有舍此世心；与及对业果未生决定信，而说不作诸恶；没有丝毫的利他心，而说是心中已生起了慈心和悲心；未通达世俗一切法无实有，而说是已通达空性等说法，都是谎言。”又说：“如果想做一个纯正的学法人，基本应以信为最要！”复启问道：“生信之因为何？”以此秘密主复对他说：“依止上师应视师如佛而生信；应念死无常而生信；应与具敬信者为友伴而生信；应思惟轮回过患而生信”等很多教授。

又有一次南喀坚赞大师和名为大婆罗门萨惹哈成就者相值遇，萨惹哈为他详细说了金刚身真实法藏。到了六十一岁的那年，秘密主为他说：“黎国有三处地区，平列分布著，中间的那一地区，有一大宫殿。”他启问是谁住在宫殿中？答说：“是尊者燃灯智住其中。”(阿底峡尊者)于是他很想能与尊者相见，虔诚祈祷而往黎国，果然见著尊者容颜洁白，身材魁梧。头戴红色法冠，安住殿中。他当即启请尊者慈悲摄受，尊者传授了他很多教授。他到了七十岁的那年，在甲噶地方作摧伏金刚灌顶法的黎明时间，得到本尊给他授记说：“有捧著薄伽梵弥勒怙主化身的大师所著论著的四人，将来到此间。”到第二日果有四人来到，而所捧的著述，为善知识洛桑扎巴(义为善慧名称，即宗喀巴大师名讳)所作的著述。大师说宗喀巴大师的经历他已经听说过，过去生中有师徒的因缘关系，所以很生欢喜。继此有一晚上，他在梦里清楚地听说善知识洛桑扎巴已迎请七佛来临的声音。他心中正想念和宗喀巴大师相见的时候，天空顿时现起五色云端，有年仅十二孺童妙相，顶髻突起的七佛来临。直到从梦里醒来，细观很长久的时间，七佛仍旧安住在云端，据说那时，正是他为精奇寺佛殿作开光法事的时候。又有一次有一白净容颜的女子对他说：“有一为弥勒所加持的有情，而与曼殊室利是无二无别，妙善天女也赐他以明智，在十五生中都有连系因缘的人将要来到此间。对他应无吝啬地传授法要，那时也应向他请求传法。”南喀坚赞大师说：“又有一次清楚地听得有说‘怙主弥勒将要来到’的声音。那时我估计是法王噶细巴(四论师)将来到嘉谟日泽寺(鬘山寺)的时候。在佛转法轮六月初四日，有来到卓瓦寺者，我前去欢迎时眼见来者是至尊曼殊室利菩萨；而受欢迎的宗喀巴大师他也眼见我是金刚手菩萨。据说在当天晚上，宗喀巴大师修了一座上师瑜伽法的当中，获得金刚手前来合入于宗喀巴大师身中。继后，在十五日的拂晓时候，耳中听到说：‘去到弥勒前请求传授《集学论》’的声音，于是在宗喀巴大师前请求讲说《集学论》。宗喀巴大师讲说《集学论》时说：‘我想这或许是诸佛本尊在作如是说吧！’就这样讲了《集学论》。在宗喀巴大师讲说的那时，眼见宗喀巴大师的顶上，有至尊弥勒安住其上，他的右肩上有白文殊，左肩上有妙音母，复有很多护法空行从而围绕，与及很多鬼神前来闻法。由此我对宗喀巴大师生起了不共的信仰，并听授了各别随求灌顶及发菩提心等法。我复尽量地传授一切法要给宗喀巴大师，并对宗喀巴大师的侍徒如喇嘛绛噶瓦等很优秀的众门人，也传授了很多经教。彼此诸师徒，都获得生起了敬信。由于这种力量，我也获得生起了一些功德。在我说法的时候，宗喀巴大师眼见我的头上，现有释迦牟尼，右有金刚手，左有白伞盖等尊安住。”

这样的大德妥扎大成就者南喀坚赞大师，获得由善知识种敦巴传衮巴瓦，由此再传内邬苏巴等诸师相承下来的菩提道次第；与及由善知识种敦巴传慬哦瓦，由此再传嘉裕瓦等诸师相承下来的菩提道次第两派法流汇合起来的教授，通过闻思修学，证得殊胜通达。复对具缘人士，作广大弘扬，至于说到有哪些获得他的传授，能主持师承宗风的人物，如他的本尊秘密主所示记别中说：“获信人数有十万，证得解脱五十人，真实成就八徒中，无与匹伦俗是慧贤。”这是说将出很多住持佛法人物，而此中能有广大事业，在西藏地区将无与匹伦的大德则是至尊法王宗喀巴大师。具足这般功德的妥扎大成就者南喀坚赞大师作了广大的弘法利生事业，圆满了他这一生应度化诸人后，在辛巳的那一年(公元一四○一年，明惠帝建文三年示寂)享寿已到七十六岁，示现了不可思议的诸象征而圆寂。师身荼毘后，发现数以万计自然显现佛像及舍利，师身所有舍利复作广大信众的供养福田。

因此，意乐菩提道次第修心的人们，应当对于称作上师金刚手，亦称大成就者业金刚，复称妥扎大堪布南喀坚赞勤行祈祷，并效法这位大师的史事与德风，而向上师本尊前勤行祈祷；并努力勤修所有摄佛陀一切密意而为一的教授——菩提道次第中三种士夫应有修学次第。
