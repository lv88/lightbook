# 五十六、前辈近侍师绛央却迫的历史

“文殊法增智慧王。”

值得这样赞叹的前辈近侍师绛央却迫(义为文殊法增)，降生在“舍”地区。由于过去长久薰修佛道的习气，他从幼年就对烦嚣的俗家不生贪恋，身入佛门而出家。他去到扎什伦布大寺，依止前辈班禅洛桑却季绛称的座前，最初学习《释量论》获得无等智慧。以此未经很长的时间，他对于七部经论等要义，已获无畏辩才。继后次第学习《现观庄严论》、《中观》、《毗奈耶》、《俱舍》等论；彻底精通，成为善巧后，游辩场于广大僧海众中，立宗辩论上述诸大论义。此后，复从班禅洛桑却季绛称得意弟子仲巴师徒，以及金刚持根却绛称(义为宝幢)等许多善巧成就大德座前，听受有关四部密续的灌顶、经教等许多教授要诀；特别是听受了阿底峡尊者及法王宗喀巴两师之心要，精华教授，即一切经论之要义《菩提道次第》甚深导释，温萨耳传教授口诀等，听后薰修，获得悟达。从此成为具足教证大德藏。

他奉班禅洛桑耶喜的命令主持妥桑岭(闻思洲)寺，为数以千计的三藏法师广说大车轨诸经论。复登密宗殿法座，为数以千计的三藏法师讲说一切密续之王《密集》，依六边四理来解说，真是善巧之极。又依四家注讲说《胜乐》密续经、论，以及《时轮》密续经、论等，而大弘金刚乘教义。在这些说法的时期中，间或为许多具缘人士，传授《菩提道次第》导释等显密无量法要，作出广大之弘法事业。最后，也就在任密宗殿法座期间示现圆寂。在示寂时，长久住于定中，肉身转变为光明性体，光渐缩小而逝。从定中起时，肉身收缩成仅一箭之高。荼毗时，发现灵骨自然现出圣救度母像等十分稀有的许多异相。

意乐修学菩提道次第的人们，应谨向这位大德祈祷求加，并效法他彻底地研习显密经论，显现一切经论皆教授而努力薰修。由此调柔自心后，对其他具缘诸有情，复作饶益。
