# 四十一、善知识桑杰温敦的历史

根据宗喀巴大师所著的师承赞颂文中所说：“拥有功德藏，桑杰温敦师。”

值得这般赞颂的善知识桑杰温敦仁波切，他从无量劫以前精修大乘要道，获得不退的定解。由于对于浊世苦恼众生，特别生起大悲利济之心，而入世降生在婆罗门杰。拉朗种姓中，父亲名云达布谟达，母亲名侠谟垛。他的母亲在寝寐酣熟不觉中生下他来。当晚他的父亲在梦中见有一很大红日轮出现，普照南赡部洲。因此说：“我这一孩子将成为一个具有大福德的人。”继后他的叔父即善知识杰贡巴大师吩咐说：“云达的这一孩子，须得出家为僧，如果住在家中深为可惜，还是到我的跟前来吧！”桑杰温敦童年时期，他在戏玩的地方踏在一块磐石上，留下他的一双足印来。继后他就去到仁清岗寺叔父杰贡巴大师的座前，善知识杰贡巴大师对自己的侍众们说：“云达的这孩子是一个稀有的人物，你们对他不能轻视，应敬重。”说而心中是对桑杰温敦十分关怀！复对桑杰温敦说：“这是你的父亲对我有大恩，作了很大的仁慈厚爱。”桑杰温敦到了十七岁的时候，善知识本塘巴为作亲教师，阿阇黎德乌贡为作阿阇黎而出家为僧，命名须鲁炯勒(义为童生源处)。本塘巴说：“我对这一出家僧是有厚望的，我认为他将来决定是一位福德增盛的人物，因昨晚，梦著在一如意摩尼宝上做了拭擦。”阿阇黎德乌贡也说：“我梦著日月同时出现。”

桑杰温敦他心行两方面都如理地依止在善知识杰贡巴座前，听受了《菩提道次第修学捷径导释》，算来他在受沙弥的时期中，已将菩提道次第教授导释，及阿底峡尊者修学诸论都尽量学完。他到年满二十的时候，善知识杰贡巴对他说：“你须得作一比丘僧。”于是请求善知识梁杰作亲教师，请格西却作羯磨师(法师)，及格西喀清作教授师而受具足戒，依法学习毘奈耶诸学处，依止在亲教师前为时三年，听受关于戒行诸事使得完全领会于心中。又在本塘巴师前听受毘奈耶学处。继后复在善知识噶哇达生(盛狮子)座前，三年中尽学所有毘奈耶诸学处。以此他成为一位精通毘奈耶的大师，于是登法座而对众及具足善缘的人士，广讲《沙弥学处》及《律经》根本颂。继后，由于善知识杰贡巴年事渐高，桑杰温敦遂来到寺中择一静室一心专修，而以如教修行使上师生欢喜为主。有一次他请求杰贡巴多赐关照，杰贡巴说：“我是常时关照安置在身边的这些人。”善知识结季说：“这话是善知识对于自己的亲属方面，表示不作过分的爱执。”桑杰温敦说：“后藏的僧伽大众在善知识杰贡巴前说情，请师命我讲说毘奈耶。杰贡巴大师说：‘如果卑劣弟子对于教诫还有一污点生起，将不能说法，如果没有一污点生起，是可以讲说毘奈耶的。这样做，他自己也真成为善巧者，我想这即是对他慈爱而关怀！’”这一段话，是说应如噶当派前辈诸师的史事那样，自己以身作则，最初于寂静处，调柔自心，使自己真实获得不退转已，然后始作利他事业，而对其他有情说法。

继后，桑杰温敦心想大德杰贡巴年事已高，为上师作仆役诸事，即是使自己圆满资粮的最胜方便，于是他住在上师住室中，作室内的仆役诸事。他说从此启白上师而得到上师的教诫，比启白上师开示法要还多。这一胜士化身而来的大德桑杰温敦大师，他不仅是具有前生修持力量的人士，就以他的此生来说，也是常依善知识，使师欢喜，以菩提道次第作为主要的修行，而获菩提道次第所有诸通达的一位大德。他精修菩提道次第下士道及中士道，而生起了真实出离心；他对于戒律诸学处，精严谨守，虽细微过失，亦不令有所染污，确是一位实修有成的士夫。对于依止善知识法门，他已修得彻底的证悟，以此他常时都是视师如佛，他曾经这样说：“没有把善知识杰贡巴大师放置一旁，而能有其他本尊诸佛。”由于他生起了上师即佛的真实信解，他获得师身的加持力，而亲见无数本尊诸佛。据说是当他于仁清岗寺中请求发菩提心法门的那一拂晓时间中，于如一圆镜大小光中，现起一百一十二位上师，依此诸师修行获得所有菩萨学处圆满通达。与及在昌窝请求灌顶时，他是观著杰贡巴大师上身内面，现起密集十九尊佛，而杰贡巴上师即十九尊中的主尊佛，为他圆满授与四种灌顶，由此他心中生起了第四灌顶胜义的通达。

有一晚上桑杰温敦他梦见阿阇黎那哇巴来到他的面前给他说了很多密乘教旨，他将所梦情况禀告善知识杰贡巴，杰贡巴大师心生欢悦。桑杰温敦依止善知识杰贡巴十八年中，勤奋学法，而以修行为供养，令上师心生欢喜。善知识杰贡巴圆寂后，桑杰温敦他见著有无数诸佛菩萨对杰贡巴大师的躯体在作供养。杰贡巴大师逝世时他心中悲伤，感得杰贡巴大师亲自现身而来对他说：“勿悲伤！常时忆念于我吧！”以此他的悲伤得以解除。桑杰温敦他曾经这样说：“我何时发动愿望，即能与善知识杰贡巴相见，而求得一切经教。”有一次他念想到自己能否长寿不可决定，不如将主寺事务托付与格西妥瓦，自己建一山庄茅蓬来修行时，梦见善知识杰贡巴引著一位白色人来对他说：“此间不可另觅他人，可求一长寿之法。”第二天他做了一次诚恳的祈祷，梦得善知识杰贡巴前来对他说：“大悲观音加持汝长寿。”据桑杰温敦说：“当供奉杰贡巴大师的灵骨殿堂开光时，发现一切佛菩萨心中放出白亮的光明来。又为嘉萨殿修开光加行法时，得见阿阇黎罗迦菩提。罗迦菩提是我的一位根本上师，我向他祈祷后，从未一次不获见面。”他又说，当他在仁清岗驻锡时，夜梦在森林空隙中有一岩穴，他去到那岩穴中时，见著那若巴大师手持盛满甘露的颅器，对他说：“汝欲饮此否？”他当即礼请赐与，于是获得赐给甘露，并对他灌顶加持。

桑杰温敦大师住在岗区时，一次进入一山中，阿阇黎让谟瓦随后来时，见桑杰温敦坐在一块岩谷上，桑杰温敦问让谟瓦道：“有瑜伽行者夫妇二人从这里下去，你遇见了吗？”让谟瓦回答说：“未曾遇见。”桑杰温敦说道：“那两人不是凡俗者。”让谟瓦复问道：“是怎样的人？”桑杰温敦说：“那瑜伽者身穿布裤，那瑜伽母提著一个陶器。对我说：‘从无自性空中，观修收摄风脉，确是对证悟空乐增益之法。’”当他在乍烘(青岩)闭关专修时，他看见龙树师徒来到，正谈论著依他种有情，仍对彼不失比丘想的问题。又桑杰温敦来到热振寺的时候，他方动念想在寺中阅读阿底峡尊者诸遗著，也就在梦中，见得阿底峡尊者来到他的面前，向他说此书是如此如此说的，而将所有著作都完全指示给他。又据说他在甘丹寺中时，得见怙主弥勒，并且听受法要。又当让谟寺奠基时，他亲见大菩提主侍三尊。此外复亲见不动怙主、救度母、阎曼德迦、马头金刚诸尊。那时让谟寺中，他亲见吉祥天女主侍三尊后，在静室的岩上，即自然现出如他所见那样的吉祥天女主侍三尊像。又让谟寺中，有一清晨，度母、妙音佛母、古鲁古里佛母三尊共同对桑杰温敦大师作恭敬供养；由古鲁古里唱言后，继由妙音佛母拍掌以和，复由度母继作补充。又桑杰温敦他在梦中，见得亨扎菩提王足前，生长出白菖蒲两株，他当即取一株以食时，生起了从未尝过的妙味。遂启问此草为何？得答复说：“此为甘露，食之能得悉地。”因此他复想念，既是这样，还有一株未能食得，不如以此一株布施众生，遂留下一株菖蒲。又据说这位大师在童年时代，即已亲见持钩刀明王等很多护法。

由于他对上师已真实生起视师如佛的心，以此获得上师语加持，而获得一切经藏及诸论藏无碍辩才。有一晚上，他梦见善知识杰贡巴来到他的面前对他说：“温敦巴，你登上这个法座说法。”于是依指示上座宣讲，会场一片赞叹声。据说俨然如善知识杰贡巴在上面谈笑自若，承许说法的情况。继后，桑杰温敦在业寺中，将开始说法时，他发现自己的脐眼中，出现一轮大红日，普照赡洲众生身心，使众生获得温暖之相，以此他念想对众生或许有益，于是才为众说法的。在业寺中为僧众说法时，他对于有一偈句难通其义发生滞碍。心念此一法座将难美满而生过失，于是停讲下座，来到自住静室中。得见密集曼陀罗主尊即上师杰贡巴，笑颜逐开地对他说：“说法的事业，也是不易的，可向我祈祷而能获得解决。”从此哪怕有数以百计的三藏法师围绕著他，他也没有丝毫畏难之苦，而对于所说法要，都是精辟通达。他曾经这样说：“上从密集而至迦里迦以上，尽我胸中所知，无一遗留，我现在都如此这般演说出来，不管声闻地也好、辟支佛地也好，我想说来没有一点堕入常断二边过失中，都是本著完全而无颠倒的无上菩提道而说的。”这位大师由于获得上师的意加持，总的说来，他证得很多三摩地门，特别是他心中生起了如幻三摩地。并且生起了清净增上心，由此进而推执著于爱己之心，为如幻解脱清净爱他之心，是以此来作利济众生的事业。他自己也曾经这样说：“三摩地中如幻现，大悲心中自他换，有情众中自生佛。”对于胜观修观法门来说，这位大师是已经修悟，心中通达了远离常断二边的大中观见。有一晚上，他梦见来到一处空寂的旧屋中，有一人对他说：“这是圣者龙树的遗产，赠给你吧！”由此他心念：自己是否已通达如龙树所有正见，自己是否已通达二谛的密意。应当是于缘起中显现空性，而能无余了知一切因果所知境界。他自己曾经这样说：“唯佛能无余通达一切因果境界，我亦能了知一切因果的大概，如于镜中观物，纤毫毕露，而无任何前后不同、颠倒矛盾之弊。”

又这位大师修学菩萨行获得定解，对于一切众生有如母爱其独子之心。特别是他对王者堕入下流，或造罪积恶的众生，尤其慈悲。在仁清岗寺中，有一作恶多端的江脱青年僧名朗萨峨热，大师说对这一造罪积恶者赐以财食，而不生悔意。由于这位大师具有极稳固的定力，以此获得诸神通，当杰惹贡协与他作伴来到自己的住室门前时，忘带门钥匙，贡协去取得门钥转来时，桑杰温敦师早已进入屋中安住著。又侍者达玛峨正取一梯来安置去到屋顶平台曝沐日光的时候，见著桑杰温敦大师从空顿时降到屋顶平台上，一见有人，忙对他说：“啊呀！我作了这样的放逸行为，切勿向外人道。”另外，去山上回来时，温敦大师稍留一阵，诸侍从也就先回来，到达寺院，大师却已在静室里，摇著铃念经，加益还曾看过大师，虽没梯子，却如登梯子般，由天窗飘然而上屋顶。温敦大师他是具有诸如此类大地山石皆能通行无阻的神通的。

至于有关于他获得天耳通的事实，他自己曾经这样说：“当我注意听的时候，所有赡洲中，大而龙吟，小而虱蚁之声，都清晰可闻。”此外关于获得他心通这方面，可以说他对于他人的起心动念，是常时洞悉，无不了知的。当他在嘉萨驻锡时，有一晚上他说：“现在仁清岗寺中妥巴的三大修行者正在打量我，而且很不高兴。”后来妥巴三修行者听得这话，心生惊惧而到他处去了。关于获得天眼通这方面的事实，温敦大师自己曾经这样说：“我入定细观，所有赡洲一切形色诸物如在座前，无一不见。”修行者爵色巴问温敦大师道：“这时大师所观察的是何种情况，能否告我？”答道：“我正起一念头想一观察从此到东方世界而入于定中，依清明的三摩地，如镜中照物，有形毕现，我皆见得。”关于此师获得宿命通的事实，总说他能记忆前生是从仙居而来到此间受生的，以及后世将生为转轮王。详细如颂中说：“前生我从仙居来，受生藏中得人身，出家为僧在佛门，精习律藏有三载，十八依止如佛师，未来将作转轮王。”有人问桑杰温敦大师说：“传说大师为嘉裕瓦大师再来此世间，不知确否？”他答说：“我有很多嘉裕瓦的作风习气，揣想前生许是这位善知识。”当修建杰贡巴大师的骨塔时，温敦大师说：“我发现很多次将生为转轮王的征相，这一成果的主因，完全是这一骨塔而来的。”有人问他道：“所见为何种轮宝？”他答说：“我所见的，有金轮王、具七政宝、七近宝。”由于获得上师的加持，因此他如愿完成了修造善知识杰贡巴大师内外两骨塔等伟大事业。当温敦大师在曲村示寂时，切喀瓦大师对他请求说：“我已发现你为利有情的特殊象征，我请求保重。”当温敦大师在仁清岗寺驻锡的时候，准提天女来到他的跟前启请道：“金刚萨埵，愿为众生永住此土。”

他得到达波、拉萨等藏南一带送来的经函有二千零四十二部之多，并且得到大量的财物，他依靠这些经函和财物而创建新寺。当修建此边新寺的时候，他虔诚地祈祷，以此获得一梦，他梦见在西边有一座上，坐著慬哦瓦大师，右边有贡波护法，左边有吉祥天女，还有其他一切护法在那里聚会，并且说应当照此而做，对他说了很多教导的话。继此，他在壬寅年四月十三，土曜当头奠好了寺基，计在一年之内修竣十二大柱的中间主殿，六十四柱的大经堂，两柱间大小的护法殿。当建寺的时候，长官达玛多杰从林区下面准备运送木材的时候，温敦大师修了一次大供养施食法，他亲见吉祥天女骑驴来到，所有侍眷空行女从而围绕，以此温敦大师是具极广大事业而获得成就的。在嘉萨寺中修开光法事时，人人都说：“如此年轻，开光行吗？”说道：“修行了一辈子的人与我所诵密咒相比，亦难预料谁多。”有一次梦到中千世界的很多有情，上山没有伴侣，于是说道：“我去帮助他们上山。”且发了希望他们不退转的大愿。又温敦大师驻锡季学的时候，梦见好像是在嘉裕的山头，吹起白螺，南赡部洲都闻得此螺声。想看来名声将遍于南洲，使人得闻。他又说：“当在‘季学寺’中，患病的时候，公札夏明王来到我跟前凶恶地说道：‘我要仁清岗寺温敦的命。’我当即缘念一种三摩地所缘系缚之，使不得动弹。”明王说道：“这下我愿为你服役，但乞给我一供食。”我于是令此明王许下誓愿而妥善安置。传说他从曼陀罗山顶也就对“香蔡寺”中的德焰大像作了驱魔法及开光法事。

此外，温敦大师还增修了热振和嘉裕寺，并对僧伽大众广作供施。由于他作了这些修行道中种种完善清净事业，以此获得不退转征相。有一次贡楚启问他道：“阿阇黎应是妙吉祥根本续中一位授有记别者。”他说道：“过去我住在学习戒律学院的时候，阿阇黎噶哇达生对我说：‘以你有这眉间白毫相情形来说，你决定是经典中有所记别的一人。’”转问阿阇黎何处得有此说？阿阇黎说：“以现今时间性来说，是应有记别的时候，我辈也不过是做一下佛所欢喜的事业。”复启问道：“那么，获得授记者，有何种为量否？”阿阇黎说：“登地后是应获授记的。”有一次阿阇黎让谟瓦来到温敦大师那里，温敦大师对他说：“今晨我发现一切佛的心中放出无量光明，照射到至尊八臂度母身中，八臂度母的心中复放出无量光明而照射到我的身上，我的全身被光明笼罩。”让谟瓦将这种情况请问于喀什米尔班智达，班智达回答说：“这是得一切佛光的灌顶，为获得十地之相。”阿阇黎让谟瓦对温敦大师转达了上师班智达所说的话后，温敦大师说：“我想我仅是获得见道位，但是以所有征相来印证，又是属于圆满了修道位的一类。”

有一次温敦大师在须默驻锡时，贡楚问他道：“请问阿阇黎，你的手心和足掌上都有八辐轮纹，而仅是未与边沿连起来，这是怎样的一回事！”温敦大师说：“这辐轮纹如果是清晰圆满，那即是佛陀具有的相好。转轮王和登地菩萨二者，也有如此那样的辐轮纹，而只是微欠清晰圆满而已。”温敦大师眉间白毫，用手拉伸约长四指，放手则向右旋卷。足心复有八吉祥纹，手上复有三十字母纹。这些异相，为众目所共睹。有一次温敦大师身体有病，让谟瓦在榻前看护的时候，随便问温敦大师道：“阿阇黎曾亲见若干本尊诸佛？阿阇黎主要的主尊观修是哪一种？”回答说：“我意乐观察时，刹那刹那见著有如微尘数诸佛菩萨。如果以我们承传的教诫宗规来说，不是以亲见本尊获得神通为主要的观修，而是以发起菩提心、如幻双运为主要的观修。”从喀什米尔班智达的传中，可以知道桑杰温敦大师是一位证得不退转的菩萨而获得授记者。楞伽岛(或说即锡兰)有一阿罗汉放置四朵香花在盒中，而持以对喀什米尔班智达的兄弟说道：“我看你的兄长将到西藏去，你将这花交给他带去。以一朵请他转交枳地区，有一位系阿阇黎龙树转生的菩萨名仁清伯(宝吉祥)的那人；以一朵请转交惹那格枳寺中，有一位系具缘车菩萨转生而来的。以一朵请转交给底○根；以一朵请转供而放置在底嚩根所建造的大佛像的心中。”后来喀什米尔班智达照所请托的那样一一转交清楚。当桑杰温敦大师在桑耶寺转法轮的时候，喀什米尔班智达说：“我听到说今天应当谒见贤劫千佛中的唯一具缘车佛，会迅速发起修善法座的声音。”随即有人来通知去见仁清岗大师啊！

众生怙主桑杰温敦大师，在他享寿七十五岁的过程中，总的说来，他很好地护持佛陀的教法，作了藏北噶当派中的教主，完成善知识种敦巴未竟的旨意。他做出很多不可思议的事业来满足众生的愿望。他对浊世有情虽没有厌离之心，但是他想念以最后事业利济有情，并为利济他方世界有情的伟大意义，所以在马年年初就多次讲说生起厌离心的教法；并说阿阇黎那嘎菩提是这样说、大善知识是这样说，现在须得去到他方另一世界。他在修夏期内有一次这样说道：“我原想也如大善知识那样高龄住此世间，现在看来，我的寿数似乎已恰如其量。如我者即使不住此世，对藏北的佛教来说，也不过如山间云雾顿消，有情见此情景除略生惊异外，尚无其他大害。”

继于庚午年十一月初二日晚间，协饶旺秋来到温敦大师的座前，温敦大师问他道：“你打算在什么时候办节会？”回答说：“打算在十三那天办。”大师说：“我们似乎还能再见，那就尽力在初四供斋吧！”到了初三的晚间，温敦大师他来到自己住室中说道：“我年廿五岁开始讲说毘奈耶，年三十三岁时主持大寺法座，年届三十有四时，善知识杰贡巴大师示现圆寂，到三十五岁时从做讲说噶当教法的导师。直到今日，可以说我是尽力忍苦耐劳，尽量饶益有情。算来是我已满足了善知识杰贡巴所有未竟的旨意，现在渴望住一山岩野窟或寂静处所。大善知识杰贡巴示寂时未现任何病象，他是无疾而终，临到于我也是不会示现有诸病象征的，而且以往我都是宽心乐望能得那般最善的象征到来。我的教授承传是有大加持的，你们应当常念我与大善知识杰贡巴。”

这样的遗嘱情况说后，继于初四日，温敦大师仍以仁清岗寺的善法根本为念，而开示了很多如焰尽火灭等无常法语。到了夕阳将下时，温敦大师复去到嘉玛，仍照常修供施食后，正是初四的黄昏时分，他结跏趺坐，安然示寂。阿阇黎敦巴当即在师前作祈祷，师身较前更发光彩，庄严倍增。从此过了四天作了广大供养。在示寂后第五天便集合僧众得睹遗容。第六天作净治遗体诸事。在第七天晚间，迎奉大师遗体到大供养殿鼓堂中，使一切具信人士，广作发愿和供养。总的说来，桑杰温敦大师门下，出有很多不可思议的受法弟子，能弘扬菩提道次第修学教授的主持教法大德，亦复不少。而能大弘噶当教授传派三士道次第的主要弟子，则为妥扎大堪布朗喀嘉补(虚空王)，大堪布朗喀嘉补传大堪布生根桑波(师子贤)，生根桑波传嘉色桑波(佛子贤)，嘉色桑波传大成就者妥扎。南喀坚赞(虚空幢系宗喀巴大师的上师)。

因此，意乐菩提道次第修心的人们，应当对于菩萨化身而来的大德桑杰温敦大师勤行祈祷求加持，并效法这位大师的史事，对于从依止善知识起直至止观双运的三士道次第，结合身语意勤修此心，而速得成就。
