# 四十四、大堪布嘉色桑波的历史

根据宗喀巴大师的《师承赞》颂文中说：“赞美大堪布，名称佛子贤。”

值得这样赞美的大堪布嘉色桑波(义为佛子贤)。生于“须普”族姓中，生时有稀有瑞相。此师厌离俗家喧嚣，为出离心所策动，年方十一岁，即在大堪布生根桑波(师子贤)座前出家。他亲近持律师措那巴及善知识门扎巴等很多大德，他对四大论者，作了彻底的研究。到了十五岁时也就能讲说毘奈耶，并在大堪布生根桑波前听受《菩提道次第修学导释》，及道次第的教授《入行论》等噶当派传承诸法典。复听受大悲观音诸法门，他对于共与不共两种道次第诸法门均修得通达。他到卓瓦大寺主持法座后，建造了很多佛像、佛经、佛塔等，并迎请门扎巴大师和僧众，建立了转正法轮之规。他对妥扎大成就者南喀坚赞等很多具缘人士，广传菩提道次第修学指导及噶当派诸法门。继后，他将所有政教事业都很好地交付给妥扎大成就者南喀坚赞(义为虚空幢)后，随即示现了不可思议的稀有象征而圆寂。为使噶当教法久住妥扎地区的这一缘起，特别奉安此师肉身在卓瓦寺的塔中供养。

因此，意乐菩提道次第修心的人们，应当对大堪布嘉色桑波勤行祈祷求加持，并效法此师的史事与德风，而如理依止开示无倒修行道次的善知识，勤修菩提道次第。
