# 附十一、库敦。准珠雍仲略传

库敦。准珠雍仲(义为精进坚固)是尊者在前藏的主要弟子——库、峨、种三师中的一位。库师于辛亥年诞生在雅鲁地区，名准珠雍仲。他和拏错译师是同年生。他与峨。勒比协饶(义为善智)及邦敦师三人，一同来到康区，在觉窝生准座前，听受了许多教法，复在迦弥。云敦雍仲(义为功德坚固)座前，学习《现对法藏》成为善巧。曾作鲁梅诸寺的上座。那时没有比他再大的人物。种敦巴尊者致前藏诸大人物的书信中，没有列入库师的名。以此库师他生了我慢，心想自我加入，而独自提前去迎接阿底峡尊者，以此将其他诸人也催动起来。夏绒师说：“不列入库师，成为有用。”实际上这也是种敦巴尊者心量如海的功德。这位库师依止阿底峡尊者很久时间，听受了许多教授。特别是对于尊者所授《波罗密多》教授及《大威德教授》等十分精通。他迎请尊者到诺波伽转法轮，在业塘讲《波罗密多》时，由库师召集了听法信众约有千人之多。后来，在乙卯年，他享寿六十五岁示现圆寂。
