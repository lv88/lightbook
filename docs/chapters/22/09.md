# 附九、伦觉巴·协饶多杰略传

伦觉巴·协饶多杰(义为智金刚)这位大德富有阿底峡尊者的许多教海，并且精通诸宗教诲，亲见六字大明的本尊(即观音)。他依止阿底峡尊者有三年的时间。有一次念诵嘛呢，从口中放出光明来。大伦觉巴说：“这位大修士无过快乐，拥有菩提心。”阿底峡尊者示寂后，他驻锡桑朴，专一精修。据说他与伦觉巴。恰赤却很友好，以此他常往来于桑朴和热振两地间，由于获得神足通，不必携带餐食。他是善知识慬哦大师的上师，以此称呼他叫阿阇黎贡清(义为大修行师)。在桑朴示寂，有一奉安他的骨身小土塔，现在仍存在桑朴的路西。前辈诸师对此骨塔赞美称作桑朴故雅(义为桑朴逝身)。
