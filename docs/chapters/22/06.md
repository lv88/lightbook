# 附六、善知识绒巴。迦格瓦略传

绒巴。迦格瓦这位善知识是居士身。曾经到芒裕去迎接阿底峡尊者。继到桑耶时，在尊者座前，听受了许多密法教授。后来，尊者驻锡业塘时，他同梁若的法师——索朗耶协一起来到业塘。继后，由种敦巴尊者迎请廓译师来尊者前，由善知识迦格瓦请求尊者传授，而听受了《欢喜金刚法门》，也才有阿阇黎辛底巴所著的《俱生瑜伽》，及阿底峡尊者所著的《座弥黑茹迦甘露光释论》，与及《胜乐金刚法门》的许多著述，及阿阇黎古古里巴及辛底巴所著《摩诃摩雅修法》等教法。总之，迦格瓦与廓译师获得尊者传授以密法所有教授；特别是这两师对密续圣传法门，十分练达，听受了鲁惠巴师传所有灌顶教授，及拉舍所著释论，九种法类等所有圆满次第全圆教授。自己依法精修，并对其他具缘信众广大弘传。
