# 附五、善知识裕氏三昆仲略传

裕氏三昆仲：即裕却旺、裕丈松、裕脱伯三昆仲，都是阿底峡尊者的亲传弟子。先是尊者到领措时，尊者说：“今天黎明，梦见空中现一白色“啥”字发出声音光明等，照射到这一尊古铜铸造十一面观音像上。像放出光明，普照西藏一切大地后，光明复照射到一位少年僧的身上，由此那少年僧显现幻身光明。”到了红日高升时，有一位十六岁的少年僧裕却旺来到尊者座前，供献黄绸一疋，请求尊者传授他《大悲观音的教授》。尊者心中大喜，立以那一尊古铜铸造十一面观音像赐他，并传授他《大悲观音全部法门》。后来，他迎请尊者到他自己的住处，在尊者前作承事服役三月之久。

在那时，尊者对法会大众，则讲《波罗密多》法门；不公开地对裕氏三昆仲，则秘传枳雅修法诸教授。由裕氏请求尊者传一护佑深法，尊者传以《六字大明》修法；复求说：此法恐有不逮，尊者复传以《不动金刚法》；迦敦巴请求尊者传一加持大的法门，尊者传授以《六字大明》及《十一面观音法》；廓译师请求尊者传一威力大的法门。尊者传以《能怖金刚法》，复请传一贴近的修法，尊者传以《救度母法门》。裕师向尊者求得《大悲观音和威法门》后，依之精修。仅六月即亲见本尊和息的观音；继复亲见威猛的观音本尊。据说《大悲观音法门》，无有能比裕师更为善巧精通的。后来，裕师复到前藏在尊者前，听受了许多要法；特别是得到尊者传授给他以《马头金刚夏那四续修法》，这一法门廓译师与藏王等请求也未得尊者允传。可是尊者对裕师说：“这是大悲本尊，因你的悲心大，以此传给你。”裕师对于尊者所传《大悲主侍三尊教授》宗风不断地广大弘扬。
