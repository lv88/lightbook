# 附七、善知识妥扎。恰赤却略传

妥札。恰赤却这位善知识诞生在妥扎地区。他在前往拉萨朝拜释迦迎佛时，顺便去到业塘和阿底峡尊者会面，而获得尊者传授他许多教授。依止尊者五年之久。他对《现对法藏》十分精通，亲见本尊观世音及救度母。并获证上界三摩地。在尊者的四大瑜伽弟子中，他是无与比伦的一位。尊者临示寂时，对他吩咐说：“你晚年常依种敦巴吧！”他依尊者所嘱为种敦巴尊者服役，而来到热振。

后来，为了建尊者的灵塔去采购白银，及运送尊者的一部份经书到印度，他亲自到了尼泊尔，派遣了许多人运送尊者的书籍和信件等到印度去，将采购的白银，装入挖空的圆木柱中。他在归途中，梦见救度母对他吩咐说：“有一十岁的婆罗门童子来卖布时，你将布买来供献于我。如能这样做，可以免灾厄。一切危险有我护佑！”第二天果然如梦所说，买得布来向救度母祈祷回向。到了伯谟伯汤时，来了很多匪徒，所有同伴都被抢光。恰赤却的银片放在一垃圾土坑中，以此匪徒们没有看见。而得复行取出。后来他回热振将这一段情节，向衮巴瓦细说时，衮巴瓦问他绿白两度母像现在哪里？他说：“当时未能想到这样做。”衮巴瓦对他说：“建造这两尊像吧！”于是也就在那布上绘画了白绿两度母的像，至今仍然存在热振寺中，善知识朗日塘巴说：“哪怕是年久像已模糊不清，可是为菩萨真实化身啊！”

继后，他暂时作嘉隆多岗为众熬茶的事务。他说道：“今天真是好比谚语所说，从悬岩跌下来那样，恐怕要坏事，请多多谅恕！”说而事先请众原谅！他向种敦巴尊者祈请道：“我的善知识！你富有尊者如瓶全倾的一切教授，不说出来仅这样无饶益，请你不断地宣说尊者所传的诸教授吧！”他对伦觉说：“伦觉巴！你在世人做法中是恶劣的，你将服侍尊者的事放下，跑到大浪翻天的大海背后去了。你在佛法行道中也是恶劣的，放下修尊者的教授，是在学习那‘坝穹敦巴’的《无我母修法》。”又说：“伦觉巴倒是对上下人等，所有命令，做得光明磊落的。现在我将圆满尊者的意旨，因此，从明天将请求闭关专修。以此伦觉巴我对上下人等是想闭关后，将与人众不见面，而跑到柏林深处去随遇而安地住下去。”

那时，伦觉巴·协饶多杰(义为智金刚，四位伦觉巴中之一)从桑朴来到热振，是想和恰赤却谈论教法，解决疑团而来的，可是来时伦觉巴。恰赤却不在。问到哪里去了？说是到柏树林那边去了。以此协饶多杰来到柏林，桑朴瓦。协饶多杰是比丘，而恰赤却是居士，以此他向桑朴瓦顶礼三下而说道：“我没有一点做人的决定！”说后也就走向柏林中去了。桑朴瓦说：“表面上没有比这更失意！更不决定的来过。然而骨子里他是对于世间分别，毅然决断而闭关。而且是依尊者那样的——舍世间心，而修慈心、悲心、菩提心等教授的。”

有一次恰赤却的家乡寄来了一小包散碎金粒时，恰赤却将小包解开，把散碎金粒倾在手心中，去到二柱殿中说道：“我欲求得解脱义，利养恭敬不必缚。”说后也就将散金粒撒向神像龛空隙中去了。他在一小院草坪上作绕行时，看见圆寂塔内面，只有尊者的一件旧衣，已没有其他供物了。衮巴瓦说道：“唉！最后热振寺成了这样啦！”他问道：“这样有何罪过呢？”衮巴瓦答说：“我建塑尊者的本尊像，伦觉巴写了许多经；种尊者示寂后，虽有恰赤却在，但是没有这样的做到。”恰赤却问道：“有何益呢？以此怕而不作。”霞惹瓦说：“不知道现在噶当宗风是怎样的？过去善知识种敦巴，及恰赤却、伦觉巴等诸师的作风，是远离乡境，视亲眷如已死完那样，而急迫地精修正法。”善知识卓隆巴说：“伦觉巴。恰赤却拥有能知寺院阿阇黎心行的他心通。尊者临示寂时，教诫他说：‘在不去凡俗分别中，修菩提心吧！不要离开种敦巴吧！’特别是他在例外开许的四年中，虽说未去凡俗分别，可是所得的除暂时的生活外，一无所求。依理依法地接待宾客时，侍者们厌烦地向他请求说：这样哪能办得到？他诃责道：单独地住起来，独立是不能圆满福德的啊！这即是信依善知识种敦巴。”就这样到了他断绝凡俗分别行动时，年届四十二岁，在热振示现圆寂，往生兜率说法内院。
