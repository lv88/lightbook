# 附八、大伦觉巴。绛秋仁清略传

大伦觉巴。绛秋仁清(义为菩提宝)是在乙卯年诞生于下康区。童贞出家，他听得阿底峡尊者来藏后的声誉，生起了意乐往谒的念头，以此前往走到领措与尊者相会。尊者知其往昔和自己的法缘及具足正法的修习。以此刚一见面之下，当即传授以誓句三立本尊的经教，及《生起想念十法教授》。他作了常时服役在尊者身边的侍者。三次前往印度对尊者的诸上师供礼物，及在金刚座作供养等事务。有一次他在梁波渡船上服侍尊者时，他问尊者当给若干船资？尊者作一手印示意，他立时领会，给糖五包。以此尊者喜悦说道：“我修成神足神通，绕赡洲三匝也寻不著像你这样的弟子。”尊者在业塘驻锡时，他心想这样不分昼夜春秋地不断为上师服役不能静修。生起了看来我的福报小的心时，尊者神通已知而向他说道：“以身语意三者为上师服役时，不必觅其他修行缘念法门。”由这一要义，大伦觉巴获得没有比这更高的悟达和最善的修行。他仅念诵《誓句三立》本尊法八千遍，立即获得亲见本尊。对于各种作业通达无余。亲见本尊誓句三立和文殊相谈。尊者示寂后，他遵照尊者的遗嘱依止在种敦巴尊者座前作服侍常驻热振寺。种敦巴尊者圆寂后，由他主持热振寺十三年之久。他继续修建了热振寺下廊等处过去未完的诸事业。并教育僧众，作出了极大的事业。由他所出的大弟子中，有大德堆隆巴及拉弥、雅绒、大德柳绒巴等人，以及噶当三昆仲也曾经在他的座前依止过，这位善知识是一位拥有无碍神通与神变的大德。有一次种敦巴尊者患病时，他运用神变，无阻碍地通过墙壁而来到种尊者前问病情，并且也是获得圆满次第，风息住入殊胜三摩地的一位瑜伽行者。于丁己年十月初八日，享寿六十三岁，发现稀有瑞相当中，而往生兜率。
