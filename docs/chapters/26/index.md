# 二十六、持律大师塔玛巴的历史

根据宗喀巴大师所著赞颂中的颂句说：“全持律藏师，当推塔玛巴。”

在这样赞词中所赞的持律大师塔玛巴，他系内邬大师的得意弟子。他在青年的时代，总对于生死轮回的一切法，就生起厌离；特别是观见著俗家是许多烦恼和罪行的生处，他也就摆脱俗家而出家。他特别如法依止大持律师侠弥。默朗楚称(义为愿律)，对于律部四教所有的一切句义，他都学习到善巧精通的程度。关于律中所说的根本和支分，粗重和轻细的一切制戒，他都按律实行，如法守护，以此持律大师的美名，为大众所称赞。他来到内邬大师的座前之后，心行两方面都如法地依止内邬大师，而听受了整个圆满的诸佛所趣唯一的大道——《菩提道次第修学导释》，随即精修而获得修验，于是他对具缘的其他人士，也广弘菩提道次第教义。当他住持堆隆塔玛寺的时候，他广弘律部的讲轨，由此因缘传出了他的族系中人——后一塔玛巴(称“后一”是与他有所分别)，伯清多须(义为大吉祥金刚銮)，及持律大师坝底。爵色(义为怙子)等许多持律的善巧精通人士。特别是胜士化身的(那时没有呼图克图的称号)桑结温(义为佛子)，也来塔玛巴座前亲近，向他学习律部达到善巧精通后，对难以数计的具缘人士，广弘戒学。由以上因缘，讲律、轨则的事业，获得很大的成功。因此，宗喀巴大师也作赞颂说：“全藏律藏师，当推塔玛巴。”这位持律师塔玛巴的真实名讳叫作迦瓦。达生(义为盛师子)。持律师塔玛巴所传出的《菩提道次第导修释义》，在妥扎地区得著广大的弘扬。初由妥扎，大堪布朗喀生根(义为虚空师子)来到持律师塔玛巴座前亲近听受了整个圆满的由衮巴瓦传来的《菩提道次第导释》，继后大堪布朗喀生根将所受的菩提道次第教法传给大堪布朗喀嘉补(义为虚空王)，复由朗喀嘉补传给大堪布生根桑波(义为师子贤)，由生根桑波再传给大堪布嘉色桑波(义为佛子贤)，再由嘉色桑波传给妥扎。大成就者南喀坚赞(义为虚空幢，系宗喀巴大师所依上师中之一)。妥扎。朗喀生根的史事，现在随即叙述。至于由大堪布朗喀嘉补传到妥扎。大成就者南喀坚赞之间的四位上师的史事，将在下面叙述由善知识慬哦瓦所传出的噶当教授派的各位上师史事的时候，那时再来叙述。

持律师塔玛巴的详细史记，还没有见著，因此，将来获得的时候，是应当补充在本著中的。由以上塔玛巴史事说来，我们对于菩提道次第意乐修心的所有人士，应当忆念持律师塔玛巴的功德而祈祷求加持，并且在修菩提道次第的时候，废弃所有制戒，依其他一种法门，徒劳无益地去寻觅那无根据的枝叶琐事，而说是在修心，这是不应当的。应当郑重地把戒学作为佛教的根本来建立起道之根本。
