# 六十六、克珠·洛桑嘉措大师的历史

赞颂中说：“现证三身洛布桑。”

值得这样赞叹的克珠·洛桑嘉措大师(善成宝贤海)，是降生在后藏达纳地区，父名朗喀伯桑(义为虚空吉祥贤)，母名却交绷(义为亿法护)，在寅年(壬寅公元一五四二年，明嘉靖二十一年)大师诞生的时候，发现稀有瑞相。大师在童年时期，由于赋有佛法的习气，对于所读的书本，感觉没有什么困难，就能知道；并能了达在家是发生很多过患的生源，总对于世间一切圆满受用，特别对俗家的喧染和受用，全不贪恋。他到了十三岁的时候，也就在乍玛却顶(红岩法寺)中，法王洛卓(智怙主)为作亲教师，却迫绛称(义为法增幢)为作轨范师的座前，出家受戒，他对在师前所受的戒，谨守不犯。他察觉到出家众应当作的闻思和修定二事中，先须广闻三藏，于是前往日库却顶(山洼寺)，亲近扎巴桑波(义为名称贤)师座，勤求多闻三藏教义而住在那里。据这位大师说：“他住在日库却顶的时候，由上师扎巴桑波及施主格江迦波等人迎请来法王协饶生根，及一切智根敦主、持律师洛卓伯巴等师，他在那里与诸师相见，得到诸师广讲三藏经论，及大车轨诸论释。那时，日库却顶寺中，聚会了大善巧有成诸大德，及其首要弟子，大菩萨等‘济济于一堂’，他们都是戒行清净，具舍此世心，广宣三藏教法的大德，真如佛在世时那样的盛况。”他复广游各大学法寺院，研习诸大经论，以此不久也就成为教理无碍的善巧师。他继复前往邓清(大乐寺)，及却柯岗(法轮寺)等处，对诸大经论，进求广大多闻，又在协饶仁清(义为智宝)等许多大德前，听受所有经教、灌顶、教授等。

他继即来到扎什伦布大寺，亲近一切智根敦主大师座前，听受三世诸佛所趣的大道，二大车轨的准绳，为阿底峡尊者及宗喀巴两位大师的心髓教授——《菩提道次第导释》后，结合自心专修，而生起悟达；并细研《般若》、《中观》、《毘奈耶》、《现对法类》，特别是《释量论》后，了知诸大经论都是修行教授。如一切智根敦主说：“须善闻所讲的一切经论，成为透达自他诸宗大海者。”他于是前往前藏遍游桑朴等处所有辩场，立宗辩论，以此他的善巧名声遍于大地之上。此师年满三十五岁时，前往甘丹大寺由法王洛卓却炯(义为智法护)为作亲教师，法王扎峨巴(义为名称光)为作轨范师，绒波。洛桑巴(义为贤慧)为作教授师，受具足戒。而成为入佛教中，获得全圆功德，代理佛陀的大师。他也就在法王洛卓却炯等许多善知识座前，听受一切智大师的论著传授等所有显密许多要法。

他年满三十七岁时，复前往峨喀静修地仁清岗(宝山寺)在法王却扎巴(义为法称)座前，听受不少的要法。就这样这位大师，已成为多闻显密教授藏海，他对此世利乐，毫不留恋，等同瑜伽自在王密勒日巴那样，依最艰苦的养命生活。住仁清岗、及唉得乌惹、峨喀、嘉索普、拉顶等为过去宗喀巴大师住下静修过的胜地，一直专修了四十年之久。在修因资粮具备的条件下，他勤奋专修三士道次第中的所有修法，获得彻底通达，对于密教五次第、及时轮六支等无上密道次第，也修来得到证达。以此他获得能忆知自他俱胝生中诸事，亲见许多本尊。通达陀罗尼门，无碍辩才，具神通诸功德。

成为说、辩、著述才德无碍大师后，在不断勤修四座瑜伽中，复为具缘无数大众，传授《菩提道次第直观教导》，及密宗所有灌顶、传经、教授等。师为了使教法常住起见，复著作有《时轮总义无垢光庄严论》、《白莲语教》、及阐明密集二次第要义的《五次第明显论》等不少的著述。主要为了受持宗喀巴大师修行法传，教导后世化机，应如是行起见。他如水流不断地勤修四座瑜伽，依宗喀巴大师教授，成就双运果位。这位大师在他圆满度生事业的时候，是在癸酉年(公元一六三三年，明崇祯六年)六月二十五日，享寿九十一岁，示现圆寂，往生兜率清净刹土，变现俱胝化身，广作度生事业。由这位大师教育而出传徒，是很多的，其中难以匹伦的，确为圆满教主一切智“根敦嘉措”(义为僧海，即达赖第二世)。

意乐修菩提道次第的人们，应当谨向克珠洛桑嘉措大师，虔诚祈祷求加持，并当效法他的清净行传，在严守之律，毫不染犯的基础上，生起舍此世心，于寂静处所，专修显密两种圆满道体。
