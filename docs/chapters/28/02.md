# 附二、善知识扎迦瓦略传

扎迦瓦是丙申年诞生的，他长期依止博多瓦，他对博多瓦的语录《喻法本论》作了释著。博多瓦圆寂后他也曾经亲近过颇章顶巴。他曾经对栋贡巴这样说：“对于一切六道众生，我愿有一时候，自己也成为如像在四方供垛玛那样，供品放置的地上，一切昆虫都来取食它。”他又说：“人是比较容易修炼的。”栋贡巴答说道：“我想非人是容易修炼，因为人有时听话会发生误解，非人有神通，不会发生误解。”扎迦瓦他在一所住室里，一直住过二十三年，一双皮的鞋底能用三年，一块酥油能够一月零十三天之用，每月所需的粮不过青稞五升。据说他对弟子们说：“我以身口两方面来说法，但是你们不懂得！”他从扎迦地方迁移到达哲的时候，随带的什物，仅只是八个陶瓦的钵罐等和净瓶一个。”他享寿八十岁，在那年十二月二十二日示寂。这位善知识他讲菩提道次第的时候，来会的僧伽约有三百多人。
