# 附三、善知识垛巴钦波略传

垛巴钦波他是己亥年生的，他的父亲是一位善知识，名勒比嘉措(义为善海)，持诵大乘密咒，有大智慧而秉性贤良的人。生育两个儿子，垛巴是他的长子，族姓是若杰氏，从生后直到五岁的这段时间，常有一道光环绕著他的全身。到五岁后即学习念书，直到十四岁，在善知识却季大师座前听受《俱舍》，从此直到十九岁之间，他在穹波。扎生(义为名称狮子)等师座前，听受中观及因明，继后他向父亲请求许他出家。父亲说他是持密者而没有允许他出家。他再三请求父亲允许他，父亲才对他说：“你如果出了家，我只有把继承持密的希望托在你兄弟的身上，而你的兄弟是不配称的。”

此后，他到了二十岁的那年，适当温地区兴办一种法会的期中，那时德高望重的人物陶、敦、协三师都聚会在这一法会中。他到那里也就在善知识协师座前请求为他作阿阇黎，上午得到给他传受沙弥戒，下午即传比丘戒，黄昏时分传发菩提心菩萨戒。协师带著诙谐的口吻说：“这真是须得要这样仔细而慎重地作了。”继后，他在持律嘉大师座前听受《毘奈耶》，三年的当中除处眠事分外，所有戒经本文全由内心背诵出来，而向当前弟子讲说。善知识嘉师曾经这样说：“我们作附座说法的诸人对于具信的人们轮流说法中，我讲大乘瑜伽时，具信的人们以此生起敬信而感动地落下泪来。但是我自己确未生起一次定解，到后来我入于善知识博多瓦的教雨法云中，我才感觉到过去我怎么那样的做啊！”垛巴钦波的父亲吩咐垛巴说：“有一位我的善友种敦巴座前的修学弟子，都成为我的善知识住在那里。你到他那里去吧！”于是他到了二十六岁时，来到了卓那寺中住的博多瓦的座前，由于茶叶一时缺乏，只好以樟脑末药十多盒，和格子条纹作得很好的法衣一件供师而请赐法要。博多瓦说道：“你走错了路呀！拉萨在闻说两方面都是如旭日升起般的兴盛地区，你不在那里住下，到我这里来，而我除随念死无常一法外，也就一无所有。这样你喜欢的话，在这里住四年，将这样法衣售出去，作饱肚的口粮吧！”说后也就将法衣仍旧还给他。于是在晚间，他随著法螺的声音而来到法会听讲，恰碰著讲到《宝鬘论》中‘示现国王品’中的颂文——“对尊虽不顺，尊为作现知，与及悲众故，祈除我执见。”他是从这颂文听讲的。他说这是他在僧会中听受说法最初的一次。这一经论讲完后，继讲《经庄严论》，当时从僧众会集听讲起，一直讲了三年。常住听讲的僧人约三十人，秘传法要时，只传授三人或四人不等。所以大师稍不悦意的时间，每对垛巴说：“你很好地作吧！不这样作，我心中是不安的，因为只不过传授三四人啊！”

继即到了安居坐夏的时候，博多瓦被请作为修夏中负责为施主祈福、超度回向之事，在这一坐夏期中，有关接受启问一切作业的修夏阿阇黎一职也请他来担任。他说：“好！说怎样的发愿回向，都会办得到的。”说后当即起座而行。心想如果不接受，而使师长不悦，是不妙的。由于种敦巴向他说：“你明晚到这里来一下吧！”以此他来到热振说：“种敦巴尊者命我当坐夏阿阇黎，而现在还没有具足坐夏阿阇黎德相的人，可以说热振松柏丛中，仅出现善知识种尊者一人是堪配德相的坐夏阿阇黎。除此其他谁当此任，都不到解制也就示寂了。薄伽梵曾经说过四念住这一法门，因此我们也应当是需要‘依止处’的。”对于博多瓦的这些话，垛巴钦波他说：“我对于善知识博多瓦所说的这些话，经常复述给他人听。我想他说的‘依止处’是指依止优婆塞种尊者而言，因为今后一切世中的希望现实都要依靠他而生起，以此他是决定能成为‘依处’的了。”慬哦大师也说：“利益我的阿阇黎，有优婆塞种老在。”善知识垛巴钦波说：“对于教法获得少许定解中，就感觉过去的那一切法门没有效用。在生起一点重后世的心时候，我不禁感叹道：唉！不必要再造作无义的讲说了。上师他连书本和笔记提纲等都赐人们了，他的书箧子空空地搁著。想到这些更使我生起知道须依善知识的重要。当我还没有遇著善知识的时候，我是大傻瓜，继后出家得遇我的这位善知识，由此我感觉所有安乐名声等一切都只有让‘我’增大了的。”他又说：“在博多瓦的座前受教了二十二年之久，就这样我根本没有感觉过所学的满足了，或这下可以了。”

善知识垛巴钦波他是夏冬两季在博多瓦的座前，春秋两季去到三昆仲中的仲师即慬哦瓦的那里，这样轮流地住下来修学的。在乙酉的那年，坐夏的那月三十日博多瓦示寂时，他那一夏是在那里住的。秋天一来他回来的时候，也就同自己侍众等约十人住在曲纳寺里，到得回来时，他复在康垄巴座前听受法要。此后本跋巴(义为官吏名圣者的)迎请他到季那贡寺，并将此处供养了他。

在戌年他住持亚格寺，据说两年中没有讲经，说法时分中，法座完全空白著。继后经徒眷等请求他说法，他开始讲了一次《寄弟子书》，继讲名著《兰吠琉璃集》时，他说为了利益自己的身心对所有因日久而荒废了的教义，更恐忘失，我才将它笔记下来的。我没有把它作为讲说的工具，如果要作讲说工具的话，只是每一夏冬所说的，记也将会记不完，我是想需要独居自修；以此只是随自喜悦的笔记下来的。他听得善知识颇章顶巴编集有一部《喻法集撰》，他说：“那么，我这些笔记如果也编集在一起的话，我想对其他者来说，是可以利益的。”他也就在亚格寺

女的尼僧对他说：“善知识：我得著一种恶梦，在梦里梦著说这是善知识的肠肝肚肺等内脏。又说现在可以见得著正在垛巴地方上把内脏分散开啦！”垛巴钦波说道：“内脏分散开来的危险虽是有的，可是也不必诵经修法来祈禳。”说后从那一冬起，他仍然讲《吠琉璃》，作了对无量众生有利益的事业。当善知识霞惹瓦手中接著这部《吠琉璃集》的时候，他说：“嗨！给我寄来了这部不广不略而合中量的论著。”说后表示敬意而站起身来一次。阿阇黎邓顶瓦说：“我也很想听受一次这部论著。”因此他在病中的时候，听著这一春季要讲的消息，他都带病去到“亚格”垛巴大师的那里。在他到的那晚上，他梦著自己到了金刚座(印度金刚座)。继即得到善知识垛巴说法的加持力，以此力量他的病也好了。因此他向善知识垛巴说道：“不料闻法中出现了治病的医生。”垛巴说：“如果独自坐修的话，这是合善知识密意的。”

此外这位善知识垛巴钦波是曾经阿底峡尊者授过记别的；并具足七生的特征；能如诸上师所说法要心生通达，亲见许多佛及本尊现身，具有广大神通等一位大德。当业塘的峨尔寺请他去开光的时候，堆隆巴的两位小兄弟很想求他传授发菩提心法，不止一次地生起这一动机，可是因为善知识垛巴座前常有很多的人来搅扰著，而没有得著请求的机会。垛巴大师神通妙用早已察知，不待他请而对他说：“你作欲受仪轨的准备吧！准备完后，来叫我一下吧！”又爵敦。阿里巴迎请了一尊合金古铜铸造的观音像来的时候，垛巴大师是根本连一些风声也没有听到的，当阿里巴走到垛巴大师的静室里去，刚一见面开始要向大师礼拜的时候，垛巴大师神通妙慧中早已知道而对他说：“你先去将佛像请来我看吧！”又当他到了让裕地方的时候，杰达贡巴说：“我在早晨观修中，生起了一次很好的观修。我正在想这是什么原因，而有这样的好现象的时候，我见垛巴大师来到这里，我才知道这是他的加持。”说后，他对垛巴大师作了很大的恭敬承事。据说后来只要垛巴大师复行来到那里的时候，他完全如过去一样——善妙的观修决定生起，以此他对大师生起了极大的虔诚信仰。又善知识门布穹瓦说：“善知识亚格巴(此系垛巴钦波的别名)今天将要到这里来，因为昨天我修法的时候，思想中生起了一种与法很相合的修验。”据说他说后也就去查看善知识垛巴师徒等一行人众是否到来。远远能望见垛巴师徒等已经到了门布穹地方的三岔路口时，他烧起了很多名香，而恭敬地祈祷求加持。

此外，据说是这位垛巴大师，只是会见著他，与及听他说法，或者思念他的人士，都能得到对治他的烦恼。当他到了南方的时候，有一位老头对他说道：“有一个与我父亲是兄妹行的人，我做什么，他都不让我做，我恨透了他，正想用药将他毒死的时候，昨天我一见著你的面，我那谋杀的心也就打消了。现在我请求你帮我授一斋戒和戒杀的戒吧！”垛巴大师对他说：“你为什么要谋杀他？我看来这是由于你过去生中对他常作残害的一种象征。”说后也就给他了一些食剩之物，并传授了他斋戒。又有一位女人说：“我有一很好的儿子，但被他人杀害，故而悲怒不止，昨天见到您怒气减轻，听人众说是遇到了七生菩萨，不知是否？我也请求受一斋戒。”垛巴大师答道：“妈妈，七生是不同平常的，我们应给他传一斋戒。”说后也就给她说了“消除丧子苦恼的教授和斋戒”。善知识垛巴真实的名讳叫协饶嘉措(义为智海)，复别称他叫亚格巴(主持亚格寺而得名)。这位善知识从二十六岁任僧伽宝众的领导人，而作出成熟无量的众生后，据说在十月末他到僧院中的时候，略生小病，继在冬月里，他说：“我将打算说一次大法，又顾虑人们有听不懂的过患。”到得他示现圆寂的时候，他说在这冬季里将想说一大法，人们会有不懂的，为了顾虑他人不懂，说《吠琉璃集》吧！或说《集菩萨学处》也可。善知识垛巴他的讲说是能令他人一听之下，就有心意转变的功能。他作出了很大的弘法利生的事业，享寿七十三岁，辛亥年冬十七清晨，在亚格寺中圆寂。

他领导亚格寺僧伽约一千多人中，大弟子有塔枳贡巴、邓顶瓦钦波、嘉切喀瓦等。伯拔谟住巴也在他的座前，听受过教法。

为大众所称扬为前藏的日、月二轮——即大善知识博多瓦的首要大弟子朗日塘巴，与霞惹瓦两位大德。霞惹瓦的历史将在下面另叙。这里先说朗日塘巴历史如下。
