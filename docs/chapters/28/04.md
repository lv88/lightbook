# 附四、善知识朗日塘巴略传

善知识朗日塘巴于甲午年诞生在彭裕地区，业贡村的色玛相地方，父亲名叫爵窝。达玛垛让，须昌是他的种姓。他在他的舅父——善知识卓谟。喀巴的座前出家，起名叫多杰生格(义为金刚狮子)。据说他是无量光佛的化身，在过去复转生为译师迦瓦。伯哲(义为吉祥聚)，而对教法作出了很大的阐扬。他在这生中，在此间一般庸俗人们的面前，最初示现的是他在极贫穷的境况下，过著困难的生活中来研习三藏教典，并对于能将三藏教典中所说的一切教义，都糅合在三士道次第中而修的教授——《菩提道次第》作一心专修。他在噶当三昆仲的座前，都亲近过。主要是在三昆仲中的博多瓦大师的座前，听受了所有噶当六论的一切讲义，与及特要法门即爱他人的心胜过爱自己的修菩提心教授——《修心七义论》的导修讲义，而作了彻底的修行。他在内邬苏巴座前，也听受过《菩提道次第导修译义》。善知识朗日塘巴在诺寺，慬哦大师的那里听法的时候，每藏一握炒熟的青稞在舖垫下而存起来。继此他凡是化缘所得的，不管什么东西，都拿来总对于僧众，特别是迎请博多瓦尊师等，作供养来培福德，他自己曾经供给过二千多僧众的口食，使皆得饱满。他的住处没有一定的地点。当慬哦诺寺的塔修建的时候，他带领著五百僧人，为建塔服务。他主要是以博多瓦的作风史事和语录，作为他的行持。当博多瓦示寂的时候对朗日塘巴吩咐说：“你不要住在一个地方，任何物质不要持为自己所有，这两件事你记在心上吧！”他在慬哦大师的座前说：“我整个一生，纯修慈心。”慬哦大师一听著这话当时，脱帽说道：“这才是阿底峡尊者门人修行的善妙方式呀！”说后连连点头表示敬意。有一次他立了坚定的誓言——愿一切生中不与比丘的事物相离。因此感得吉祥天女骑著神驴，驴声清晰地长鸣而来到他的面前说：“从今起直到你所发誓言的将来，我都愿作你的助伴。”

朗日塘巴曾经这样说：“不管怎样做，或是在做了一些护持戒律；或是做了少许思修；及一些福业的当中，甚至不管说怎样的一种甚深经卷等，一开口就是说——一切过失是自己的，一切功德是怙主有情的。这一关键，在于将一切利益和胜利都给与其他有情，一切亏损和失败都归自己取受的心，如果不是这样，他就还没有获得知解。”他又说：“生在六道有情中哪一处，是无定的。可是不管生在哪处，都要不忘对于一切有情作利益的心，哪怕是眼瞎了也不丢失这一法。耳聋了，瘫了，脚手跛残了，舌僵声哑了也都不丢失这一法。”这种意思表示了是他亲口坚许，意乐是“绝不退转”。在博多瓦圆寂后，他在塘村上区供施“垛玛水施”的时候，他的垛玛供盘，被乌鸦啣去放在塘村东山德乌那里，因此朗日塘巴觅踪来到那里，得著当地长官名叫释迦的为他服役帮助之下，他在那里净修了三年，净修处的下面，也发现了因修德而涌现的泉水。由于他昼夜不断勤修菩提心的三摩地，感得龙女三姊妹将朗塘处所供献给他，请求他修建僧院。后来他向山顶飞腾的时候，在掉下了他的念珠的地上掘井，在掉下了他的帽子的那里，作修导师住屋的地方，而建立了朗塘寺。他依照博多瓦的事业作风，以噶当六论及《道炬论》，弥勒诸大论等来培养门徒。

当朗日塘巴住在谟洛德乌山中的时候，嘉裕瓦也在他座前听受过毘奈耶根本经义。后来朗日塘巴成了内邬苏巴的再传弟子。内邬大师对他说：“你所有的这些功德和安乐，不是从其他方面而来的，而是从菩提心所生出的果。”真实完全是如内邬所说——他纯粹是以修自他相换菩提心为主要的。朗日塘巴自己曾经这样说：“我呼出的气息，也没有作过一次凡俗的呼出。我于任何时间中，我没有离开过依出入息修取舍的菩提心法。”据说朗日塘巴住世的当中，朗塘的围墙以内，所有鸟、蝇、昆虫等动物，绝不彼此互相残害。金刚座大德上师对穹波。瑜伽者说：“你去从无量光佛的化身——朗日塘巴座前受具足戒吧！”瑜伽者依照上师的记别，请求朗日塘巴作了他受具戒的阿阇黎。有一次当博多瓦住在隆学那闻的时候，朗日塘巴来到那里，他的身体发生病痛，不思饮食，以此他想：“总的六道有情是这样的痛苦，此中最殊胜的是人，而我又是人中的出家者。”他进而思惟业果及轮回过患，心中生起了厌离而思出离的心。可是想到“我这身体现在没有净治诸恶的功能”时，他也就来到博多瓦作绕行的路口上，以衣服舖设起坐垫来请求博多瓦在他舖设的垫上坐下。博多瓦说：“你干什么呢？我要作绕行。”而没有答应他的请求。他说：“有要紧的事向师请求指示，以此请上师在这里安坐一下。”善知识博多瓦当即在他舖设的垫上坐下了。他请求道：“我今夏发现我身体太坏，不思饮食。观修无常及轮回过患，生起了出离心。由于没有去恶修善的功能，诸根的识别也很不安舒。以此求师赐我一种教授法门。”博多瓦说：“阿底峡尊者身中诸大是寒热平均的安舒现象，这样对后世有利益吗？”说到这里同时引证了两位阿罗汉的故事，对他说出颂言道：“‘所谓苦功德，能以厌除骄，对众生悲心，耻恶而乐善。’这是你应作的去作吧！我还要绕行。”说后也就继续地走了。朗日塘巴受教后从那天晚上起感觉身体稍安，渐次也就痊愈了。

朗日塘巴他对积福是很喜欢作的，熬著的好糜粥总是邀请如师长等尊重的人来受用。有一次他连茶也没有了，只有一些微有辣味的干面包碎块，他也请博多瓦师徒等来受用，当博多瓦继即为他作回向的时候，天空顿然下起大雪来了，以此博多瓦对他说道：“黑脸修士(因他常修观轮回过患心，面容常带忧郁之色)，你从今天起，将要离脱贫困了。”善知识朗日塘巴他在拉萨作长时间的绕塔庙经行的时候，在夜间走到了住屋外面的一大丛野刺梅的那里，听著有痛苦的哼声。走去一看，见著有一青年妇女弯著身体在刺梅丛里。他将她解救出来，那妇人就暂时只好垫著衣襟而睡。他说：“妳对我当作你的父亲或儿子想吧！我对妳是当作你是我的母亲和姐妹想的。”说后也就坐在一旁。第二天他给了那妇人一件衣裳把她遣走了。后来那妇人成为他基本的施主，而在朗塘的东山德乌那里，为他修起静修精舍，他也就在那里静修。继此之后这位大善知识教化众生的时会也就来到了。比如建朗塘寺和结合噶当六论来广说菩提道次第等情况，已在前面说过了，他是以先调伏自心为主要的。有一次他在断了口食等受用的当中，有一过路的旅客，供养了他一簸箕好茶叶说：“把这茶叶熬来受用吧！”得这位供茶的施主转回来时，复去朝拜他的时候，见著茶满著灰尘仍放在那里，施主请问他这茶熬来喝过没有？他答道：“我也没有煎熬它，它也没有煎熬我。”他的近身侍者向他请求说：“人家对我们都在说：‘朗日塘巴一点笑容都没有，常时都是黑起脸不欢喜的样子。’我们请求上师对来朝拜你的人们，每谈一次话，都作一次欢容笑脸吧！”他答道：“我确也是那样的态度，可是如果思惟生死轮回的过患，能欢容笑脸吗？因此要知道我们确实是住在无可救治时的这一生死病中，和无可解脱时的这生死牢狱中啊！”据说他从出家起整个一生中，只发现过他三次笑容。

这样的善知识朗日塘巴他对精修善业是长久不断作的，对于大乘一切法要，也是一点不放松地精研。他游戏在一切陀罗尼门和三摩地等无量佛法中，并具足天眼及各种神通等一切功德，亲见诸佛现身，有如虚空中的星群。《入行论》中有颂说：“若不将自乐，正换他众苦，彼不获成佛，流转亦乏乐。”(言就在六道中，连暂时的乐受也得不著的意思。)这位大师他真如颂中说的那样，在气息呼吸中修自他相换法门，以此而得到任运成就的功能。他自己曾经说：“我的气息没有作过一次凡庸的呼吸。”有一次朗日塘巴在他正讲经的时候，有一妇人抱著一个刚生下的婴孩，给他送来说：“这婴孩是你的儿子，我不养育他了。”说后随即就走了。对于这一事，朗塘大师连脸色一些也没有变地接受了婴孩。他随即觅得乳母来，他供给他们，使乳母和婴孩两得安饱。在婴孩长大了的时候，过去送婴孩来的那一家人对朗塘大师，作了恭敬承事，真诚地启请说：“先是生过孩子，苦不能养活，这也因为那时问卜和算命都说如不用那种方便，仍不能养活的原因。请求你饶恕我们的罪过，将孩子给与我们。”朗塘大师答应了他们的请求，满足了他们所喜的心愿。这确是朗塘大师真实学到而且做到菩萨行中最难行处！又他在塔谟隆寺住的时候，在一夏天里，色觉瓦的田中，发生了水灾，来请求朗塘大师修法退水，大师当时拿了一个截口的牛角，盖上图章封好而给来人说：“将这东西埋藏在受水灾的潮水里。”那里的人照他所说的做后，水立刻退了。后来把牛角截口打开一看，里面只有一字条写的是——“比丘金刚狮子在此，水你快退！”这确是与偈中所说：“真诚加持力，能灭大火聚，此义应当知，记别为不还。”等句的情理是相同的。朗日塘巴的佛尊塔——“诸佛菩萨无量宫见者具义宝塔”修建成功后，从四方请来如善知识博多瓦等身著袈裟的清净比丘一百零八人，来做真言身中安住智慧尊的开光法事，及供花仪轨等事。当雨花时，空中普遍现出甚为稀有的虹光交织成幕，八吉祥相等，复从空中天雨诸种香花、芬芳异常，就是畜类也做出闻得这种异香的表情，塔前面供设稀有珍贵的盛大供养；聚集僧伽海会前，作了承事供养；对无数人众作了广大的布施；对贫穷者给予了供养余物。这种情况复如颂所说：“尽我所有物，咸作善业果，愿对一切众，以我能舍心，作施波罗蜜。”初段时间中，由朗日塘巴及侠窝贡巴两师彼此演说，互闻法要。侠窝贡巴说：“朗日塘巴的菩提心量大，我对利益我者，能舍身命，但对损害我者确不能做到。朗日塘巴他是对二者都能做到。”业。纳谟瓦同两师在一起，三师聚会中，提出如果现时将死，当怎样来做的问题。纳谟师说：“这件事要做，那件事也要做，各种各样要做的事很多啊！”侠窝贡巴说：“我认为除修菩提心外，没有其他可作的。”朗日塘巴则说：“哪怕我现前将死，连发心的念诵我都也没有丝毫作念诵的打算。”据说这位大菩萨朗日塘巴他发的愿是为利一切有情故，愿往生地狱中去。直到他临终示寂时，他说：“我的常愿似乎未成熟，此刻纯是清净境相(指如净土，迎接的天人等)显现眼前，这如何是好？我心中有些焦急！”(为一切有情愿入地狱，这样的大善业所感的果，岂是地狱？所以无地狱可入。)善知识切喀瓦在嘉信巴大师座前听受朗日塘巴所著的《修菩提心八颂》后，自心获得很好的转变。这一《修心八颂》是这样：

“常将爱乐心，以之对众生，愿我胜宝身，思惟成大义。

与谁结伴时，众中自居卑，愿以我念绳，绕他生胜爱。

诸行察自心，烦恼刚起时，愿自他恶作，强制立回退。

性恶诸众生，被苦压迫时，愿如遇宝藏，生起难得爱。

他者对我嫉，责谤等不情，亏懊愿自受，胜利献他人。

愿我对谁众，极思利彼心，对我纵毒害，观作是我师。

隐显诸利乐，愿供如母众，诸母害与苦，我愿密取受。

八风污勿染，知诸法如幻，愿以此胜慧，解脱无贪著。”

如上述的具德朗日塘巴他作出了广大的弘法利生事业后，享寿七十岁，于癸卯年四月二十三日在朗塘寺里示现圆寂，而往生兜率宣法宫中。他的遗体在供献各种不可思议供品的同时荼毘的时候，虚空中普现虹光网幕，天雨诸花，天供诸香，芬芳四溢。为数以万计的僧俗大众，都见著这种清净境相，大都发起菩提心，与不改变的信心。灵骨中出现了不可思议的佛本尊等像，与及心脏(诸贤大德有的火焚不化留下眼、舌、心等)、靛蓝舍利树、舍利等物。而拿灵骨舍利来复作了利众的广大事业(如建塔等事业)。

以此意乐菩提道次第修心的人们，应当对于大菩萨博多瓦师徒等大德供养而祈祷求加；并应忆念博多瓦大师的清净史事。追风实践，最低限度也应当在发愿中，思惟他的所有事业史事，愿尽量增加一些他的善习德性于自己的身心中。
