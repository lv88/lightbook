# 附一、善知识颇章顶巴略传

颇章顶巴他的种姓名业，诞生在赵坝地方，名叫迅鲁峨(义为童光)。他长期依止善知识博多瓦。除夏冬两季中稍有一些时间未在师前外，他从见师起一直到上师圆寂之间，都在上师博多瓦的座前，对上师的一切所作，他的心目中都见为功德外，从来没有过不顺的看法。这样的一位大德，博多瓦大师到示寂的时候，对他说：“你须得要结交十人至十五人为自己的助友，否则如果你一己独处的话，将会如地鼠一样，被其他的敌人一如野狼抓走而杀害。”他对博多瓦所说的一切教授，都能完全体会在心里，特别是对博多瓦所说一切法中配合各种譬喻来说的这点，心发生惊奇，因此他向上师博多瓦请求将所有譬喻编集在一起，博多瓦对他说：“好！你来将它广弘一下吧！那么，你做吧！”因此，颇章顶巴他将一切譬喻作出了初次的集撰。当博多瓦在喀脱住的时候，勒敦。嘉勒坝启请博多瓦说道：“我愿请上师对所说的那些譬喻教法，说一种修学它的次第。”这一请求，善知识扎迦瓦那时听得后，将它记在心里来，直到博多瓦示寂后，过了六年了，扎迦瓦才来到赵坝。颇章顶巴的那里来请求说：“我们上师在世时所说的那些《喻法》，现在我向您请授一切当初您在善知识——博多瓦大师前所求到的《喻法》。”颇章顶巴说道：“你在上师的座前，住的时间比我还住得久一些，对于《喻法》，你有不精通的吗？”经再三地恳求，颇章顶巴也就将《喻法》向扎迦瓦说了一遍。从此扎迦瓦的心中获得新生起了一种过去没有的通达。他也就首先向勒敦。嘉勒坝说了一次《喻法》的广义。继后他复根据颇章顶巴所集撰的著作，对其中还有未全的地方，都加以增补，对一切意义不明显的，都加以阐明，和上下有错乱的，都作了分别的编撰。经他这样作了一些改正后，作出了比颇章顶巴原著还要精深广博的善本。此后，善知识扎迦瓦的座前，复由阿阇黎彭裕瓦。降秋朗瓦(义为菩提光现)听受了这一《喻法》，降秋朗瓦前，复由生在达纳达汝地方的杰。贡仲巴。协绕多杰(义为智金刚)听受了这一《喻法》，并向通俗易晓方面，复作修改后，而对他人广为弘传。

善知识赵坝。颇章顶巴他修建赵勒色(义为新寺)及颇章顶(义为宫中寺)，集会僧伽约四百多人。他享寿六十五岁，在赵勒色寺里示寂。
