# 三十五、持律大师措那巴的历史

根据宗喀巴大师所著“菩提道次第师承启祷文”中的颂句赞叹道：

“亿部毘奈耶，拥主措那巴。”

获得这样赞词的大德措那巴，系生在门。措那上区。他从童年时代会说话开始，就一味乐学正法，身语意三门的一切行动，就完全能顺正法而作，不趣向一般孩童的性情。他年满八岁的时候，常说他要到喇嘛的座前去；在谁也不能阻止他的这种心愿的当中，他逃奔到桑钦巴大师的座前而出了家。最初阶段他受了沙弥戒，起名叫协饶让波。那时，他很自然地表现出具足善巧的班智达的态度，以此都传说他是忆持三藏的大师洛卓生根(义为智狮子)的化身。此后他心行两方面都很如法依止善知识桑钦巴，而很好地学习《噶当六论》等大车轨诸论著，特别是对于毘奈耶四部，及摄一切律义的戒经，钻研学习而对于所习句义都作到领会通达。他并请求善知识桑钦巴为作亲教师，也就在教范等师和如数满足的僧众当中，受了具足戒。他心中所知的一切戒律从学处最微细分，都能依照而实行，以此有如圣优波离尊者再来到西藏地方一样光景。

他继在善知识桑钦巴前听受了为三世一切诸佛共趣大道，也是大车轨龙树与无著两位大师的亲规准绳，复经阿底峡尊者在此藏地阐明的教授——《菩提道次第导释》，是依照噶当教典的讲规而说的。所有教义他都能听受后而作实修获得了定解。据说由于这位善知识，他是发有伟大的护持正法的愿力已得成熟的一位大师的缘故，他不仅是在昼间听受一切佛经和经论等，又已获得净治幻梦的原因，所以他在夜里梦中复在阿阇黎德光前听受《毘奈耶》；在寂天菩萨前听受《入行论》；在阿阇黎世亲前听受《对法俱舍论》；在阿阇黎方象前听受《集量颂》等；在阿阇黎法称前听受《释量论》等因明七论；在阿阇黎月称前听受《密集》；在至尊弥勒前听受《现观庄严颂》等。就这样他是已获得到了闻法大海的彼岸。特别是由于他对于毘奈耶已彻底精通的缘故，所以贡波(即怙主明王)等一切护法，和许多善神都来劝请说：“请著一部能使藏中的受化众生容易通晓的摄四部律要义的毘奈耶论著。我们对于依你所著论著而作闻思的一切人士，都愿如爱子般地保护他。”同时许多僧伽也劝请去主持讲学僧院，他于是来到大学法僧院中，登讲学的狮子座而广弘宣说大车轨诸经论，并摄四部律要义而著作了解说律经的《日光论》。据传说一切善神为了赞说他作的这部论著的缘故，他刚一著完，就被一切善神将论著函卷迎请走了，后来他再次复著这一论著。此外这位大师复著作了许多如菩提道次第等的论著。这位大师他也效法博多瓦的史事高风，获得结合大车轨诸经论来讲说菩提道次第的无畏辩才。外表虽是看起来他对密教是很严谨慎重的，而他的内德确是具足修密彻底的功德。以此他是已获得吉祥密集的圆满次第的住持梦幻功德，所以他能显现在梦中去到一切他方佛刹，与及向应化众生说法、在一切佛菩萨前闻法等各种幻化的功德。这类事迹也不过是为前面一样附说一点而已。

这位大德他广作弘法利生的事业，直到七十二岁时，他对一切僧众说了许多教诫他们的话，并将学院法座托付给门扎巴后，也就示寂了。这位大德虽拥有许多不可思议弟子，但能做他的代表人的首要弟子，确为善知识门扎巴。

以此意乐菩提道次第修心的人们应当对于这位持律大师祈祷求加持，并应清净守护佛法的内珍宝藏——毘奈耶而为基础的情况下，勤修菩提道次第修心教授。
