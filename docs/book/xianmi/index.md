# 显密问答录

### 汉藏佛教十九问答

*济群法师 问 · 索达吉堪布 答*

::: tip 关于本书
底本为流通于网络的电子版，题「济群法师 问　索达吉堪布 答」。本站按底本全文录入，仅对行首会被 Markdown 误解析的字符作转义，不改动原文语句与标点。
:::

汉传与藏传佛教在食素、戒律、传法资格、即身成佛、密咒、如来藏、寺院教育等诸多问题上，长期存在误解与争讼。济群法师将心中疑问整理寄往喇荣五明佛学院，索达吉堪布逐条作答，往复十九问，遂成此《显密问答录》。

全书以「问—答」相扣：既有三藏经论的教证，也有藏地僧俗实情的陈述，读来如同旁观一场坦诚的对话。卷末另附堪布致济群法师的信，及《生死救度》中关于临终助念的节选。

:::: tip 阅读建议
十九篇各自独立，可按兴趣跳读；每篇末有「上一篇／下一篇」，页右下方「字」按钮可调节字号、行距与底色。卷前《缘起》《前言》交代了问答的由来，建议先读。
::::
