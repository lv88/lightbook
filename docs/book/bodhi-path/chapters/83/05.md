# 阿底峡师徒不共秘法《噶当十六滴》师承概况

> 本篇为 [八十三、至尊仁达瓦·迅路洛卓大师的历史](/book/bodhi-path/chapters/83/) 之附传。

阿底峡尊者师徒的不共秘法《噶当十六滴》师承次第如下：

在阿底峡尊者尊师徒住世时，对于这一法门，极为严密，只传给成就住持这一法流宏愿，并得到至尊文殊加持的大善知识峨·勒比协饶(义为善智)大师一人。大师谨守严印。阿底峡尊者示寂后，由种敦巴尊者将这一法门的灌顶，及教授摄要传给善知识迦瓦大师，也嘱谨守严印。种敦巴尊者的上首弟子三昆仲中，作了记别由朴穷瓦住持《噶当十六心滴教授》法藏。下面就介绍这位为众所称，种敦巴尊者的得意弟子善知识朴穷瓦大师的历史。
