# 附二、阿阇黎释迦弥遮略传

> 本篇为 [十五、至尊圣龙树菩萨的历史](/book/bodhi-path/chapters/15/) 之附传。

阿阇黎释迦弥遮所著《五次第》，其中二次第以上诸法，传称是由阿阇黎龙树随后赐法而著出的。此外虽是未见这位大德著有其他论著，但是这位阿阇黎对很多具缘信众，确是做出了大弘圣龙树中观妙理的事业。
