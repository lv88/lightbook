# 附四、大德玛达根巴略传

> 本篇为 [十五、至尊圣龙树菩萨的历史](/book/bodhi-path/chapters/15/) 之附传。

他将从圣龙树前得来的耳传诸教授，完全传授给获得成就大师德洛巴，并对其他许多具缘信众，也广弘耳传教法。
