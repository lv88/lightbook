# 关于本站

lightbook 是一个静态电子书站，把中文佛学典籍按篇目拆分为页面，逐篇成页、可全文检索。架上现有两部书：

| 书目 | 署名 | 构成 |
| --- | --- | --- |
| [菩提道次第师师相承传](/book/bodhi-path/) | 耶喜绛称 著 · 郭和卿 译 | 八十四篇祖师行传，附传别记五十四篇，卷末译者附录六页 |
| [显密问答录](/book/xianmi/) | 济群法师 问 · 索达吉堪布 答 | 卷前缘起、前言二篇，正文十九问，附录二篇，卷末回向偈 |

每本书占一个独立路径 `/book/<书>/`，各有封面、全书目录、侧边栏与翻页序列；翻页与目录都不跨书。

## 页面构成

- **卷前**：缘起、前言一类置于编号篇目之前的文字；
- **正文**：按底本编号的篇目，每篇一页，其下附传、略传、琐记、年表作为该篇子页列于侧边栏；
- **卷末**：回向偈一类置于全书末尾的短篇；
- **附录**：随书刊行的附录文字；若属译者自撰（如《菩提道次第师师相承传》卷末《学习六部》总叙），另标注撰者并单列，不计入正文书目与翻页序列。

## 检索与导航

- 页右上「检索全书」对全站逐字检索，中文按单字切分，输入人名或地名即可；
- 页底提供上一篇／下一篇，通读时不必回目录；
- 右下圆形「字」按钮可调节字号、行距、字距，并在**宣纸／米黄／墨夜**三种底色间切换；偏好保存在本机浏览器，下次打开仍然生效；
- 内置 `@media print` 样式，隐藏界面元素、单栏排印，可直接打印或导出 PDF。

## 录校体例

- 全文按底本简体横排录入，仅对极少数字的异体写法作规范处理，不改动原译的语法、标点风格与人名译法；
- 原文中的作者按语（如「我(著者自称)」）与译者按语（如「译者按：……」）均予保留；
- 底本中个别仅有标题而未刊载正文的条目，本电子版未生成空页面；
- 原排版中的表记与缺字符号（如连串的破折号），依原貌保留；
- 正文行首若出现会被 Markdown 误解析的字符（引用、标题、列表、表格标记），插入反斜杠转义，确保「原文照录」。

## 如何上架一部新书

1. 把源 md 放进 `sources/`（平铺，文件保持原样，脚本只读不写）；
2. 在 `books/` 下新建目录，如 `books/<书标识>/`，写入 `book.mjs`：`slug`、`source` 指向 `sources/` 中的文件名，以及书名、署名、简介；
3. 若该书结构与默认规则不同，在 `book.mjs` 中覆盖切分规则：`mainTitleRe`（正文篇目）、`frontTitleRe`（卷前）、`tailTitleRe`（卷末）、`appendixTitleRe`（附录）、`groups`（卷次分组，不分组写 `[]`）、`expectedMainCount`（篇数自检）；
4. 重跑 `npm run gen`，脚本自动发现新书并生成 `/book/<书标识>/` 下的封面、目录与全部页面。
