# 关于本书

## 著者与译本

本书藏文原著题为《菩提道次第师师相承传》，副题「庄严圣教最胜宝鬘」，为泰宝耶喜绛称大师所编著。汉译由**郭和卿**居士据藏文本译出，即本电子版所依的汉文全译本。

全书以师师相承为经，以诸师的发心、积资、弘法事业为纬，依次叙说：

- **广行派师承**：自释迦牟尼佛传至尊弥勒菩萨、无著菩萨、世亲菩萨等广弘菩萨广大行持者；
- **深观派师承**：自至尊文殊传圣龙树菩萨及其弟子，抉择甚深中观见者；
- **伟大行派师承**：自文殊菩萨传寂天菩萨等的自他相换修心教授；
- 上述三派法流由**阿底峡尊者**摄集为一，再经种敦巴与噶当三昆仲传衍；
- 其后由**至尊三界法王宗喀巴大师**及其法脉，乃至编著者时代的诸大善知识承续不绝。

## 关于卷末的译者附录

底本卷末附有《学习六部》总叙一篇，为**译者郭和卿（藏文法名绛巴妥默）居士自撰**，叙述其翻译本书的因缘与增益编撰《学习五部》的原委，**并非藏文原著《菩提道次第师师相承传》的正文**。

本电子版不将其并入八十四篇祖师行传的书目与侧边栏，而是单列为「译者附录」一部（顶部导航可直接进入）；页首与每节均标注撰者，页底翻篇亦与原著序列分列，以免与原译正文相混。

## 电子版检索与导航

本电子版将全帙按篇拆分为页面：

- 每篇主传独立成页，其后所附的「附传」「略传」「琐记」「年表」等，作为该篇的嵌套子页列于侧边栏中，亦可展开跳览；
- 页右上「检索全书」可对全书逐字检索（中文按字切分，输入人名或地名即可）；
- 页底提供上一篇／下一篇，通读时不必回目录；
- 右下圆形「字」按钮可调节字号、行距、字距，并在**宣纸／米黄／墨夜**三种底色间切换；偏好保存在本机浏览器，下次打开仍然生效。

## 录校体例

- 全文按底本简体横排录入，仅对极少数字的异体写法作规范处理，不改动原译的语法、标点风格与人名译法；
- 原文中的作者按语（如「我(著者自称)」）与译者按语（如「译者按：……」）均予保留；
- 底本中个别仅有标题而未刊载正文的附录条目，本电子版未生成空页面；
- 原排版中的表记与缺字符号（如连串的破折号），依原貌保留。
