# 《学习六部》总叙(由于六部，各有叙言，此指总摄六部而言也。)

> 本篇为 译者绛巴妥默（郭和卿）居士 所撰《学习六部》总叙之一段，非原著正文，详见[附录总叙](/appendix/)。

综余所著，教出西藏，法崇宗喀。他者得毋谓余学自西藏，有先入为主之成见乎？以此余不能默然无言。兹据事理，略叙数端，以证非有地区门户之见，而使未来学人，有所认识，知当推重者，唯此西藏佛教宗喀之法也。
